# 自定义产品组件区

此目录只承载具有 Vulcan Code 业务辨识度、且会被多个页面复用的组合组件。普通按钮、输入框、选择框、弹层、导航项继续放在 `components/ui`；仅做业务编排的页面组件继续留在对应功能目录。

## 准入规则

组件必须同时满足以下条件：

1. 表达稳定的产品概念，例如用量、成本、模型消耗或命令会话状态。
2. 至少存在两个真实使用位置，或已在视觉实验室中建立完整状态基线。
3. 只接收已经确定的视图模型，不直接请求服务、不订阅全局状态、不自行推断业务字段。
4. 空、加载、部分可用、错误、长数字和窄宽度状态必须可验证。

业务目录负责把后端事实转换成视图模型；本目录只负责统一呈现。供应商特有字段不得通过候选字段或模糊回退塞进通用组件。
