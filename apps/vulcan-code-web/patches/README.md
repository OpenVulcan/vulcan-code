# React 开发版性能记录清理

`react-dom@19.2.3.patch` 将 React 上游
[修复 #34803](https://github.com/react/react/pull/34803) 的客户端计时清理逻辑
回移到当前锁定的 19.2.3。修改普通客户端与 profiling 客户端的开发构建，
覆盖该版本全部八处性能记录路径；生产构建保持原样。

每次写入性能记录后立即按名称清理，避免组件属性副本在长时间流式更新中累积。
DevTools 的 Performance 时间线仍可记录事件；通过
`performance.getEntriesByType("measure")` 查询时不再长期保留这些 React 内部条目。
不覆盖全局计时 API，也不引入定时器。

补丁由 `pnpm-workspace.yaml` 的精确版本声明与 `pnpm-lock.yaml` 的补丁摘要共同锁定；
正常安装与冻结锁文件安装均会应用。升级 React 时，应先核对新版本是否已包含上游修复，
再移除补丁及对应声明，不能只删除补丁文件或静默忽略应用失败。

依赖安装完成后，需要重启 Vite 和桌面客户端，使预构建依赖与已打开页面使用修复后的代码。
本次按用户要求未执行自动化测试或压力测试，实际运行验收由用户完成。
