# 语义引擎隔离浏览器验收

此入口渲染生产设置组件、国际化及完整生产样式，仅替换设置和语义引擎传输模块。它不加载用户服务发现插件，不读取用户配置，不发送模型请求；保存、兼容预检和模型测试均明确拒绝，不伪造成功。

在前端目录运行：

```powershell
rtk pnpm exec tsc --project tests/vce-browser/tsconfig.json --pretty false
rtk pnpm exec vite --config tests/vce-browser/vite.config.ts
```

打开 `http://127.0.0.1:17617/`。端口固定且占用即失败。页面按钮调整的是内容面板宽度，不是浏览器视口；两者必须分别验证。样式入口显式扫描生产源码，避免隔离根目录导致工具类缺失而产生无效截图。

## 回归步骤

1. 宽浏览器下依次切换三百六十、六百四十、一千像素内容面板。前两档模型行应堆叠，一千像素时可以横排；说明不可竖排或被遮挡。
2. 设置真实浏览器视口为三百六十像素，分别检查中英文。页面不应产生横向滚动，模型测试按钮不能挤窄模型说明。
3. 切换长诊断，检查三种能力的连续长串完整换行；点击重排测试，顶部失败信息也必须完整换行。测量对应元素的滚动宽度不大于内容宽度。
4. 键盘回车打开向量模型，输入账号 `Beta` 后首选候选为该账号，回车只修改草稿，显示尚未保存及还原操作。通用组件使用模糊排序，并不保证其他弱匹配消失。
5. 输入 `zzzz-unmatched`，应显示无匹配模型；按退出键后焦点回到模型选择器。
6. 验收结束恢复视口，停止此隔离开发进程。

此入口只证明浏览器组件布局和选择器行为，不代替真实模型、主服务启动、配置保存事务或聊天流式并发验收。
