# 语义引擎真实后端浏览器验收

与相邻的布局夹具不同，此入口加载完整生产应用、生产浏览器传输、真实鉴权协议及事件通道。后端必须为本任务的私有完整启动夹具，不连接现有用户服务。

## 启动

1. 创建一个新的空绝对临时目录。在测试进程环境中明确设置 `VULCAN_VCE_BROWSER_TEST_ROOT`，运行内核唯一手动测试：

   `rtk cargo test -p vulcan-service-kernel service_bootstrap::vce_startup_tests::real_browser_vce_lifecycle_host -- --ignored --exact --test-threads=1 --nocapture`

2. 等待私有目录生成 `browser-discovery.json`，不要复制或输出其中的访问令牌。在前端目录的独立进程中设置相同的专用环境变量，再运行：

   `rtk pnpm exec vite --config tests/vce-live/vite.config.ts`

3. 打开 `http://127.0.0.1:17619/`。只使用测试项目。模型声明真实但没有可调用凭据，禁止把模型测试失败计为真实模型成功。

## 隔离边界

页面内容安全策略只允许本页面及回执中的精确私有端点。生产发现逻辑即使探测默认服务范围，也会被浏览器阻断，不能误连用户服务。此配置不加载普通开发发现插件，不写全局主目录环境变量，不变更生产发现逻辑。后端使用真实服务引导、真实项目设置、真实持久作业及项目独立存储；没有响应桩。

初始两个项目关闭语义引擎且手动更新，源码为空；模型配置有效，不暗建索引。验收固定设置导航、通用模型过滤、项目开关、人工初始化、手动／自动模式、状态浮窗、菜单跳转及页面重载。需要非空模型交错的证据应引用已独立执行的真实传输组合测试，不能把空索引当成非空向量计算成功。

## 结束

先关闭测试浏览器页，再在精确私有根内创建 `stop-browser-host` 文件。宿主中止自己的监听、执行真实关闭准备及控制器租约释放，并确认私有控制器端点退出。最长三十分钟到期也退出并报测试超时，不把超时算通过。随后停止此 Vite 进程。不得按进程名称或默认端口清理其他服务。
