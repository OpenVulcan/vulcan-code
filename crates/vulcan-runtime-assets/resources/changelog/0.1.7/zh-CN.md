Vulcan Code 0.1.7 让 Ubuntu 23.10 及以后版本上的 Linux 桌面端可以从程序坞和应用菜单启动，让 Windows 上的重新安装与更新更安全，修补了若干安全与数据丢失问题，并随附安装器 0.2.9。

### 更新到此版本

```ui-checklist
ok | 完整更新 | 此版本修改了安装程序与安装布局，因此以完整更新的方式安装：Windows 上应用会下载并运行一次安装包
ok | 安装器安装 | 用安装器安装的版本请运行 vulcan-code-setup update 更新；应用会给出这一提示，而不是提供下载
```

### Linux

```ui-checklist
ok | 程序坞与应用菜单 | 在 Ubuntu 23.10 及以后版本上，安装器 0.2.9 会一次性安装 AppArmor 配置，桌面端可以从程序坞和应用菜单启动，不再只能从桌面图标启动
ok | 在应用中安装配置 | 配置缺失或过期时，更新设置会提供一键安装（只询问一次管理员密码），或给出可在终端中运行的命令
```

### Windows

```ui-checklist
ok | 安全的重新安装 | 安装到没有旧安装的文件夹时，绝不删除其中的文件；重新安装同一版本未完成时，会恢复原来的版本
ok | 试运行 | 上一版本的 Core 仍在运行时打开桌面端，不再被算作新版本启动失败，也不会触发回退
```

### 安全

```ui-checklist
ok | 本地服务 | Core 只接受发往回环主机名的请求，把自身地址指向本机的网页无法读取服务
ok | 附件 | SVG 附件在沙箱中打开，无法运行脚本；附件路径不能离开其所在文件夹
ok | 只读判断 | 名称含写入动词的扩展工具、git branch 的写入选项以及 fd 的执行选项不再被视为只读
ok | 密钥 | 用普通值覆盖密钥环境变量时，它仍保持为密钥
```

### 修复

```ui-checklist
ok | 技能与项目 | 从技能自身所在文件夹安装本地技能不再把它删除；删除项目时一并删除其项目变量
ok | 记忆 | Markdown 记忆可以正确读取中文、日文和韩文标题
ok | 计划模式 | 回合结束后开启或关闭计划模式不再失败
ok | 工具参数 | 引用共享定义的参数（如可选值列表）保持可见且为必填
ok | 模型参数 | 小数参数以数字形式发送；Tavily 提取只给 URL 时也能正常工作
ok | 文件编辑 | 在文件末尾插入内容时保留最后一行和末尾的空行
ok | WebUI | 提交信息中的方向键移动光标；以 --- 或 +++ 开头的差异行可以正常显示；代码示例中的图片链接保持原样
```
