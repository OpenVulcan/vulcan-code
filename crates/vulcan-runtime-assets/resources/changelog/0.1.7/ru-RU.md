Vulcan Code 0.1.7 позволяет запускать приложение для Linux из дока и меню приложений в Ubuntu 23.10 и новее, делает переустановку и обновление в Windows безопаснее, устраняет ряд проблем безопасности и потери данных и поставляется с программой установки 0.2.9.

### Обновление до этой версии

```ui-checklist
ok | Полное обновление | В этой версии изменились установщик и структура установки, поэтому она ставится как полное обновление: в Windows приложение один раз скачивает и запускает установщик
ok | Установки через setup | Установки, сделанные программой установки, обновляются командой vulcan-code-setup update; приложение сообщает об этом вместо предложения скачать
```

### Linux

```ui-checklist
ok | Док и меню приложений | В Ubuntu 23.10 и новее setup 0.2.9 один раз устанавливает профиль AppArmor, и приложение запускается из дока и меню приложений, а не только со значка на рабочем столе
ok | Профиль из приложения | Если профиля нет или он устарел, настройки обновления предлагают установить его с однократным вводом пароля администратора или показывают команду для терминала
```

### Windows

```ui-checklist
ok | Безопасная переустановка | Установка в папку без прежней установки никогда не удаляет её файлы; если переустановка той же версии не завершилась, прежняя версия восстанавливается
ok | Пробный запуск | Открытие приложения, пока ещё работает прежний Core, больше не считается неудачным запуском новой версии и не вызывает откат
```

### Безопасность

```ui-checklist
ok | Локальный сервис | Core принимает только запросы, адресованные loopback-имени хоста, поэтому веб-страница, направившая свой адрес на этот компьютер, не может читать сервис
ok | Вложения | SVG-вложения открываются в песочнице и не могут запускать скрипты, а пути вложений не могут выйти за пределы своей папки
ok | Проверка только чтения | Инструменты расширений с глаголом записи в названии, записывающие параметры git branch и параметры выполнения fd больше не считаются только читающими
ok | Секреты | Запись обычного значения поверх секретной переменной окружения сохраняет её секретной
```

### Исправления

```ui-checklist
ok | Навыки и проекты | Установка локального навыка из его собственной папки больше не удаляет его, а удаление проекта удаляет и его переменные проекта
ok | Память | Markdown-память правильно читает заголовки на китайском, японском и корейском
ok | Режим плана | Включение или выключение режима плана после завершения хода больше не завершается ошибкой
ok | Параметры инструментов | Параметры, ссылающиеся на общие определения, например списки допустимых значений, остаются видимыми и обязательными
ok | Параметры модели | Десятичные параметры отправляются как числа, а извлечение Tavily работает только с URL
ok | Правка файлов | Вставка в конец файла сохраняет последнюю строку и завершающие пустые строки
ok | WebUI | Стрелки в сообщении коммита двигают курсор, строки diff, начинающиеся с --- или +++, отображаются, а примеры кода сохраняют ссылки на изображения в исходном виде
```
