Vulcan Code 0.1.7 では、Ubuntu 23.10 以降で Linux デスクトップアプリを Dock やアプリメニューから起動できるようになり、Windows での再インストールと更新がより安全になり、いくつかのセキュリティとデータ消失の問題を修正しました。セットアップ 0.2.9 が付属します。

### このバージョンへの更新

```ui-checklist
ok | フル更新 | このバージョンではインストーラーとインストール構成が変わったため、フル更新としてインストールされます。Windows ではアプリがインストーラーを一度ダウンロードして実行します
ok | セットアップでのインストール | セットアッププログラムでインストールした場合は vulcan-code-setup update を実行して更新します。アプリはダウンロードを提示する代わりにその旨を表示します
```

### Linux

```ui-checklist
ok | Dock とアプリメニュー | Ubuntu 23.10 以降では、セットアップ 0.2.9 が AppArmor プロファイルを一度だけインストールするため、デスクトップアイコンだけでなく Dock やアプリメニューからもデスクトップアプリを起動できます
ok | アプリからのインストール | プロファイルがない、または古い場合、更新設定から管理者パスワードの入力一回でインストールできます。ターミナルで実行するコマンドも表示されます
```

### Windows

```ui-checklist
ok | 安全な再インストール | 以前のインストールがないフォルダーにインストールしても、そのフォルダーのファイルは削除されません。同じバージョンの再インストールが完了しなかった場合は、元のバージョンが復元されます
ok | 試行起動 | 前のバージョンの Core が動作中にデスクトップアプリを開いても、新バージョンの起動失敗とは数えられず、ロールバックも起きません
```

### セキュリティ

```ui-checklist
ok | ローカルサービス | Core はループバックのホスト名宛てのリクエストだけを受け付けるため、自分のアドレスをこのコンピューターに向けた Web ページはサービスを読み取れません
ok | 添付ファイル | SVG の添付ファイルはサンドボックス内で開かれ、スクリプトを実行できません。添付ファイルのパスはそのフォルダーの外に出られません
ok | 読み取り専用の判定 | 名前に書き込み動詞を含む拡張ツール、git branch の書き込みオプション、fd の実行オプションは読み取り専用として扱われなくなりました
ok | シークレット | シークレットの環境変数を通常の値で上書きしても、シークレットのまま保たれます
```

### 修正

```ui-checklist
ok | スキルとプロジェクト | ローカルスキルを自身のフォルダーからインストールしても削除されなくなり、プロジェクトを削除するとそのプロジェクト変数も削除されます
ok | メモリ | Markdown メモリが中国語・日本語・韓国語の見出しを正しく読み取ります
ok | プランモード | ターンの終了後にプランモードを切り替えても失敗しなくなりました
ok | ツールのパラメーター | 共有定義を参照するパラメーター（許可される値の一覧など）が表示され、必須のまま保たれます
ok | モデルのパラメーター | 小数のパラメーターは数値として送信され、Tavily の抽出は URL だけでも動作します
ok | ファイル編集 | ファイルの末尾に挿入しても、最後の行と末尾の空行が保たれます
ok | WebUI | コミットメッセージ内の矢印キーでカーソルが動き、--- や +++ で始まる差分の行が表示され、コード例の画像リンクは書かれたまま保たれます
```

ok | Git | 接続が切れても、コミットとメッセージ生成が再起動までロックされなくなりました
