Vulcan Code 0.1.7 讓 Ubuntu 23.10 及以後版本上的 Linux 桌面應用程式可以從 Dock 與應用程式選單啟動，讓 Windows 上的重新安裝與更新更安全，修補了數項安全與資料遺失問題，並隨附安裝程式 0.2.9。

### 更新到此版本

```ui-checklist
ok | 完整更新 | 此版本修改了安裝程式與安裝配置，因此以完整更新的方式安裝：Windows 上應用程式會下載並執行一次安裝檔
ok | 安裝程式安裝 | 以安裝程式安裝的版本請執行 vulcan-code-setup update 更新；應用程式會顯示這項提示，而非提供下載
```

### Linux

```ui-checklist
ok | Dock 與應用程式選單 | 在 Ubuntu 23.10 及以後版本上，安裝程式 0.2.9 會一次性安裝 AppArmor 設定檔，桌面應用程式可以從 Dock 與應用程式選單啟動，不再只能從桌面圖示啟動
ok | 在應用程式中安裝設定檔 | 設定檔缺少或過期時，更新設定會提供一鍵安裝（只詢問一次管理員密碼），或提供可在終端機中執行的指令
```

### Windows

```ui-checklist
ok | 安全的重新安裝 | 安裝到沒有舊安裝的資料夾時，絕不刪除其中的檔案；重新安裝同一版本未完成時，會還原原本的版本
ok | 試執行 | 上一版本的 Core 仍在執行時開啟桌面應用程式，不再被算作新版本啟動失敗，也不會觸發回復
```

### 安全性

```ui-checklist
ok | 本機服務 | Core 只接受發往迴路主機名稱的請求，把自身位址指向本機的網頁無法讀取服務
ok | 附件 | SVG 附件在沙箱中開啟，無法執行指令碼；附件路徑不能離開其所在資料夾
ok | 唯讀判斷 | 名稱含寫入動詞的擴充工具、git branch 的寫入選項以及 fd 的執行選項不再被視為唯讀
ok | 密鑰 | 以一般值覆寫密鑰環境變數時，它仍保持為密鑰
```

### 修正

```ui-checklist
ok | 技能與專案 | 從技能本身所在資料夾安裝本機技能不再將其刪除；刪除專案時一併刪除其專案變數
ok | 記憶 | Markdown 記憶可以正確讀取中文、日文與韓文標題
ok | 計畫模式 | 回合結束後開啟或關閉計畫模式不再失敗
ok | 工具參數 | 參照共用定義的參數（例如可選值清單）保持可見且為必填
ok | 模型參數 | 小數參數以數字形式傳送；Tavily 擷取只提供 URL 時也能正常運作
ok | 檔案編輯 | 在檔案結尾插入內容時保留最後一行與結尾的空行
ok | WebUI | 提交訊息中的方向鍵移動游標；以 --- 或 +++ 開頭的差異行可以正常顯示；程式碼範例中的圖片連結保持原樣
```
