Vulcan Code 0.1.7은 Ubuntu 23.10 이상에서 Linux 데스크톱 앱을 독과 앱 메뉴에서 시작할 수 있게 하고, Windows에서 재설치와 업데이트를 더 안전하게 만들며, 여러 보안 및 데이터 손실 문제를 해결합니다. 설치 프로그램 0.2.9가 함께 제공됩니다.

### 이 버전으로 업데이트

```ui-checklist
ok | 전체 업데이트 | 이 버전은 설치 프로그램과 설치 구조가 바뀌어 전체 업데이트로 설치됩니다. Windows에서는 앱이 설치 파일을 한 번 내려받아 실행합니다
ok | 설치 프로그램으로 설치한 경우 | 설치 프로그램으로 설치했다면 vulcan-code-setup update를 실행해 업데이트합니다. 앱은 다운로드 대신 이 안내를 보여 줍니다
```

### Linux

```ui-checklist
ok | 독과 앱 메뉴 | Ubuntu 23.10 이상에서는 설치 프로그램 0.2.9가 AppArmor 프로필을 한 번 설치하므로, 데스크톱 아이콘뿐 아니라 독과 앱 메뉴에서도 데스크톱 앱이 시작됩니다
ok | 앱에서 프로필 설치 | 프로필이 없거나 오래되었으면 업데이트 설정에서 관리자 비밀번호를 한 번 입력해 설치하거나, 터미널에서 실행할 명령을 확인할 수 있습니다
```

### Windows

```ui-checklist
ok | 안전한 재설치 | 이전 설치가 없는 폴더에 설치해도 그 폴더의 파일은 절대 삭제되지 않습니다. 같은 버전의 재설치가 끝나지 않으면 이전 버전이 복원됩니다
ok | 시험 실행 | 이전 버전의 Core가 실행 중일 때 데스크톱 앱을 열어도 새 버전의 시작 실패로 계산되지 않고 롤백되지 않습니다
```

### 보안

```ui-checklist
ok | 로컬 서비스 | Core는 루프백 호스트 이름으로 보낸 요청만 받으므로, 자신의 주소를 이 컴퓨터로 가리키는 웹 페이지는 서비스를 읽을 수 없습니다
ok | 첨부 파일 | SVG 첨부 파일은 샌드박스에서 열려 스크립트를 실행할 수 없고, 첨부 파일 경로는 해당 폴더를 벗어날 수 없습니다
ok | 읽기 전용 판단 | 이름에 쓰기 동사가 들어간 확장 도구, git branch의 쓰기 옵션, fd의 실행 옵션은 더 이상 읽기 전용으로 취급되지 않습니다
ok | 비밀 값 | 비밀 환경 변수를 일반 값으로 덮어써도 비밀 값으로 유지됩니다
```

### 수정

```ui-checklist
ok | 스킬과 프로젝트 | 로컬 스킬을 자신의 폴더에서 설치해도 더 이상 삭제되지 않으며, 프로젝트를 삭제하면 그 프로젝트 변수도 함께 삭제됩니다
ok | 메모리 | Markdown 메모리가 중국어, 일본어, 한국어 제목을 올바르게 읽습니다
ok | 계획 모드 | 턴이 끝난 뒤 계획 모드를 켜거나 꺼도 더 이상 실패하지 않습니다
ok | 도구 매개변수 | 공유 정의를 참조하는 매개변수(허용 값 목록 등)가 보이고 필수로 유지됩니다
ok | 모델 매개변수 | 소수 매개변수는 숫자로 전송되며, Tavily 추출은 URL만으로도 동작합니다
ok | 파일 편집 | 파일 끝에 내용을 삽입해도 마지막 줄과 끝의 빈 줄이 유지됩니다
ok | WebUI | 커밋 메시지에서 방향키로 커서가 이동하고, --- 또는 +++로 시작하는 diff 줄이 표시되며, 코드 예제의 이미지 링크는 작성된 그대로 유지됩니다
```
