Vulcan Code 0.1.8 将 Shell 命令改为可在后台继续运行的任务，新增项目主页，托盘图标可以打开你选择的客户端并切换语言，并带来发布前全面复查得出的数百项修复。随附安装器 0.2.10。

### 更新到此版本

```ui-checklist
ok | 完整更新 | 此版本再次修改了安装程序，因此以完整更新的方式安装：Windows 上应用会下载并运行一次安装包
ok | 安装器安装 | 用安装器安装的版本请运行 vulcan-code-setup update 更新；应用会给出这一提示，而不是提供下载
```

### Shell 命令

```ui-checklist
ok | 实时输出 | 展开的命令卡片会显示运行中命令的最新几行输出，长时间运行的命令不再像卡住了一样
ok | 后台任务 | 命令可以在后台运行；命令运行时发送的消息会把它转入后台，也可以在命令卡片上手动转入
ok | 不再有大小上限 | 输出写入滚动日志，不再在 8 MiB 时终止命令；AI 拿到最新的几行，需要时可以读取更早的内容
ok | 活动面板 | 会话面板统计子代理和后台命令的数量，点开可查看列表及其日志；为更新而重启时会提醒仍在运行的任务
```

### 项目

```ui-checklist
ok | 项目主页 | 点击侧边栏中的项目名称会打开项目页面，可在其中重命名、使用快捷操作、查看会话统计、搜索会话列表并修改全部项目设置
ok | 未保存的编辑 | 离开项目页面后再回来，未保存的项目记忆编辑仍然保留
```

### 托盘

```ui-checklist
ok | 双击 | 在 Windows 上双击托盘图标会打开你选择的客户端：桌面端、WebUI 或终端客户端；菜单改为右键打开
ok | 语言 | 托盘中的“语言”菜单可以切换界面语言，已打开的客户端会随之切换
```

### 界面

```ui-checklist
ok | 阅读宽度 | 各档对话宽度都更宽了，在普通窗口中加宽内容列也不会再折叠导航
ok | 状态提示 | 状态提示改为贴在输入框的上边缘，不再悬浮在对话上方
ok | 深色主题 | 深色主题中选中的文字清晰可见
ok | 回答组件 | 较长的键名不再把值挤成窄窄的一列；图例前分成多组的公式可以正常显示
ok | 工具运行 | 折叠的工具运行中，正在运行的工具卡片保持紧凑排列
```

### 修复

```ui-checklist
ok | 计划模式 | 只有已提交的计划才会等待确认，重启后也会恢复
ok | 空回答 | 没有给出回答就结束的响应会按你的重试设置重试；在给出回答前就因输出上限被截断时会明确提示
ok | 继续会话 | 上下文整理之后发送消息不再无法开始
ok | 模型参数 | 为特定模型设置的参数不会发送给其他模型
ok | MCP | 分多页返回的工具列表会被完整读取；你设置的请求头优先于环境变量中的请求头
ok | Windows 安装包 | 切换到新版本失败时，安装包会说明原因并保留文件
ok | 安装损坏 | 安装不完整的桌面端会明确提示，而不是启动错误的服务
ok | 复查修复 | 会话、存储、记忆、文件、权限、插件、WebUI 和终端客户端中的数百项小修复
```
