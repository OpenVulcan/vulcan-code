Vulcan Code 0.1.8 では、シェルコマンドをバックグラウンドでも続行できるジョブとして実行し、プロジェクトのホームページを追加し、トレイアイコンから選んだクライアントを開いたり言語を切り替えたりできるようになりました。リリース前の全面的な見直しによる数百件の修正も含まれます。セットアップ 0.2.10 が付属します。

### このバージョンへの更新

```ui-checklist
ok | フル更新 | このバージョンでもインストーラーが変わったため、フル更新としてインストールされます。Windows ではアプリがインストーラーを一度ダウンロードして実行します
ok | セットアップでのインストール | セットアッププログラムでインストールした場合は vulcan-code-setup update を実行して更新します。アプリはダウンロードを提示する代わりにその旨を表示します
```

### シェルコマンド

```ui-checklist
ok | ライブ出力 | 展開したコマンドカードに実行中のコマンドの最新の行が表示され、長いコマンドが止まっているように見えなくなりました
ok | バックグラウンドジョブ | コマンドをバックグラウンドで実行できます。コマンドの実行中にメッセージを送るとバックグラウンドに移り、コマンドカードから移すこともできます
ok | サイズ上限なし | 出力はローテーションするログに書き込まれ、8 MiB でコマンドが止まることはなくなりました。AI は最新の行を受け取り、必要に応じてそれ以前の行を読めます
ok | アクティビティパネル | セッションパネルにサブエージェントとバックグラウンドコマンドの数が表示され、一覧とログを開けます。更新のための再起動時には実行中のジョブを警告します
```

### プロジェクト

```ui-checklist
ok | プロジェクトホーム | サイドバーのプロジェクト名からプロジェクトページを開けます。名前の変更、クイックアクション、セッション統計、検索できるセッション一覧、すべてのプロジェクト設定がそろっています
ok | 未保存の編集 | プロジェクトページを離れて戻っても、未保存のプロジェクトメモリの編集は保たれます
```

### トレイ

```ui-checklist
ok | ダブルクリック | Windows ではトレイアイコンのダブルクリックで、選んだクライアント（デスクトップアプリ、WebUI、ターミナルクライアント）が開きます。メニューは右クリックに移りました
ok | 言語 | トレイの言語メニューで表示言語を切り替えると、開いているクライアントも切り替わります
```

### インターフェース

```ui-checklist
ok | 読みやすい幅 | 会話の幅のプリセットがすべて広くなり、通常のウィンドウでは幅を広げてもナビゲーションが折りたたまれなくなりました
ok | 状態表示 | 状態表示は会話の上に浮かぶのではなく、入力欄の上端に付くようになりました
ok | ダークテーマ | ダークテーマで選択したテキストが見えるようになりました
ok | 回答コンポーネント | 長いキーが値を細い列に押し込まなくなり、凡例の前にある複数グループの数式が正しく表示されます
ok | ツールの実行 | 折りたたまれた実行中のツールカードがまとまって表示されます
```

### 修正

```ui-checklist
ok | プランモード | 確認を待つのは提出されたプランだけになり、再起動後も復元されます
ok | 空の回答 | 回答なしで終わった応答は再試行の設定に従って再試行され、回答の前に出力上限で切れた場合はその旨が表示されます
ok | セッションの続行 | コンテキストの整理後にメッセージを送っても開始に失敗しなくなりました
ok | モデルのパラメーター | 特定のモデル向けに設定したパラメーターが他のモデルに送られなくなりました
ok | MCP | 複数ページにわたるツール一覧を最後まで読み取り、自分で設定したヘッダーが環境変数のヘッダーより優先されます
ok | Windows インストーラー | 新しいバージョンへの切り替えに失敗すると、理由を表示してファイルを残します
ok | 破損したインストール | インストールが不完全なデスクトップアプリは、誤ったサービスを起動せずにその旨を表示します
ok | 見直しによる修正 | セッション、ストレージ、メモリ、ファイル、権限、プラグイン、WebUI、ターミナルクライアントにわたる数百件の小さな修正
```

### セキュリティ

```ui-checklist
ok | 内蔵ブラウザー | 内蔵ブラウザーは Core の保護されたポートへのあらゆるローカルアドレス表記をブロックします
ok | プロバイダーのエラー | プロバイダーのエラーは短縮や表示の前に API キーが取り除かれます
```
