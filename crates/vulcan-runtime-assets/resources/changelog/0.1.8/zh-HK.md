Vulcan Code 0.1.8 將 Shell 指令改為可在背景繼續執行的工作，新增專案首頁，系統匣圖示可以開啟你選擇的用戶端並切換語言，並帶來發佈前全面複查得出的數百項修正。隨附安裝程式 0.2.10。

### 更新至此版本

```ui-checklist
ok | 完整更新 | 此版本再次修改了安裝程式，因此以完整更新的方式安裝：Windows 上應用程式會下載並執行一次安裝檔
ok | 安裝程式安裝 | 以安裝程式安裝的版本請執行 vulcan-code-setup update 更新；應用程式會顯示這項提示，而非提供下載
```

### Shell 指令

```ui-checklist
ok | 即時輸出 | 展開的指令卡片會顯示執行中指令的最新幾行輸出，長時間執行的指令不再像是卡住了
ok | 背景工作 | 指令可以在背景執行；指令執行時傳送的訊息會將它移至背景，亦可以在指令卡片上手動移入
ok | 不再有大小上限 | 輸出寫入循環記錄，不再於 8 MiB 時終止指令；AI 取得最新的幾行，需要時可以讀取更早的內容
ok | 活動面板 | 工作階段面板統計子代理及背景指令的數量，按開可查看清單及其記錄；為更新而重新啟動時會提醒仍在執行的工作
```

### 專案

```ui-checklist
ok | 專案首頁 | 按側邊欄中的專案名稱會開啟專案頁面，可在其中重新命名、使用快捷操作、查看工作階段統計、搜尋工作階段清單並修改所有專案設定
ok | 未儲存的編輯 | 離開專案頁面後再回來，未儲存的專案記憶編輯仍會保留
```

### 系統匣

```ui-checklist
ok | 按兩下 | 在 Windows 上按兩下系統匣圖示會開啟你選擇的用戶端：桌面應用程式、WebUI 或終端機用戶端；選單改為按右鍵開啟
ok | 語言 | 系統匣中的「語言」選單可以切換介面語言，已開啟的用戶端會隨之切換
```
