Vulcan Code 0.1.8 выполняет команды оболочки как задания, которые могут продолжаться в фоне, добавляет домашнюю страницу проекта, позволяет значку в трее открывать выбранный клиент и переключать язык и содержит несколько сотен исправлений по итогам полной проверки перед выпуском. Поставляется с программой установки 0.2.10.

### Обновление до этой версии

```ui-checklist
ok | Полное обновление | В этой версии снова изменился установщик, поэтому она ставится как полное обновление: в Windows приложение один раз скачивает и запускает установщик
ok | Установки через setup | Установки, сделанные программой установки, обновляются командой vulcan-code-setup update; приложение сообщает об этом вместо предложения скачать
```

### Команды оболочки

```ui-checklist
ok | Вывод в реальном времени | Развёрнутая карточка команды показывает последние строки выполняющейся команды, и долгие команды больше не выглядят зависшими
ok | Фоновые задания | Команда может выполняться в фоне; сообщение, отправленное во время её работы, переводит её туда, а ещё её можно перевести с карточки команды
ok | Завершённые задания | Если фоновая команда завершается после того, как ИИ остановился, сеанс продолжается сам; завершение показывается карточкой контекста с названием и результатом команды
ok | Без ограничения размера | Вывод пишется в циклический журнал, а не останавливает команду на 8 МиБ; ИИ получает последние строки и при необходимости может прочитать более ранние
ok | Панель активности | Панель сеанса показывает число субагентов и фоновых команд и открывает их список с журналами; перезапуск для обновления предупреждает о работающих заданиях
ok | Всегда на месте | Счётчики видны в каждом сеансе, даже без Git, субагентов и запущенных команд
```
