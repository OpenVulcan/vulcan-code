Vulcan Code 0.1.8은 셸 명령을 백그라운드에서도 계속 실행할 수 있는 작업으로 실행하고, 프로젝트 홈 페이지를 추가하며, 트레이 아이콘으로 원하는 클라이언트를 열고 언어를 바꿀 수 있게 합니다. 출시 전 전면 검토에서 나온 수백 건의 수정도 포함됩니다. 설치 프로그램 0.2.10이 함께 제공됩니다.

### 이 버전으로 업데이트

```ui-checklist
ok | 전체 업데이트 | 이 버전도 설치 프로그램이 바뀌어 전체 업데이트로 설치됩니다. Windows에서는 앱이 설치 파일을 한 번 내려받아 실행합니다
ok | 설치 프로그램으로 설치한 경우 | 설치 프로그램으로 설치했다면 vulcan-code-setup update를 실행해 업데이트합니다. 앱은 다운로드 대신 이 안내를 보여 줍니다
```

### 셸 명령

```ui-checklist
ok | 실시간 출력 | 펼친 명령 카드에 실행 중인 명령의 최신 줄이 표시되어, 오래 걸리는 명령이 멈춘 것처럼 보이지 않습니다
ok | 백그라운드 작업 | 명령을 백그라운드에서 실행할 수 있습니다. 명령 실행 중에 메시지를 보내면 백그라운드로 옮겨지며, 명령 카드에서 직접 옮길 수도 있습니다
ok | 작업 종료 | AI가 멈춘 뒤 백그라운드 명령이 끝나면 세션이 스스로 이어집니다. 종료는 명령 이름과 결과를 담은 컨텍스트 카드로 표시됩니다
ok | 크기 제한 없음 | 출력은 순환 로그에 기록되어 더 이상 8 MiB에서 명령이 중단되지 않습니다. AI는 최신 줄을 받고 필요하면 이전 줄을 읽을 수 있습니다
ok | 활동 패널 | 세션 패널에 하위 에이전트와 백그라운드 명령의 수가 표시되고, 목록과 로그를 열 수 있습니다. 업데이트를 위해 재시작할 때 실행 중인 작업을 경고합니다
ok | 항상 표시 | Git, 하위 에이전트, 실행 중인 명령이 없어도 모든 세션에 개수가 표시됩니다
```

### 프로젝트

```ui-checklist
ok | 프로젝트 홈 | 사이드바의 프로젝트 이름을 누르면 이름 변경, 빠른 작업, 세션 통계, 검색 가능한 세션 목록, 모든 프로젝트 설정이 있는 프로젝트 페이지가 열립니다
ok | 저장하지 않은 편집 | 프로젝트 페이지를 떠났다가 돌아와도 저장하지 않은 프로젝트 메모리 편집이 유지됩니다
```

### 트레이

```ui-checklist
ok | 더블 클릭 | Windows에서 트레이 아이콘을 더블 클릭하면 선택한 클라이언트(데스크톱 앱, WebUI, 터미널 클라이언트)가 열립니다. 메뉴는 오른쪽 클릭으로 옮겨졌습니다
ok | 언어 | 트레이의 언어 메뉴로 인터페이스 언어를 바꾸면 열려 있는 클라이언트도 따라 바뀝니다
```

ok | 상태 표시 | 상태 표시가 대화 위에 떠 있지 않고 입력창 위쪽 가장자리에 붙습니다

ok | 도구 실행 | 접힌 도구 실행에서 실행 중인 도구 카드가 모여서 표시됩니다
```

ok | 검토 수정 | 세션, 저장소, 메모리, 파일, 권한, 플러그인, WebUI, 터미널 클라이언트 전반의 수백 건의 작은 수정
```
