Vulcan Code 0.1.22 新增免费云端记忆，并改进长会话中的图片发送、供应商错误提示和语音录制。

### 记忆

```ui-checklist
ok | 免费云端记忆 | 在提供服务的站点登录 OpenVulcan。启用前可查看各阶段的模型、处理地区和数据说明，用量按记忆处理阶段显示。
ok | 向量重建 | 显示已完成的批次和限流等待倒计时，等待结束后继续重建。
ok | Markdown 记忆 | 修订冲突会区分同批次暂存的修订和上次已保存的修订。
```

### 会话

```ui-checklist
ok | 长会话发送新图片 | 开启自动压缩后，历史图片占用过多预算时可先分批生成描述，再通过原请求发送本轮新图片。
ok | 供应商错误 | 百炼额度错误按限流处理。余额不足和网络故障会显示错误卡，普通系统提示显示为状态行。
```
