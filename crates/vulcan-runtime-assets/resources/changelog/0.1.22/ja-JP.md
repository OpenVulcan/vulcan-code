Vulcan Code 0.1.22 では無料のクラウドメモリに対応し、長い会話での画像送信、プロバイダーエラー、音声録音を改善しました。

### メモリ

```ui-checklist
ok | 無料のクラウドメモリ | 対応サイトで OpenVulcan にサインインしてください。有効化する前にモデル、処理地域、データの取り扱いを確認できます。使用量は処理段階ごとに表示されます。
ok | ベクトルの再構築 | 完了したバッチ数とレート制限の待ち時間を表示し、待機後に処理を再開します。
ok | Markdown メモリ | リビジョンの競合時に、バッチ内の一時リビジョンと最後に保存されたリビジョンを区別して表示します。
```

### 会話

```ui-checklist
ok | 長い会話での画像送信 | 自動圧縮が有効な場合、過去の画像をバッチごとに要約してから、元のリクエストで新しい画像を送信できます。
ok | プロバイダーエラー | Bailian の割り当てエラーをレート制限として扱います。残高不足とネットワーク障害はエラーカード、通常のシステム通知はステータス行に表示します。
```

### 音声入力とツール

```ui-checklist
ok | 録音時間 | 上限に達した録音も文字起こしに送信できます。
ok | RTK 統計 | Claude の会話ログを走査せず、既存の RTK 統計データベースからコマンドのランキングを表示します。
```
