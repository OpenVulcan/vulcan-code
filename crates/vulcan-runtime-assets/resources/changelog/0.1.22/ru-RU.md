В Vulcan Code 0.1.22 добавлена бесплатная облачная память и улучшены отправка изображений в длинных беседах, уведомления об ошибках и запись голоса.

### Память

```ui-checklist
ok | Бесплатная облачная память | Войдите в OpenVulcan на сайте, где доступна услуга. Перед включением можно проверить модели, регионы обработки и условия работы с данными. Расход показан по этапам.
ok | Перестроение векторов | Отображаются завершённые пакеты и время ожидания при ограничении частоты запросов. После ожидания перестроение продолжается.
ok | Память Markdown | При конфликте отдельно отображаются промежуточная ревизия внутри пакета и последняя сохранённая ревизия.
```

### Беседы

```ui-checklist
ok | Новые изображения в длинных беседах | При автоматическом сжатии предыдущие изображения можно описать по пакетам, освободив место для новых. Новые изображения отправляются в исходном запросе.
ok | Ошибки провайдеров | Ошибки квоты Bailian обрабатываются как ограничение частоты. Ошибки баланса и сети отображаются в карточках, обычные системные уведомления — в строках состояния.
```

### Голосовой ввод и инструменты

```ui-checklist
ok | Длительность записи | Запись можно отправить на расшифровку, даже если она достигла предельной длительности.
ok | Статистика RTK | Рейтинг команд использует существующую базу статистики RTK без сканирования журналов бесед Claude.
```
