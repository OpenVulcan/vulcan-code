Vulcan Code 0.1.22 ergänzt den kostenlosen Cloud-Speicher für Erinnerungen und verbessert den Bildversand in langen Gesprächen, die Fehleranzeige und Sprachaufnahmen.

### Gedächtnis

```ui-checklist
ok | Kostenloses Cloud-Gedächtnis | Melden Sie sich auf einer unterstützten Website bei OpenVulcan an. Vor der Aktivierung können Sie Modelle, Verarbeitungsregionen und den Umgang mit Daten einsehen. Die Nutzung wird nach Verarbeitungsschritt aufgeschlüsselt.
ok | Vektoren neu aufbauen | Sehen Sie abgeschlossene Stapel und die Wartezeit bei einer Ratenbegrenzung. Danach wird der Neuaufbau fortgesetzt.
ok | Markdown-Gedächtnis | Bei Versionskonflikten wird die im Stapel vorgemerkte Version von der zuletzt gespeicherten Version unterschieden.
```

### Gespräche

```ui-checklist
ok | Neue Bilder in langen Gesprächen | Bei aktivierter automatischer Komprimierung können frühere Bilder stapelweise zusammengefasst werden. Die neuen Bilder werden mit der ursprünglichen Anfrage gesendet.
ok | Anbieterfehler | Bailian-Kontingentfehler gelten als Ratenbegrenzung. Guthaben- und Netzwerkfehler erscheinen in Fehlerkarten, gewöhnliche Systemhinweise in Statuszeilen.
```

### Spracheingabe und Werkzeuge

```ui-checklist
ok | Aufnahmedauer | Aufnahmen können auch beim Erreichen der maximalen Dauer zur Transkription gesendet werden.
ok | RTK-Statistiken | Die Befehlsrangliste nutzt die bestehende RTK-Statistikdatenbank und überspringt das Durchsuchen von Claude-Gesprächsprotokollen.
```
