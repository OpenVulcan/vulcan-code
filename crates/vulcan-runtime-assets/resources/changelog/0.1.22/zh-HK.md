Vulcan Code 0.1.22 新增免費雲端記憶，並改善長對話的圖片傳送、供應商錯誤提示及語音錄製。

### 記憶

```ui-checklist
ok | 免費雲端記憶 | 在提供服務的站點登入 OpenVulcan。啟用前可查看各階段的模型、處理地區和資料說明，用量按記憶處理階段顯示。
ok | 向量重建 | 顯示已完成的批次和限流倒數，等候結束後繼續重建。
ok | Markdown 記憶 | 修訂衝突會分辨同一批次暫存的修訂和上次已儲存的修訂。
```

### 對話

```ui-checklist
ok | 長對話傳送新圖片 | 開啟自動壓縮後，歷史圖片佔用過多預算時可先分批產生描述，再經原請求傳送本輪的新圖片。
ok | 供應商錯誤 | 百煉配額錯誤會按速率限制處理。餘額不足和網絡故障會顯示錯誤卡，普通系統提示顯示為狀態行。
```

### 語音輸入與工具

```ui-checklist
ok | 錄音長度 | 錄音達到長度上限時仍可提交轉錄。
ok | RTK 統計 | 載入指令排行時略過 Claude 對話記錄掃描，繼續讀取原有 RTK 統計資料庫。
```
