Vulcan Code 0.1.22에는 무료 클라우드 메모리가 추가되었으며, 긴 대화의 이미지 전송과 공급자 오류 표시, 음성 녹음이 개선되었습니다.

### 메모리

```ui-checklist
ok | 무료 클라우드 메모리 | 지원 사이트에서 OpenVulcan에 로그인하세요. 활성화 전에 모델, 처리 지역, 데이터 처리 방식을 확인할 수 있습니다. 사용량은 메모리 처리 단계별로 표시됩니다.
ok | 벡터 재구축 | 완료된 배치와 호출 제한 대기 시간을 표시하고, 대기가 끝나면 재구축을 이어갑니다.
ok | Markdown 메모리 | 리비전 충돌 시 배치에 임시로 반영된 리비전과 마지막으로 저장된 리비전을 구분해 표시합니다.
```

### 대화

```ui-checklist
ok | 긴 대화에서 이미지 보내기 | 자동 압축이 켜져 있으면 이전 이미지를 배치별로 요약해 공간을 확보한 뒤 원래 요청으로 새 이미지를 보낼 수 있습니다.
ok | 공급자 오류 | Bailian 할당량 오류를 호출 제한으로 처리합니다. 잔액 부족과 네트워크 오류는 오류 카드에, 일반 시스템 알림은 상태 줄에 표시합니다.
```

### 음성 입력 및 도구

```ui-checklist
ok | 녹음 시간 | 제한 시간에 도달한 녹음도 텍스트 변환을 위해 제출할 수 있습니다.
ok | RTK 통계 | Claude 대화 로그를 검색하지 않고 기존 RTK 통계 데이터베이스에서 명령 순위를 불러옵니다.
```
