Vulcan Code 0.1.17 verringert Ruckler in langen Unterhaltungen weiter und korrigiert das Denkfenster beim Wechsel der Unterhaltung.

### Verbesserungen für Unterhaltungen

```ui-checklist
ok | Flüssigere lange Unterhaltungen | Lange Unterhaltungen laufen flüssiger. Gestreamte Antworten, das Live-Denkfenster, Zeitmesser und Statusanzeigen aktualisieren nur die Bereiche, die sich ändern.
ok | Denkfenster beim Wechsel der Unterhaltung | Beim Wechsel der Unterhaltung zeigt das Denkfenster nicht mehr kurz den Text aus einer anderen Unterhaltung an.
```
