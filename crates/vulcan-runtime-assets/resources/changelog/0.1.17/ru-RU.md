В Vulcan Code 0.1.17 уменьшено подтормаживание в длинных диалогах и исправлено окно рассуждений при переключении между диалогами.

### Улучшения в диалогах

```ui-checklist
ok | Плавная работа в длинных диалогах | Снижено подтормаживание в длинных диалогах. Потоковые ответы, окно рассуждений в реальном времени, таймеры и индикаторы состояния обновляют только те части интерфейса, которые меняются.
ok | Окно рассуждений при переключении диалогов | Исправлено кратковременное появление текста рассуждений из другого диалога во всплывающем окне при переключении между диалогами.
```
