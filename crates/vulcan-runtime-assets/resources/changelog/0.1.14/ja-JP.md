### デスクトップとセッション

- **macOS デスクトップ** — アプリバンドル、Dock、メニューバーに Vulcan Code の名前とアイコンが表示されます。macOS 標準のウィンドウボタンをタイトルバーに配置し、タイトルバーのダブルクリックで標準のフルスクリーンを切り替えられます。
- **セッションの未読表示** — バックグラウンドのセッションが完了すると未読マークが付き、再起動後も残ります。ウィンドウが非表示または非アクティブな間に選択中のセッションが完了した場合も、ウィンドウを再操作するまで未読マークが表示されます。
- **ストリーミング状態** — リクエストやターンの終了時に残っていた推論ポップアップを閉じ、再接続後にストリーミング状態を復元します。
- **ツール呼び出しと選択カード** — ツール呼び出しが多くても既存の見出し幅に収まります。Web とターミナルの両方で、アスタリスク直後に空白がない推奨項目や、選択肢から始まるカードを認識します。

### コンテキストと使用量

- **コンテキスト圧縮** — 圧縮リクエストに元のターンと同じツール一覧を含めることで、プロンプトキャッシュ対応のプロバイダーがキャッシュ済みの先頭部分を再利用できます。
- **使用量統計** — トークン合計と参考費用の見積もりを修正し、一部の使用量だけに基づく見積もりには印を付けます。読み込み中に統計が更新された場合は、一度再読み込みします。
