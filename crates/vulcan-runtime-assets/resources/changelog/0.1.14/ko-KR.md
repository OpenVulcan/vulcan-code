Vulcan Code 0.1.14에서는 macOS 데스크톱과 세션의 읽지 않음 표시를 개선하고 컨텍스트 압축과 사용량 통계를 수정했습니다.

### 데스크톱과 세션

```ui-checklist
ok | macOS 데스크톱 | 앱 번들, Dock, 메뉴 막대에 Vulcan Code 이름과 아이콘이 표시됩니다. 기본 창 제어 버튼을 제목 표시줄에 배치했으며, 제목 표시줄을 두 번 클릭하면 macOS 전체 화면이 전환됩니다.
ok | 읽지 않은 세션 | 백그라운드 세션이 완료되면 읽지 않음 표시가 나타나고 재시작 후에도 유지됩니다. 창이 숨겨져 있거나 포커스를 잃은 동안 선택한 세션이 완료되면, 창을 다시 조작할 때까지 읽지 않음 표시가 나타납니다.
ok | 스트리밍 상태 | 요청이나 턴이 끝나면 남아 있던 추론 팝업을 닫고 재연결 후 스트리밍 상태를 복원합니다.
ok | 도구 호출과 선택 카드 | 긴 도구 호출 목록도 기존 헤더 너비에 맞게 표시됩니다. 웹과 터미널 클라이언트에서 별표 뒤에 공백이 없는 추천 항목과 선택지로 바로 시작하는 카드를 인식합니다.
```

### 컨텍스트와 사용량

```ui-checklist
ok | 컨텍스트 압축 | 압축 요청에 원래 턴의 도구 목록을 포함하여 프롬프트 캐시를 지원하는 공급자가 캐시된 앞부분을 재사용할 수 있게 했습니다.
ok | 사용량 통계 | 토큰 합계와 참고용 비용 추정치를 수정하고 일부 사용량만 반영된 추정치를 표시합니다. 조회 도중 통계가 변경되면 대시보드가 한 번 다시 조회합니다.
```
