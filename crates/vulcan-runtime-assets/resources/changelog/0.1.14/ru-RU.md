В Vulcan Code 0.1.14 улучшены интерфейс macOS и отметки о непрочитанных сеансах, исправлены сжатие контекста и статистика использования.

### Приложение и сеансы

```ui-checklist
ok | Приложение для macOS | Пакет приложения, Dock и строка меню используют название и значок Vulcan Code. Системные кнопки окна размещены в строке заголовка. Двойной щелчок по ней переключает полноэкранный режим macOS.
ok | Непрочитанные сеансы | После завершения фонового сеанса появляется отметка о непрочитанном, которая сохраняется после перезапуска. Такая же отметка появляется у выбранного сеанса, если он завершился при скрытом или неактивном окне. Она сохраняется до следующего действия в окне.
ok | Состояние потока | Веб-интерфейс закрывает оставшиеся окна рассуждений по завершении запроса или хода и восстанавливает состояние потока после переподключения.
ok | Вызовы инструментов и карточки выбора | Длинные последовательности вызовов помещаются в пределах заголовка. Веб-клиент и терминальный клиент распознают рекомендуемые варианты без пробела после звёздочки и карточки, которые начинаются сразу с вариантов.
```

### Контекст и использование

```ui-checklist
ok | Сжатие контекста | Запросы на сжатие сохраняют список инструментов исходного хода, чтобы провайдеры с кешированием промптов могли повторно использовать уже сохранённый префикс.
ok | Статистика использования | Исправлены суммы токенов и оценки ориентировочной стоимости. Оценки по неполным данным отмечаются отдельно. Если статистика обновляется во время чтения, панель повторяет запрос один раз.
```
