Vulcan Code 0.1.14 改善 macOS 桌面介面和工作階段未讀提示，並修正上下文壓縮與用量統計。

### 桌面與工作階段

```ui-checklist
ok | macOS 桌面 | 應用程式套件、Dock 和選單列使用 Vulcan Code 的名稱和圖示。原生視窗按鈕移至標題列，按兩下標題列可切換原生全螢幕。
ok | 工作階段未讀提示 | 背景工作階段完成時會亮起未讀圓點，重新啟動後仍會保留。視窗失去焦點或隱藏時，當前工作階段完成亦會顯示未讀提示，直至你回到視窗操作。
ok | 串流狀態 | 請求或回合結束後關閉殘留的思考彈出視窗，重新連線後恢復工作階段的串流狀態。
ok | 工具呼叫與選項卡片 | 較長的工具呼叫序列會以緊湊方式顯示，避免撐闊標題。網頁端與終端機端均能辨識星號後沒有空格的建議選項，以及直接從選項開始的決策卡片。
```

### 上下文與用量

```ui-checklist
ok | 上下文壓縮 | 壓縮請求沿用原回合的工具清單，讓支援提示快取的供應商可重用快取。
ok | 用量統計 | 修正 Token 總數與參考費用合計，標示只涵蓋部分用量的估算。讀取期間統計更新時，會自動重讀一次以取得一致的結果。
```
