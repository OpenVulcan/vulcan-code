Vulcan Code 0.1.14 改进 macOS 桌面界面和会话未读提示，并修正上下文压缩与用量统计。

### 桌面与会话

```ui-checklist
ok | macOS 桌面 | 应用包、程序坞和菜单栏使用 Vulcan Code 的名称和图标。原生窗口按钮移到标题栏，双击标题栏可切换原生全屏。
ok | 会话未读提示 | 后台会话完成时会点亮未读圆点，重启后仍保留。窗口失焦或隐藏时，当前会话完成也会显示未读提示，直到你回到窗口操作。
ok | 流式状态 | 请求或回合结束后关闭残留的思考弹窗，重连后恢复会话的流式状态。
ok | 工具调用与选项卡片 | 长工具调用序列会压缩显示，避免撑宽标题。网页端和终端端都能识别星号后没有空格的推荐选项，以及直接从选项开始的决策卡片。
```

### 上下文与用量

```ui-checklist
ok | 上下文压缩 | 压缩请求沿用原回合的工具列表，让支持提示缓存的供应商能够复用缓存。
ok | 用量统计 | 修正总 Token 数与参考费用合计，标明用量只覆盖一部分的估算。读取期间统计更新时，自动重读一次以取得一致的结果。
```
