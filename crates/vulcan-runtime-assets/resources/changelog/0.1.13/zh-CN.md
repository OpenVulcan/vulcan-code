Vulcan Code 0.1.13 修复了 Intel Mac 上的内置浏览器、提示不再自动消失，以及安装运行时重复下载同一文件的问题。

### 更新到此版本

```ui-checklist
ok | 增量更新 | 从 0.1.8 至 0.1.12 更新时只下载有变化的文件
```

### 界面

```ui-checklist
ok | 提示恢复自动消失 | 用提示自身的关闭或操作按钮关掉一条提示后，之后的每条提示都会一直停留、只能手动关闭；现在它们重新按时自动消失
ok | Intel Mac 内置浏览器 | 0.1.12 的 macOS Intel（x64）版本误带了 Apple 芯片版浏览器，无法在 Intel Mac 上运行；此版本改为 Intel 版浏览器，并且每个 macOS 版本在发布前都会检查其中所有程序是否与处理器架构一致
```

### 运行时

```ui-checklist
ok | 复用已下载的运行时 | 安装或重新安装 uv、Node.js 与 pnpm 时，之前下载且仍通过校验的安装包直接复用，不再重新下载
```
