Vulcan Code 0.1.13 では、Intel Mac の内蔵ブラウザー、通知が自動で消えなくなる問題、およびランタイムのインストール時に同じファイルを再ダウンロードする問題を修正しました。

### このバージョンへの更新

```ui-checklist
ok | 差分更新 | 0.1.8 から 0.1.12 までのバージョンからは、変更されたファイルだけをダウンロードします
```

### インターフェース

```ui-checklist
ok | 通知が再び自動で消えます | 通知自身の閉じるボタンや操作ボタンで通知を閉じると、その後の通知がすべて手動で閉じるまで残り続けていました。再び自動で消えるようになりました
ok | Intel Mac の内蔵ブラウザー | 0.1.12 の macOS Intel（x64）版には Intel Mac で動作しない Apple シリコン版のブラウザーが含まれていました。本バージョンでは Intel 版のブラウザーを同梱し、すべての macOS 版で含まれるプログラムがプロセッサーと一致するかを検査するようにしました
```
