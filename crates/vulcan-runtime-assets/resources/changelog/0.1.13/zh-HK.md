Vulcan Code 0.1.13 修正了 Intel Mac 上的內置瀏覽器、通知不再自動消失，以及安裝運行環境時重複下載相同檔案的問題。

### 更新至此版本

```ui-checklist
ok | 增量更新 | 由 0.1.8 至 0.1.12 更新時只下載有變更的檔案
```

### 介面

```ui-checklist
ok | 通知恢復自動消失 | 用通知本身的關閉或操作按鈕關閉一則通知後，之後的每則通知都會一直停留、只能手動關閉；現在它們重新按時自動消失
ok | Intel Mac 內置瀏覽器 | 0.1.12 的 macOS Intel（x64）版本誤帶了 Apple 晶片版瀏覽器，無法在 Intel Mac 上運行；此版本改為 Intel 版瀏覽器，而且每個 macOS 版本在發佈前都會檢查其中所有程式是否與處理器架構一致
```

### 運行環境

```ui-checklist
ok | 重用已下載的運行環境 | 安裝或重新安裝 uv、Node.js 與 pnpm 時，之前下載而仍通過校驗的安裝檔直接重用，不再重新下載
```
