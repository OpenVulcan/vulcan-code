В Vulcan Code 0.1.13 исправлены встроенный браузер на Mac с Intel, уведомления, которые перестали закрываться сами, и установка сред выполнения, при которой те же файлы скачивались заново.

### Обновление до этой версии

```ui-checklist
ok | Инкрементное обновление | При обновлении с версий 0.1.8–0.1.12 скачиваются только изменённые файлы
```

### Интерфейс

```ui-checklist
ok | Уведомления снова закрываются сами | После закрытия уведомления его собственной кнопкой закрытия или действия все последующие уведомления оставались на экране до закрытия вручную; теперь они снова исчезают сами
ok | Встроенный браузер на Mac с Intel | Сборка 0.1.12 для macOS Intel (x64) содержала браузер для Apple silicon, который не работает на Mac с Intel; эта версия поставляется с браузером для Intel, а каждая сборка для macOS теперь проверяется на соответствие всех программ её процессору
```

### Среды выполнения

```ui-checklist
ok | Повторное использование загрузок | При установке или переустановке uv, Node.js или pnpm ранее скачанный архив используется повторно, если он по-прежнему проходит проверку контрольной суммы, а не скачивается заново
```
