Vulcan Code 0.1.13은 Intel Mac의 내장 브라우저, 알림이 저절로 사라지지 않던 문제, 런타임 설치 시 같은 파일을 다시 내려받던 문제를 수정합니다.

### 이 버전으로 업데이트

```ui-checklist
ok | 증분 업데이트 | 0.1.8부터 0.1.12까지의 버전에서는 변경된 파일만 내려받습니다
```

### 인터페이스

```ui-checklist
ok | 알림이 다시 저절로 사라짐 | 알림 자체의 닫기 또는 작업 버튼으로 알림을 닫으면 이후의 모든 알림이 직접 닫을 때까지 화면에 남아 있었습니다. 이제 다시 저절로 사라집니다
ok | Intel Mac 내장 브라우저 | 0.1.12의 macOS Intel(x64) 빌드에는 Intel Mac에서 실행할 수 없는 Apple 실리콘용 브라우저가 들어 있었습니다. 이번 버전은 Intel용 브라우저를 포함하며, 모든 macOS 빌드에서 포함된 프로그램이 프로세서와 일치하는지 검사합니다
```

### 런타임

```ui-checklist
ok | 내려받은 런타임 재사용 | uv, Node.js, pnpm을 설치하거나 다시 설치할 때 이전에 내려받아 체크섬 검증을 통과한 압축 파일을 다시 내려받지 않고 재사용합니다
```
