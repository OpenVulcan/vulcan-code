Vulcan Code 0.1.6 では、Linux での更新後の再起動とアプリの再起動を修正し、起動に失敗したデスクトップウィンドウを閉じられるようにしました。インストール全体を対話式インストーラーで行うセットアップ 0.2.8 も同梱しています。

### デスクトップ

```ui-checklist
ok | 起動の失敗 | 起動または画面の読み込みに失敗すると、Windows と Linux ではウィンドウに再読み込みと閉じるボタンが表示され、ウィンドウを閉じられます
ok | 使用中のデータディレクトリ | 別のプロセスがデータディレクトリを使用したまま応答しない場合、起動画面で vulcan-code-service のプロセスを終了してアプリを開き直すよう案内します
```

### Linux

```ui-checklist
ok | 更新後の再起動 | 更新後すぐに Core が再起動し、デスクトップアプリは 2 分待たずに新しいバージョンで開きます
ok | 再度開く | 終了中にアプリを開くと、何も起きないのではなくもう一度起動します。デスクトップアプリの補助プロセスも残らなくなりました
ok | Dock のアイコン | セットアップ 0.2.8 が書き込むメニュー項目がデスクトップアプリのウィンドウと一致し、Dock に固定したアイコンがアプリに対応します。既存のメニュー項目はセットアップの更新を一度実行すると書き直されます
```

### 修正

```ui-checklist
ok | プロバイダーのエラー | 応答の途中でプロバイダーがエラーを報告したとき、応答項目が未完了という通知ではなく、プロバイダー自身のメッセージを表示します（OpenAI Chat と Anthropic プロトコル）
```

### セットアップ

```ui-checklist
ok | 対話式インストーラー | ウィザードの後の確認、ダウンロードの進捗と結果も対話式インストーラー内に表示され、画面の言語で表示されます。更新でも同様です
ok | 正確なダウンロード量 | 確認画面に正確なダウンロード量を表示します。既にあるファイルは重ねて数えません
ok | 次回の使い方 | 最後の画面で、後から変更・更新・アンインストールする方法と、セットアップがまず自身を更新することを説明します
ok | キャンセル | 確認画面で戻るかキャンセルすると、何も変更せずに静かに終了します
ok | インストールスクリプト | インストールスクリプトはダウンロード元と進捗を表示し、30 秒データが届かないと別のサーバーに切り替えます
```
