Vulcan Code 0.1.6 修正了 Linux 上更新後的重新啟動與再次開啟應用程式，啟動失敗的桌面視窗可以關閉，並隨附安裝程式 0.2.8：整個安裝過程都在互動式安裝介面中完成。

### 桌面版

```ui-checklist
ok | 啟動失敗 | 啟動或介面載入失敗時，Windows 與 Linux 上的視窗顯示重新載入與關閉按鈕，視窗可以正常關閉
ok | 資料目錄被佔用 | 資料目錄被另一個程序佔用且沒有回應時，啟動頁會提示結束 vulcan-code-service 程序後重新開啟應用程式
```

### Linux

```ui-checklist
ok | 更新重新啟動 | 更新後 Core 立即重新啟動，桌面版直接以新版本開啟，不再等候兩分鐘
ok | 再次開啟 | 應用程式正在關閉時再次開啟會重新啟動，不再沒有反應；桌面版的輔助程序不再殘留
ok | Dock 圖示 | 安裝程式 0.2.8 寫入的選單項目與桌面版視窗對應，固定到 Dock 的圖示屬於應用程式；現有選單項目執行一次安裝程式的更新即可重寫
```

### 修正

```ui-checklist
ok | 供應商錯誤 | 供應商在回答中途報告錯誤時，顯示其原始錯誤訊息，而不是「回答項目仍未結束」的提示（OpenAI Chat 與 Anthropic 協定）
```

### 安裝程式

```ui-checklist
ok | 互動式安裝介面 | 精靈之後的審閱、下載進度與結果都留在互動式安裝介面中，並使用介面語言；更新同樣如此
ok | 準確的下載量 | 審閱頁顯示確切的下載量，已有的檔案不再重複計算
ok | 下次使用 | 最後一頁說明之後如何修改、更新或解除安裝，以及安裝程式會先自我更新
ok | 取消 | 在審閱頁返回或取消不會作任何更改，安靜結束
ok | 安裝指令碼 | 安裝指令碼顯示下載來源與進度，30 秒沒有資料時改用另一部伺服器
```
