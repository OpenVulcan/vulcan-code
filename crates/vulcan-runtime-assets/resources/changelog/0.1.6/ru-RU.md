В Vulcan Code 0.1.6 исправлены перезапуск после обновления и повторное открытие приложения в Linux, окно приложения с неудавшимся запуском теперь можно закрыть, а в комплекте идёт установщик 0.2.8, который проводит всю установку в интерактивном установщике.

### Приложение

```ui-checklist
ok | Сбой запуска | Если запуск или загрузка интерфейса не удались, окно в Windows и Linux показывает кнопки перезагрузки и закрытия, поэтому его можно закрыть
ok | Занятый каталог данных | Если другой процесс держит каталог данных и не отвечает, страница запуска предлагает завершить процессы vulcan-code-service и снова открыть приложение
```

### Linux

```ui-checklist
ok | Перезапуск после обновления | После обновления Core перезапускается сразу; приложение открывается в новой версии без двухминутного ожидания
ok | Повторное открытие | Открытие приложения во время его закрытия запускает его снова, а не ничего не делает; вспомогательные процессы приложения больше не остаются
ok | Значок в доке | Пункт меню из установщика 0.2.8 соответствует окну приложения, поэтому закреплённый в доке значок относится к нему; однократное обновление через установщик перезаписывает существующий пункт
```

### Исправления

```ui-checklist
ok | Ошибки поставщика | Если поставщик сообщает об ошибке посреди ответа, показывается его собственное сообщение, а не уведомление о незакрытом элементе ответа (протоколы OpenAI Chat и Anthropic)
```

### Установщик

```ui-checklist
ok | Интерактивный установщик | После мастера сводка, ход загрузки и результат остаются в интерактивном установщике на языке интерфейса; обновления тоже идут в нём
ok | Точный объём загрузки | Сводка показывает точный объём загрузки; уже имеющиеся файлы повторно не учитываются
ok | В следующий раз | Последняя страница объясняет, как позже изменить, обновить или удалить установку, и что установщик сначала обновляет сам себя
ok | Отмена | Возврат или отмена на странице сводки ничего не меняют и завершаются без ошибки
ok | Скрипты установки | Скрипты установки показывают источник и ход загрузки и переходят на другой сервер, если данных нет 30 секунд
```
