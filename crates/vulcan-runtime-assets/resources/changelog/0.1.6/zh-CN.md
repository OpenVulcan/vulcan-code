Vulcan Code 0.1.6 修复了 Linux 上更新后的重启与再次打开应用，启动失败的桌面窗口可以关闭，并随附安装器 0.2.8：整个安装过程都在交互式安装界面中完成。

### 桌面端

```ui-checklist
ok | 启动失败 | 启动或界面加载失败时，Windows 与 Linux 上的窗口显示重新加载与关闭按钮，窗口可以正常关闭
ok | 数据目录被占用 | 数据目录被另一个进程占用且无响应时，启动页会提示结束 vulcan-code-service 进程后重新打开应用
```

### Linux

```ui-checklist
ok | 更新重启 | 更新后 Core 立即重启，桌面端直接以新版本打开，不再等待两分钟
ok | 再次打开 | 应用正在关闭时再次打开会重新启动，不再没有反应；桌面端的辅助进程不再残留
ok | 程序坞图标 | 安装器 0.2.8 写入的菜单项与桌面端窗口对应，固定到程序坞的图标归属于应用；已有菜单项运行一次安装器的更新即可重写
```

### 修复

```ui-checklist
ok | 供应商错误 | 供应商在回答中途报告错误时，显示其原始错误信息，而不是“回答项仍未结束”的提示（OpenAI Chat 与 Anthropic 协议）
```

### 安装程序

```ui-checklist
ok | 交互式安装界面 | 向导之后的审阅、下载进度与结果都留在交互式安装界面中，并使用界面语言；更新同样如此
ok | 准确的下载量 | 审阅页显示确切的下载量，已有的文件不再重复计算
ok | 下次使用 | 最后一页说明以后如何修改、更新或卸载，以及安装器会先自我更新
ok | 取消 | 在审阅页返回或取消不会做任何改动，安静结束
ok | 安装脚本 | 安装脚本显示下载来源与进度，30 秒无数据时改用另一台服务器
```
