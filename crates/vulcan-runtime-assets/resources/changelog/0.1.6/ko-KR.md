Vulcan Code 0.1.6은 Linux에서 업데이트 후 재시작과 앱 다시 열기를 수정하고, 시작에 실패한 데스크톱 창을 닫을 수 있게 했습니다. 설치 전체를 대화형 설치 화면에서 진행하는 설치 프로그램 0.2.8도 함께 제공됩니다.

### 데스크톱

```ui-checklist
ok | 시작 실패 | 시작이나 화면 로드에 실패하면 Windows와 Linux에서 창에 다시 불러오기와 닫기 버튼이 표시되어 창을 닫을 수 있습니다
ok | 사용 중인 데이터 디렉터리 | 다른 프로세스가 데이터 디렉터리를 사용 중이면서 응답하지 않으면, 시작 화면에서 vulcan-code-service 프로세스를 종료한 뒤 앱을 다시 열도록 안내합니다
```

### Linux

```ui-checklist
ok | 업데이트 후 재시작 | 업데이트 후 Core가 바로 재시작되고, 데스크톱 앱은 2분을 기다리지 않고 새 버전으로 열립니다
ok | 다시 열기 | 앱이 종료되는 중에 다시 열면 아무 반응이 없는 대신 다시 시작됩니다. 데스크톱 앱의 보조 프로세스도 더 이상 남지 않습니다
ok | Dock 아이콘 | 설치 프로그램 0.2.8이 만드는 메뉴 항목이 데스크톱 앱 창과 일치하여 Dock에 고정한 아이콘이 앱에 속합니다. 기존 메뉴 항목은 설치 프로그램의 업데이트를 한 번 실행하면 다시 작성됩니다
```

### 수정

```ui-checklist
ok | 제공자 오류 | 응답 도중 제공자가 오류를 보고하면, 응답 항목이 아직 열려 있다는 안내 대신 제공자의 원래 메시지를 표시합니다(OpenAI Chat 및 Anthropic 프로토콜)
```

### 설치 프로그램

```ui-checklist
ok | 대화형 설치 화면 | 마법사 이후의 검토, 다운로드 진행률과 결과도 대화형 설치 화면에 화면 언어로 표시됩니다. 업데이트도 마찬가지입니다
ok | 정확한 다운로드 크기 | 검토 화면에 정확한 다운로드 크기를 표시하며, 이미 있는 파일은 다시 계산하지 않습니다
ok | 다음 사용 | 마지막 화면에서 나중에 설치를 변경, 업데이트, 제거하는 방법과 설치 프로그램이 먼저 스스로 업데이트한다는 점을 알려 줍니다
ok | 취소 | 검토 화면에서 뒤로 가거나 취소하면 아무것도 바꾸지 않고 조용히 끝납니다
ok | 설치 스크립트 | 설치 스크립트가 다운로드 출처와 진행률을 표시하고, 30초 동안 데이터가 없으면 다른 서버로 바꿉니다
```
