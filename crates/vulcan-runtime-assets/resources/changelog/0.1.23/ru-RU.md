В Vulcan Code 0.1.23 появилась защищённая очистка истории, улучшен встроенный браузер и исправлена загрузка поставляемых модулей Lua в Linux и macOS.

### Обновление до этой версии

```ui-checklist
ok | Установщик 0.2.12 | Скрипт запускает уже установленную программу, которая автоматически обновляется и перезапускается. В Linux и macOS добавление в PATH делает команды доступными в новых терминалах. Установка из командной строки показывает команды управления службой и порты WebUI.
```

### Беседы

```ui-checklist
ok | Быстрая очистка истории | В неактивной обычной беседе после сжатия контекста выберите границу очистки через меню добавления или команду `/clean-history`. Подробности старых вызовов инструментов и записи рассуждений удаляются. Упрощённые вопросы и ответы остаются в ленте, а нужная беседе история защищена.
ok | Прокрутка длинных бесед | Потоковый Markdown обновляется независимо. При загрузке предыдущих шагов и очищенной истории лента сохраняет текущую позицию чтения.
```

### Встроенный браузер

```ui-checklist
ok | Отображение страниц | WebUI отображает структуру страниц встроенного браузера вместо прежнего потока снимков экрана.
ok | Размер области просмотра | Выберите настольный, портретный или альбомный режим, задайте свой размер или одним действием подгоните область просмотра под текущее окно.
```

### Рабочая область и среда выполнения

```ui-checklist
ok | База знаний | В новой боковой панели база знаний закреплена по умолчанию. Сохранённая раскладка имеет приоритет.
ok | Среда Lua в macOS | Исправлена загрузка встроенных нативных модулей Lua на компьютерах Mac с Intel и Apple Silicon. Context7 инициализирует локальное хранилище при первом открытии настроек.
ok | Среда Lua в Linux | Встроенные нативные модули Lua, включая OpenSSL, теперь загружаются на ARM64 и x64. При сборке пакетов проверяется совместимость с glibc 2.35.
```
