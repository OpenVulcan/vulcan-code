Vulcan Code 0.1.23 新增受保護的對話歷史清理，改善內建瀏覽器，並修正 Linux 與 macOS 隨附 Lua 原生模組的載入。

### 更新至此版本

```ui-checklist
ok | 安裝程式 0.2.12 | 安裝指令碼會沿用現有安裝程式，由安裝程式自動更新並重新啟動。Linux 與 macOS 選擇加入 PATH 後，新終端機可直接使用指令。純命令列安裝完成後會顯示服務管理指令與 WebUI 連接埠。
```

### 對話

```ui-checklist
ok | 快速清理歷史 | 完成脈絡壓縮且閒置的一般對話，可從輸入區的加號選單或使用 `/clean-history` 選擇清理到哪一輪。清理會移除舊的工具詳情與思考記錄，時間軸仍顯示簡化問答，並保護對話仍需使用的歷史。
ok | 長對話捲動 | 串流 Markdown 會獨立更新正文。載入更早的回合或已清理的簡化歷史時，時間軸會保留目前的閱讀位置。
```

### 內建瀏覽器

```ui-checklist
ok | 網頁算繪 | WebUI 根據內建瀏覽器的頁面結構算繪網頁，取代原先的截圖串流。
ok | 檢視區大小 | 可選擇桌面、直向或橫向預設，也可輸入自訂大小，或一鍵配合目前視窗。
```

### 工作區與執行環境

```ui-checklist
ok | 知識庫入口 | 新的側邊欄配置預設釘選「知識庫」，已儲存的配置優先。
ok | macOS Lua 執行環境 | 修正 Intel Mac 與 Apple 晶片 Mac 的隨附 Lua 原生模組載入。首次開啟 Context7 設定時會初始化本機儲存空間。
ok | Linux Lua 執行環境 | 修正 ARM64 與 x64 上隨附 Lua 原生模組（如 OpenSSL）的載入。發行封裝時會檢查檔案是否相容於 glibc 2.35。
```
