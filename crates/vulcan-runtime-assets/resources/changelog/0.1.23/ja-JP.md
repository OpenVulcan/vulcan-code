Vulcan Code 0.1.23 では、会話履歴の保護付き整理を追加し、内蔵ブラウザーを改善しました。macOS の同梱 Lua モジュールも修正しています。

### 会話

```ui-checklist
ok | 履歴のクイック整理 | コンテキスト圧縮が済んだ待機中の通常会話で、入力欄の追加メニューか `/clean-history` から整理する範囲を選べます。古いツールの詳細と思考記録を削除し、簡略化した質問と回答はタイムラインに残します。会話に必要な履歴は保護されます。
ok | 長い会話のスクロール | ストリーミング中の Markdown 本文を個別に更新します。古いターンや整理済みの履歴を読み込んでも、現在の閲覧位置を保ちます。
```

### 内蔵ブラウザー

```ui-checklist
ok | ページ描画 | WebUI はスクリーンショットの配信に代わり、内蔵ブラウザーのページ構造から表示を描画します。
ok | ビューポートのサイズ | デスクトップ、縦向き、横向きのプリセットに加え、サイズ指定や現在のウィンドウに一度で合わせる操作が使えます。
```

### ワークスペースと macOS

```ui-checklist
ok | ナレッジベース | 新しいサイドバーでは既定でナレッジベースを固定します。保存済みの配置が優先されます。
ok | macOS の Lua ランタイム | Intel Mac と Apple シリコン Mac で同梱の Lua ネイティブモジュールを読み込めるように修正しました。Context7 は設定を初めて開いたときにローカルストレージを初期化します。
```
