Vulcan Code 0.1.23 新增带保护的会话历史清理，改进内置浏览器，并修复 macOS 随包 Lua 原生模块的加载。

### 会话

```ui-checklist
ok | 快速清理历史 | 已完成上下文压缩且空闲的普通会话，可从输入区加号菜单或用 `/clean-history` 选择清理到哪一轮。清理会移除旧工具详情和思考记录，时间线仍显示简化问答，会话仍需使用的历史受保护。
ok | 长会话滚动 | 流式 Markdown 单独更新正文。加载更早的回合或已清理的简化历史时，时间线会保持当前阅读位置。
```

### 内置浏览器

```ui-checklist
ok | 网页渲染 | WebUI 根据内置浏览器的页面结构渲染网页，替代原来的截图串流。
ok | 视口尺寸 | 支持桌面、竖屏、横屏预设和自定义尺寸，也可一键适配当前窗口。
```

### 工作区与 macOS

```ui-checklist
ok | 知识库入口 | 新的侧栏布局默认固定「知识库」，已有布局按保存的设置显示。
ok | macOS Lua 运行时 | 修复 Intel Mac 和 Apple 芯片 Mac 上随包 Lua 原生模块的加载。Context7 首次打开设置时会初始化本地存储。
```
