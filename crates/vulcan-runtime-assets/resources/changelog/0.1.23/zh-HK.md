Vulcan Code 0.1.23 新增受保護的對話歷史清理，改善內置瀏覽器，並修正 Linux 和 macOS 隨附 Lua 原生模組的載入。

### 更新至此版本

```ui-checklist
ok | 安裝程式 0.2.12 | 安裝腳本會沿用現有安裝程式，由安裝程式自動更新並重新啟動。Linux 和 macOS 選擇加入 PATH 後，新終端可直接使用指令。純命令列安裝完成後會顯示服務管理指令和 WebUI 連接埠。
```

### 對話

```ui-checklist
ok | 快速清理歷史 | 完成上下文壓縮並處於閒置狀態的一般對話，可從輸入區加號選單或用 `/clean-history` 選擇清理至哪一輪。清理會移除舊工具詳情及思考記錄，時間線仍顯示簡化問答，並保護對話仍需使用的歷史。
ok | 長對話捲動 | 串流 Markdown 會獨立更新正文。載入較早的回合或已清理的簡化歷史時，時間線會保留目前閱讀位置。
```

