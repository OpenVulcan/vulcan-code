Vulcan Code 0.1.23 新增受保護的對話歷史清理，改善內置瀏覽器，並修正 macOS 隨附 Lua 原生模組的載入。

### 對話

```ui-checklist
ok | 快速清理歷史 | 完成上下文壓縮並處於閒置狀態的一般對話，可從輸入區加號選單或用 `/clean-history` 選擇清理至哪一輪。清理會移除舊工具詳情及思考記錄，時間線仍顯示簡化問答，並保護對話仍需使用的歷史。
ok | 長對話捲動 | 串流 Markdown 會獨立更新正文。載入較早的回合或已清理的簡化歷史時，時間線會保留目前閱讀位置。
```

### 內置瀏覽器

```ui-checklist
ok | 網頁呈現 | WebUI 根據內置瀏覽器的頁面結構呈現網頁，取代原有的截圖串流。
ok | 視口尺寸 | 可選桌面、直向或橫向預設，亦可自訂尺寸，或一鍵配合目前視窗。
```

### 工作區與 macOS

```ui-checklist
ok | 知識庫入口 | 新的側欄版面預設固定「知識庫」，已儲存的版面優先。
ok | macOS Lua 執行環境 | 修正 Intel Mac 和 Apple 晶片 Mac 的隨附 Lua 原生模組載入。首次開啟 Context7 設定時會初始化本機儲存。
```
