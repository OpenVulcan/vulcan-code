Vulcan Code 0.1.23은 보호 기능이 적용된 대화 기록 정리를 추가하고, 내장 브라우저를 개선하며, macOS의 번들 Lua 모듈 문제를 수정합니다.

### 대화

```ui-checklist
ok | 기록 빠른 정리 | 컨텍스트 압축을 마친 유휴 상태의 일반 대화에서 입력창의 추가 메뉴 또는 `/clean-history`로 정리 범위를 선택할 수 있습니다. 오래된 도구 상세 정보와 추론 기록을 제거하고, 간략한 질문과 답변은 타임라인에 남깁니다. 대화에 필요한 기록은 보호됩니다.
ok | 긴 대화 스크롤 | 스트리밍 Markdown 본문을 독립적으로 갱신합니다. 이전 턴이나 정리된 기록을 불러와도 현재 읽는 위치를 유지합니다.
```

### 내장 브라우저

```ui-checklist
ok | 페이지 렌더링 | WebUI는 스크린샷 스트리밍 대신 내장 브라우저의 페이지 구조를 사용해 웹페이지를 렌더링합니다.
ok | 뷰포트 크기 | 데스크톱, 세로, 가로 프리셋이나 사용자 지정 크기를 선택할 수 있으며, 현재 창 크기에 한 번에 맞출 수도 있습니다.
```

### 작업 공간 및 macOS

```ui-checklist
ok | 지식 베이스 | 새 사이드바에서는 기본으로 지식 베이스를 고정합니다. 저장된 배치가 있으면 그 설정을 적용합니다.
ok | macOS Lua 런타임 | Intel 및 Apple Silicon Mac에서 번들 Lua 네이티브 모듈 로딩을 수정했습니다. Context7 설정을 처음 열 때 로컬 저장소를 초기화합니다.
```
