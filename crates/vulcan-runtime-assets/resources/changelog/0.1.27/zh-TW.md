Vulcan Code 0.1.27 新增請求上下文面板，讓技能與外掛更容易按需呼叫，並改善子代理協作與 MCP 用戶端授權。

### 對話與工作區

```ui-checklist
ok | 檢視請求上下文 | 從對話選單開啟「請求上下文」，檢查最近請求使用的提示詞、訊息和工具定義。對話尚未送出請求時，面板會預覽目前組合的上下文。
ok | 子代理執行時繼續主要工作 | 子代理尚在執行時，主對話可處理優先訊息及已回傳的結果。回傳結果會納入後續請求。
ok | 捲動位置與請求耗時 | 向上捲動閱讀歷史時，串流更新會保留閱讀位置。重新開啟對話後，執行中的請求會從 Core 事件恢復計時。
```

### 技能、外掛與 MCP

```ui-checklist
ok | 在輸入框引用技能與外掛 | 輸入 `@` 可選取技能或專案路徑，輸入 `#` 可選取外掛。候選項目會顯示簡短名稱。
ok | 按需載入工具 | Vulcan Browser、Context7 和對話 MCP 連線管理可按需呼叫。LuaSkills 升級至 0.9.1，含指南的套件工具可切換為按需呼叫。
ok | 分組授權 MCP 用戶端 | 每個用戶端可分別授予對話、獨立工具和多模態權限。可逐項授權檔案、Shell、CodeKit 和知識庫工具，並限制專案或知識庫範圍。
```

### 安裝、模型與意見回饋

```ui-checklist
ok | 獨立安裝程式 0.2.18 | 首次安裝時會測速並推薦回應較快的下載線路，可手動改選。LuaSkills Hub 和 GitHub 下載來源隨安裝線路設定。
ok | LuaSkills 啟動診斷 | 啟動畫面顯示本地化的相依項目準備進度，並在安裝失敗時指出失敗項目。
ok | 新增 Qwen4 Max | 阿里雲 Token Plan 模型清單現已提供正式版 Qwen4 Max。
ok | 意見回饋可附聯絡方式 | 送出意見時可選擇附上並預覽站外聯絡方式。公開回覆可在應用程式的訊息中心查看。
```
