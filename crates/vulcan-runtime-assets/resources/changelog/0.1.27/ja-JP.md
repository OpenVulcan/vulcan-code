Vulcan Code 0.1.27 では、リクエストのコンテキストを確認できるようになり、スキルやプラグインのオンデマンド呼び出し、サブエージェントとの連携、MCP クライアントの権限設定が改善されました。

### 会話とワークスペース

```ui-checklist
ok | リクエストのコンテキストを確認 | 会話メニューから直近のリクエストで使われたプロンプト、メッセージ、ツール定義を確認できます。会話でまだリクエストを送信していない場合は、組み立てられるコンテキストがプレビューされます。
ok | サブエージェントの実行中も作業を継続 | 親会話は、サブエージェントの実行中も優先メッセージや届いた結果を処理できます。結果は後続のリクエストに含まれます。
ok | スクロール位置と経過時間 | 履歴を読み返している間も、ストリーミング更新で表示位置がずれません。会話を開き直すと、実行中の経過時間が Core のイベントから復元されます。
```

### スキル、プラグイン、MCP

```ui-checklist
ok | 入力欄でスキルやプラグインを参照 | `@` でスキルやプロジェクト内のパスを、`#` でプラグインを選べます。候補には短い名前が表示されます。
ok | 必要に応じてツールを読み込む | Vulcan Browser、Context7、会話内の MCP 接続管理をオンデマンドで利用できます。LuaSkills 0.9.1 では、ガイド付きのパッケージツールをオンデマンド呼び出しに切り替えられます。
ok | MCP クライアントの権限をグループ別に設定 | 会話、独立ツール、マルチモーダルの権限をクライアントごとに設定できます。ファイル、シェル、CodeKit、ナレッジベースの各ツールを個別に許可し、プロジェクトやライブラリの範囲を指定できます。
```

ok | LuaSkills の起動時診断 | 依存関係の準備状況が選択言語で表示され、インストールに失敗した項目も確認できます。
