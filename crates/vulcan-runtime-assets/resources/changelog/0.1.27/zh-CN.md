Vulcan Code 0.1.27 新增请求上下文面板，让技能和插件更容易按需调用，并改进了子代理协作与 MCP 客户端授权。

### 会话与工作台

```ui-checklist
ok | 查看请求上下文 | 从会话菜单打开「请求上下文」，检查最近请求使用的提示词、消息和工具定义。会话还没有已发出的请求时，面板会预览当前组装的上下文。
ok | 子代理运行时继续主任务 | 子代理仍在执行时，主会话可处理插队输入和已返回的结果，回流内容会带入后续请求。
ok | 滚动位置与请求耗时 | 向上滚动阅读历史时，流式更新会保留阅读位置。重新打开会话后，正在运行的请求从 Core 事件恢复计时。
```

### 技能、插件与 MCP

```ui-checklist
ok | 在输入框引用技能和插件 | 输入 `@` 可选择技能或项目路径，输入 `#` 可选择插件。候选项会显示简短名称。
ok | 按需载入工具 | Vulcan Browser、Context7 和会话 MCP 的连接管理可按需调用。LuaSkills 升级到 0.9.1，带指南的包工具支持切换到按需调用。
ok | 按组授权 MCP 客户端 | 配置客户端时可分别授予会话、独立工具和多模态权限。文件、Shell、CodeKit 和知识库工具可逐项授权，也可限制项目和知识库范围。
```

### 安装、模型与反馈

```ui-checklist
ok | 独立安装器 0.2.18 | 首次安装时测速并推荐响应更快的下载线路，可手动改选。LuaSkills Hub 和 GitHub 下载源会随安装线路配置。
ok | LuaSkills 启动诊断 | 启动页显示本地化的依赖准备进度。依赖安装失败时会显示失败项，方便定位问题。
ok | 新增 Qwen4 Max | 阿里云 Token Plan 模型列表现已提供正式版 Qwen4 Max。
ok | 反馈可附联系方式 | 提交反馈时可以勾选并预览站外联系方式，也可以只通过站内消息接收公开回复。
```
