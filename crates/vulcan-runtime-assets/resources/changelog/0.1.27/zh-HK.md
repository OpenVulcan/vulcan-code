Vulcan Code 0.1.27 新增請求上下文面板，方便按需使用技能及插件，並改善子代理協作和 MCP 客戶端授權。

### 對話與工作區

```ui-checklist
ok | 檢視請求上下文 | 從對話選單開啟「請求上下文」，檢查最近請求使用的提示詞、訊息和工具定義。對話尚未送出請求時，面板會預覽目前組合的上下文。
ok | 子代理執行時繼續主工作 | 子代理仍在執行時，主對話可處理優先訊息和已返回的結果。返回的結果會納入後續請求。
ok | 捲動位置與請求耗時 | 向上捲動閱讀記錄時，串流更新會保留閱讀位置。重新開啟對話後，進行中的請求會按 Core 事件恢復計時。
```

### 技能、插件與 MCP

```ui-checklist
ok | 在輸入欄引用技能及插件 | 輸入 `@` 可選擇技能或專案路徑，輸入 `#` 可選擇插件。建議項目會顯示簡短名稱。
ok | 按需載入工具 | Vulcan Browser、Context7 及對話 MCP 連線管理可按需呼叫。LuaSkills 升級至 0.9.1，附指南的套件工具可切換為按需呼叫。
ok | 分組授權 MCP 客戶端 | 每個客戶端可分別授予對話、獨立工具和多模態權限。可逐項授權檔案、Shell、CodeKit 和知識庫工具，並限制專案或知識庫範圍。
```

### 安裝、模型與意見回饋

```ui-checklist
ok | 獨立安裝程式 0.2.18 | 首次安裝會測速並推薦回應較快的下載線路，亦可自行改選。LuaSkills Hub 和 GitHub 下載來源隨選定線路設定。
ok | LuaSkills 啟動診斷 | 啟動畫面顯示本地化的相依項目準備進度，並在安裝失敗時指出失敗項目。
ok | 新增 Qwen4 Max | 阿里雲 Token Plan 模型清單已提供正式版 Qwen4 Max。
ok | 回饋可附聯絡資料 | 提交回饋時可選擇附上及預覽站外聯絡資料。公開回覆可在應用程式的訊息中心查看。
```
