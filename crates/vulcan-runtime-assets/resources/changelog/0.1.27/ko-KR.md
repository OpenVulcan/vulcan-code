### 대화와 작업 공간

```ui-checklist
ok | 요청 컨텍스트 확인 | 대화 메뉴에서 최근 요청에 사용된 프롬프트, 메시지, 도구 정의를 확인하세요. 대화에서 아직 요청을 보내지 않았다면 구성할 컨텍스트가 미리 표시됩니다.
ok | 하위 에이전트가 실행 중일 때도 기본 작업 계속 | 상위 대화는 하위 에이전트가 실행되는 동안 우선 메시지와 도착한 결과를 처리할 수 있습니다. 반환된 결과는 이후 요청에 포함됩니다.
ok | 스크롤 위치와 요청 경과 시간 | 이전 메시지를 읽는 동안 스트리밍 업데이트가 읽던 위치를 유지합니다. 대화를 다시 열면 Core 이벤트를 바탕으로 실행 중인 요청의 경과 시간을 복원합니다.
```
