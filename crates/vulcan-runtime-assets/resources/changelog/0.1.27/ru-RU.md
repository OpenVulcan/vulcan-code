В Vulcan Code 0.1.27 можно просматривать контекст запросов и проще вызывать навыки и плагины по требованию. Также улучшены координация субагентов и настройка разрешений клиентов MCP.

### Диалоги и рабочая область

```ui-checklist
ok | Просмотр контекста запроса | Откройте контекст в меню диалога, чтобы изучить инструкции, сообщения и определения инструментов, использованные в последнем запросе. До отправки первого запроса показывается предварительный контекст, который будет собран для диалога.
ok | Продолжение основной задачи | Родительский диалог может обрабатывать приоритетные сообщения и полученные результаты, пока субагенты продолжают работу. Результаты включаются в последующие запросы.
ok | Позиция прокрутки и время выполнения | Потоковые обновления сохраняют позицию при чтении истории. При повторном открытии диалога время выполнения активного запроса восстанавливается по событиям Core.
```

### Навыки, плагины и MCP

```ui-checklist
ok | Ссылки на навыки и плагины в поле ввода | Введите `@`, чтобы выбрать навык или путь в проекте, и `#`, чтобы выбрать плагин. В подсказках отображаются короткие названия.
ok | Загрузка инструментов по требованию | Vulcan Browser, Context7 и управление подключениями MCP в диалоге доступны по требованию. В LuaSkills 0.9.1 инструменты пакетов с руководством можно перевести в этот режим.
ok | Разрешения клиентов MCP по группам | Настраивайте разрешения на диалоги, отдельные инструменты и мультимодальные функции для каждого клиента. Доступ к инструментам работы с файлами, оболочкой, CodeKit и базами знаний можно выдавать по одному и ограничивать проектами или библиотеками.
```

ok | Необязательные контактные данные | Перед отправкой отзыва можно добавить и проверить контактные данные. Публичные ответы доступны в центре сообщений приложения.
