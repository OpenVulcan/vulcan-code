В Vulcan Code 0.1.26 можно заново привязать недоступную папку проекта, сохранив сеансы. Также улучшены обновление приложения и отображение результатов инструментов.

### Проекты и сеансы

```ui-checklist
ok | Восстановление папки проекта | Если папку переместили или диск отключился, можно снова проверить исходный путь либо выбрать другую папку и сохранить историю сеансов. Изменение появится в истории разговора, а следующий запрос к модели будет использовать новую папку.
ok | Открытие подключённых дисков и введённых путей | В Linux и macOS окно выбора папки показывает подключённые тома. Введённый путь можно сначала открыть, а затем подтвердить выбор папки.
ok | Последнее сообщение при переключении разговора | При переходе в другой разговор открывается его последнее сообщение, чтобы можно было продолжить чтение.
```

### Установка и обновления

```ui-checklist
ok | Подготовка обновления перед перезапуском | Автоматическая загрузка включена по умолчанию. Приложение сообщает, когда обновление загружено и проверено, а переключение версии происходит после подтверждения перезапуска. Автоматическую загрузку можно отключить и обновляться вручную.
ok | Отдельный установщик 0.2.17 | Для Windows доступен подписанный графический установщик, для Linux — пакеты AppImage, для macOS — образ DMG. После установки через терминал в macOS команда `vcode manager gui` открывает графический менеджер. При первой установке LuaSkills выбирает международный Hub или Hub для материкового Китая в соответствии с маршрутом установки.
```

### Инструменты для браузера и документов

```ui-checklist
ok | Карточки действий браузера | Карточки Playwright показывают действие, цель и результат переходов, щелчков, снимков экрана и других операций. Встроенный навык Vulcan Browser описывает порядок действий и их проверки.
ok | Инструменты Vulcan Work для документов | Vulcan Code устанавливает Vulcan Work из выбранного LuaSkills Hub для работы с PDF, Word, Excel и PowerPoint. Отдельные карточки показывают файлы, диапазоны ячеек или результаты в зависимости от операции. Справка неявно зарегистрированных инструментов LuaSkills показывает, какие параметры принимает каждый инструмент.
```
