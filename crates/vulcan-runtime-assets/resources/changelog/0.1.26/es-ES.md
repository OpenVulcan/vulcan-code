Vulcan Code 0.1.26 permite volver a vincular la carpeta de un proyecto sin perder las sesiones y mejora las actualizaciones de la aplicación y la presentación de los resultados de las herramientas.

### Proyectos y sesiones

```ui-checklist
ok | Recuperar la carpeta de un proyecto | Si la carpeta se mueve o se desconecta una unidad, puedes comprobar de nuevo la ubicación original o elegir otra carpeta y conservar el historial de sesiones. El cambio aparece en la conversación y la siguiente solicitud al modelo usa la nueva carpeta.
ok | Explorar unidades montadas y rutas escritas | El selector de carpetas muestra los volúmenes montados en Linux y macOS. Si escribes una ruta, puedes abrirla antes de confirmar la selección.
ok | Abrir el mensaje más reciente al cambiar de conversación | Al cambiar de conversación se muestra el último mensaje para que puedas seguir leyendo desde donde lo dejaste.
```

### Instalación y actualizaciones

```ui-checklist
ok | Preparar las actualizaciones antes de reiniciar | Las descargas automáticas están activadas de forma predeterminada. La aplicación avisa cuando la actualización se ha descargado y verificado, y cambia de versión cuando confirmas el reinicio. Puedes desactivar las descargas automáticas y actualizar manualmente.
ok | Instalador independiente 0.2.17 | Windows dispone de un instalador gráfico firmado, Linux de paquetes AppImage y macOS de un DMG. Tras instalar desde el terminal en macOS, puedes abrir el gestor gráfico con `vcode manager gui`. En la primera instalación, LuaSkills selecciona el Hub de China continental o el internacional según la ruta de instalación.
```

### Herramientas de navegación y documentos

```ui-checklist
ok | Tarjetas de acciones del navegador | Las tarjetas de Playwright muestran la acción, el objetivo y el resultado de operaciones como navegar, hacer clic o tomar capturas. La habilidad Vulcan Browser incluida también guía las acciones y su verificación.
ok | Herramientas de documentos de Vulcan Work | Vulcan Code instala Vulcan Work desde el Hub de LuaSkills seleccionado para trabajar con PDF, Word, Excel y PowerPoint. Sus tarjetas muestran archivos, rangos de hojas de cálculo o resultados, según la operación. La ayuda de las herramientas de LuaSkills registradas de forma implícita también muestra los parámetros que acepta cada una.
```
