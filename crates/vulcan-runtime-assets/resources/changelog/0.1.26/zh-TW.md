Vulcan Code 0.1.26 可在專案資料夾失效後重新連結資料夾並保留工作階段，也改善了應用程式更新和工具結果的呈現方式。

### 專案與工作階段

```ui-checklist
ok | 復原專案資料夾 | 資料夾移動或磁碟中斷連線後，可以重新檢查原本的位置，或改選新資料夾並保留工作階段記錄。變更會顯示在對話時間軸，下次模型請求會使用新資料夾。
ok | 瀏覽掛載的磁碟與輸入的路徑 | Linux 與 macOS 的資料夾選擇器會列出已掛載的卷宗。輸入路徑後，可先開啟資料夾，再確認選取。
ok | 切換對話時開啟最新訊息 | 切換對話時會跳到最新訊息，方便接續閱讀。
```

### 安裝與更新

```ui-checklist
ok | 先準備更新，再選擇重新啟動 | 預設會自動下載。新版下載並通過驗證後會提示更新已就緒，確認重新啟動時才切換版本。也可關閉自動下載並手動更新。
ok | 獨立安裝程式 0.2.17 | Windows 提供已簽署的圖形安裝程式，Linux 提供 AppImage，macOS 提供 DMG。從 macOS 終端機安裝後，可用 `vcode manager gui` 開啟圖形管理工具。首次安裝時，LuaSkills 會依安裝路線選用中國大陸或國際 Hub。
```

### 瀏覽器與文件工具

```ui-checklist
ok | 瀏覽器操作卡片 | Playwright 的導覽、點擊和螢幕截圖等操作會顯示動作、目標和結果。內建 Vulcan Browser 技能也包含瀏覽器操作與驗證步驟。
ok | Vulcan Work 文件工具 | Vulcan Code 會從目前的 LuaSkills Hub 安裝 Vulcan Work，支援 PDF、Word、Excel 和 PowerPoint 操作。專用卡片會依操作顯示檔案、工作表範圍或結果。以隱式方式註冊的 LuaSkills 工具也會在說明中列出實際參數。
```
