O Vulcan Code 0.1.26 permite vincular novamente a pasta de um projeto sem perder as sessões e melhora as atualizações do aplicativo e a exibição dos resultados das ferramentas.

### Projetos e sessões

```ui-checklist
ok | Recupere a pasta de um projeto | Se uma pasta for movida ou uma unidade for desconectada, confira novamente a localização original ou escolha outra pasta e mantenha o histórico das sessões. A alteração aparece na linha do tempo da conversa, e a próxima solicitação ao modelo usa a nova pasta.
ok | Abra unidades montadas e caminhos digitados | O seletor de pastas lista os volumes montados no Linux e no macOS. Após digitar um caminho, você pode abrir a pasta antes de confirmar a seleção.
ok | Veja a mensagem mais recente ao trocar de conversa | Ao alternar para outra conversa, a mensagem mais recente é aberta para você continuar a leitura.
```

### Instalação e atualizações

```ui-checklist
ok | Prepare a atualização antes de reiniciar | Os downloads automáticos vêm ativados. O aplicativo avisa quando a atualização já foi baixada e verificada. A versão muda ao confirmar a reinicialização. Você também pode desligar os downloads automáticos e atualizar manualmente.
ok | Instalador independente 0.2.17 | O Windows tem um instalador gráfico assinado, o Linux tem pacotes AppImage e o macOS tem um DMG. Depois de instalar pelo terminal no macOS, use `vcode manager gui` para abrir o gerenciador gráfico. Na primeira instalação, o LuaSkills seleciona o Hub internacional ou o da China continental conforme a rota de instalação.
```

### Ferramentas de navegador e documentos

```ui-checklist
ok | Cartões de ações do navegador | Os cartões do Playwright mostram a ação, o alvo e o resultado de operações como navegação, cliques e capturas de tela. A habilidade Vulcan Browser incluída também fornece instruções para executar e verificar as ações.
ok | Ferramentas de documentos do Vulcan Work | O Vulcan Code instala o Vulcan Work pelo Hub do LuaSkills selecionado para trabalhar com PDF, Word, Excel e PowerPoint. Os cartões dedicados exibem arquivos, intervalos de planilha ou resultados conforme a operação. A ajuda das ferramentas do LuaSkills registradas implicitamente também mostra os parâmetros que cada uma aceita.
```
