Vulcan Code 0.1.26 では、プロジェクトフォルダーが見つからなくなってもセッションを保持したまま別の場所に接続できます。アプリの更新とツール結果の表示も改善しました。

### プロジェクトとセッション

```ui-checklist
ok | プロジェクトフォルダーの復旧 | フォルダーの移動やドライブの切断後は、元の場所を再確認するか、セッション履歴を保持したまま新しいフォルダーを選択できます。変更は会話のタイムラインに表示され、次回のモデルへのリクエストから新しいフォルダーが使われます。
ok | マウント済みドライブと入力したパスを開く | Linux と macOS のフォルダー選択画面にマウント済みボリュームが表示されます。パスを入力した場合は、フォルダーを開いてから選択を確定できます。
ok | 会話切り替え時に最新メッセージを表示 | 別の会話に切り替えると最新メッセージが開き、続きから読み進められます。
```

### インストールと更新

```ui-checklist
ok | 更新の準備ができてから再起動 | 自動ダウンロードは既定で有効です。ダウンロードと検証が完了すると通知され、再起動を確定したときにバージョンが切り替わります。自動ダウンロードを無効にして手動で更新することもできます。
ok | スタンドアロンインストーラー 0.2.17 | Windows では署名済みの GUI インストーラー、Linux では AppImage、macOS では DMG を利用できます。macOS でターミナルからインストールした後は `vcode manager gui` で GUI 管理画面を開けます。初回インストール時には、インストール経路に合わせて中国本土向けまたは国際版の LuaSkills Hub が選ばれます。
```

### ブラウザーと文書ツール

```ui-checklist
ok | ブラウザー操作カード | Playwright の画面遷移、クリック、スクリーンショットなどについて、操作、対象、結果が表示されます。同梱の Vulcan Browser スキルには操作と確認の手順も含まれます。
ok | Vulcan Work の文書ツール | 選択中の LuaSkills Hub から Vulcan Work がインストールされ、PDF、Word、Excel、PowerPoint を扱えます。専用カードに操作に応じてファイル、セル範囲、結果が表示されます。暗黙的に登録された LuaSkills ツールのヘルプには、実際に受け付けるパラメーターが表示されます。
```
