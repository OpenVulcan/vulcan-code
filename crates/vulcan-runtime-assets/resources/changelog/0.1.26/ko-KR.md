Vulcan Code 0.1.26에서는 프로젝트 폴더에 접근할 수 없을 때 세션을 유지한 채 폴더를 다시 연결할 수 있습니다. 앱 업데이트와 도구 결과 표시도 개선했습니다.

### 프로젝트 및 세션

```ui-checklist
ok | 프로젝트 폴더 복구 | 폴더가 이동했거나 드라이브 연결이 끊어지면 기존 위치를 다시 확인하거나 세션 기록을 유지한 채 새 폴더를 선택할 수 있습니다. 변경 사항은 대화 타임라인에 표시되며 다음 모델 요청부터 새 폴더를 사용합니다.
ok | 마운트된 드라이브 및 입력한 경로 열기 | Linux와 macOS의 폴더 선택기에 마운트된 볼륨이 표시됩니다. 경로를 입력한 뒤 해당 폴더를 먼저 열고 선택을 확정할 수 있습니다.
ok | 대화를 전환하면 최신 메시지 표시 | 다른 대화로 전환할 때 최신 메시지가 열려 이어서 읽을 수 있습니다.
```

### 설치 및 업데이트

```ui-checklist
ok | 업데이트를 준비한 후 다시 시작 | 자동 다운로드는 기본으로 켜져 있습니다. 다운로드와 검증을 마치면 알림이 표시되며 다시 시작을 확인할 때 버전이 바뀝니다. 자동 다운로드를 끄고 수동으로 업데이트할 수도 있습니다.
ok | 독립 설치 프로그램 0.2.17 | Windows에는 서명된 그래픽 설치 프로그램, Linux에는 AppImage, macOS에는 DMG가 제공됩니다. macOS에서 터미널로 설치한 후 `vcode manager gui`로 그래픽 관리자를 열 수 있습니다. 처음 설치할 때 LuaSkills는 설치 경로에 맞는 중국 본토 또는 국제 Hub를 선택합니다.
```

### 브라우저 및 문서 도구

```ui-checklist
ok | 브라우저 작업 카드 | 페이지 이동, 클릭, 스크린샷 등 Playwright 작업의 동작, 대상, 결과가 표시됩니다. 기본 제공 Vulcan Browser 스킬에는 브라우저 작업과 확인 절차도 포함됩니다.
ok | Vulcan Work 문서 도구 | 선택한 LuaSkills Hub에서 Vulcan Work를 설치해 PDF, Word, Excel, PowerPoint 작업을 지원합니다. 전용 카드에는 작업에 따라 파일, 시트 범위 또는 결과가 표시됩니다. 암묵적으로 등록된 LuaSkills 도구의 도움말에도 실제 매개변수가 표시됩니다.
```
