Vulcan Code 0.1.26 可在專案資料夾無法存取時重新連結位置並保留工作階段，同時改善應用程式更新及工具結果的顯示。

### 專案與工作階段

```ui-checklist
ok | 復原專案資料夾 | 資料夾移動或磁碟中斷連線後，可重新檢查原位置，亦可改選新資料夾並保留工作階段記錄。變更會顯示在對話時間線，下次模型請求會使用新資料夾。
ok | 瀏覽掛載磁碟及輸入的路徑 | Linux 和 macOS 的資料夾選擇器會列出掛載的磁碟區。輸入路徑後，可先開啟該資料夾，再確認選擇。
ok | 切換對話時開啟最新訊息 | 切換對話時會跳到最新訊息，方便繼續閱讀。
```

### 安裝與更新

```ui-checklist
ok | 先準備更新，再選擇重新啟動 | 預設自動下載。新版下載及驗證完成後會提示更新已就緒，確認重新啟動後才切換版本。亦可關閉自動下載並手動更新。
ok | 獨立安裝程式 0.2.17 | Windows 提供已簽署的圖形安裝程式，Linux 提供 AppImage，macOS 提供 DMG。從 macOS 終端機安裝後，可用 `vcode manager gui` 開啟圖形管理工具。首次安裝時，LuaSkills 會按安裝路線選用中國大陸或國際 Hub。
```

### 瀏覽器與文件工具

```ui-checklist
ok | 瀏覽器操作卡片 | Playwright 卡片會顯示導覽、點擊、截圖等操作的動作、目標及結果。內置 Vulcan Browser 技能亦提供操作及驗證步驟。
ok | Vulcan Work 文件工具 | Vulcan Code 會從目前的 LuaSkills Hub 安裝 Vulcan Work，支援 PDF、Word、Excel 和 PowerPoint 操作。專用卡片會按操作顯示檔案、工作表範圍或結果。以隱式方式註冊的 LuaSkills 工具亦會在說明中顯示實際參數。
```
