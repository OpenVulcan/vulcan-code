Vulcan Code 0.1.21 では、音声入力のショートカットと無音時の通知を改善しました。

### 音声入力

```ui-checklist
ok | 押して話すショートカット | 右 Ctrl など、左右の修飾キーを単独で割り当てられます。Ctrl+/ のような記号との組み合わせにも対応します。Ctrl+M などの既存のショートカットは元の操作に使えます。
ok | 音声のない録音 | 無音の場合や文字起こし結果が空の場合は、短い通知が表示されます。下書きはそのまま残ります。
ok | 通知の表示位置 | 会話の通知は入力欄の上に表示され、キーボードフォーカスは入力欄に残ります。
```
