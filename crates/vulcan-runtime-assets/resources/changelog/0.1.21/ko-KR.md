Vulcan Code 0.1.21에서 음성 입력 단축키와 무음 녹음 처리를 개선했습니다.

### 음성 입력

```ui-checklist
ok | 누르고 말하기 단축키 | 오른쪽 Ctrl처럼 왼쪽 또는 오른쪽 보조 키를 단독으로 지정하거나 Ctrl+/처럼 기호가 포함된 조합을 사용할 수 있습니다. Ctrl+M 등 이미 지정된 단축키는 기존 기능에 사용됩니다.
ok | 음성이 없는 녹음 | 녹음이 무음이거나 변환 결과가 비어 있으면 짧은 알림을 표시합니다. 작성 중인 초안은 그대로 유지됩니다.
ok | 알림 위치 | 대화 알림은 입력란 위에 표시되며 키보드 포커스는 입력란에 유지됩니다.
```
