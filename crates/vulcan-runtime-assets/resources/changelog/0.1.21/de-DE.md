Vulcan Code 0.1.21 verbessert die Tastenkürzel für die Spracheingabe und den Umgang mit stillen Aufnahmen.

### Spracheingabe

```ui-checklist
ok | Tastenkürzel zum Sprechen | Lege eine einzelne linke oder rechte Modifikatortaste fest, etwa die rechte Strg-Taste, oder verwende eine Kombination mit einem Satzzeichen wie Strg+/. Belegte Kürzel wie Strg+M behalten ihre Funktion.
ok | Aufnahmen ohne Sprache | Bei Stille oder einem leeren Transkript erscheint kurz ein Hinweis. Der Entwurf bleibt erhalten.
ok | Benachrichtigungen | Benachrichtigungen im Gespräch erscheinen oberhalb des Eingabefelds. Der Tastaturfokus bleibt im Eingabefeld.
```
