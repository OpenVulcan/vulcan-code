Vulcan Code 0.1.21 améliore les raccourcis de dictée et la gestion des enregistrements silencieux.

### Saisie vocale

```ui-checklist
ok | Raccourcis pour parler | Associez une touche de modification gauche ou droite seule, par exemple Ctrl droit, ou une combinaison avec un signe de ponctuation comme Ctrl+/. Les raccourcis déjà attribués, comme Ctrl+M, gardent leur fonction.
ok | Enregistrements sans parole | Un bref message s’affiche en cas de silence ou de transcription vide. Le brouillon reste intact.
ok | Notifications | Les notifications s’affichent au-dessus de la zone de saisie, qui conserve le focus clavier.
```
