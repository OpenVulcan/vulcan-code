В Vulcan Code 0.1.21 улучшены сочетания для голосового ввода и обработка записей без речи.

### Голосовой ввод

```ui-checklist
ok | Клавиши для голосового ввода | Можно назначить левую или правую клавишу-модификатор отдельно, например правый Ctrl, или сочетание со знаком препинания, например Ctrl+/. Уже назначенные сочетания, такие как Ctrl+M, сохраняют свои функции.
ok | Записи без речи | При тишине или пустом результате распознавания появляется короткое уведомление. Черновик сохраняется.
ok | Уведомления | Уведомления в беседе появляются над полем ввода. Фокус клавиатуры остаётся в поле.
```
