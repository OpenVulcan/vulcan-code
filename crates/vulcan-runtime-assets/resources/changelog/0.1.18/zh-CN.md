Vulcan Code 0.1.18 修复了上下文压缩中的请求错误，并改进了消息发送、浏览器关闭和用量计价。

### 上下文与会话

```ui-checklist
ok | 上下文压缩 | 手动压缩使用当前所选模型。遇到余额不足或鉴权失败等明确错误时停止自动重试。摘要模型提出工具调用时，工具预览会归到正确的压缩请求，避免因缺少请求编号而中断。
ok | 自动重试记录 | 同一次请求的重试错误集中显示，可以在一张卡片中查看各次尝试。
ok | 记忆失效提示 | 会话会明确标出先前附加的记忆上下文已失效。
```

### 操作与设置

```ui-checklist
ok | 排队与插队快捷键 | 任务运行时，可选用 Enter 排队或插队，Ctrl+Enter 执行另一种操作。会话空闲时直接发送。
ok | 默认审批与思考等级 | 可设置新会话的默认审批模式。切回已用过的模型时，会恢复该模型保存的思考等级。
ok | 关闭本地浏览器 | 点击工作区浏览器面板的关闭按钮，会直接关闭当前会话的浏览器页面并释放资源。
```

### 供应商与用量统计

```ui-checklist
ok | 供应商提示 | 未配置的 NodeAI 不再出现在供应商列表中。标记为不稳定的供应商会显示风险提示。
ok | 按模型查看请求 | 用量统计的最近请求列表支持按模型筛选。
ok | 阶梯计价与供应商价格 | 用量估算可按模型的 Token 用量区间计价，也可以为指定供应商单独设置模型价格。
```
