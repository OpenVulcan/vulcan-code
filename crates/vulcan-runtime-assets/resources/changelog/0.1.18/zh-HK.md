Vulcan Code 0.1.18 修正了上下文壓縮的請求錯誤，並改善訊息傳送、關閉瀏覽器及用量計價。

### 上下文與工作階段

```ui-checklist
ok | 上下文壓縮 | 手動壓縮會使用目前選取的模型。遇到餘額不足或驗證失敗等明確錯誤時，會停止自動重試。摘要模型提出工具呼叫時，工具預覽會歸到正確的壓縮請求，避免因缺少請求編號而中斷。
ok | 自動重試記錄 | 同一請求的重試錯誤會集中顯示，可在同一張卡片查看每次嘗試。
ok | 記憶失效提示 | 工作階段會清楚標示先前附加的記憶上下文已失效。
```

### 操作與設定

```ui-checklist
ok | 排隊與插隊快捷鍵 | 任務執行期間，可選擇用 Enter 排隊或插隊，Ctrl+Enter 執行另一種操作。工作階段閒置時會直接傳送。
ok | 預設審批與思考等級 | 可設定新工作階段的預設審批模式。切回曾用過的模型時，會恢復該模型已儲存的思考等級。
ok | 關閉本機瀏覽器 | 按下工作區瀏覽器面板的關閉按鈕，會直接關閉目前工作階段的瀏覽器分頁並釋放資源。
```

### 供應商與用量統計

```ui-checklist
ok | 供應商提示 | 未設定的 NodeAI 會從供應商清單隱藏。標示為不穩定的供應商會顯示風險提示。
ok | 按模型查看請求 | 用量統計的最近請求清單支援按模型篩選。
ok | 階梯計價與供應商價格 | 用量估算可按模型的 Token 用量級別計價，也可為指定供應商單獨設定模型價格。
```
