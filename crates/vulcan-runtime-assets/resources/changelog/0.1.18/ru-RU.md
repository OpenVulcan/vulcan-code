В Vulcan Code 0.1.18 исправлены ошибки сжатия контекста и улучшены сочетания клавиш для отправки, закрытие браузера и расчёт стоимости использования.

### Контекст и диалоги

```ui-checklist
ok | Сжатие контекста | Ручное сжатие использует выбранную модель. При нехватке средств или ошибке аутентификации автоматические повторы прекращаются. Если модель для резюме запрашивает инструмент, его предпросмотр остаётся связан с нужным запросом сжатия.
ok | История повторных попыток | Ошибки автоматических повторов одного запроса собраны в карточке, где можно просмотреть каждую попытку.
ok | Уведомления об истечении срока памяти | В диалоге отмечается, когда ранее добавленный контекст памяти утратил силу.
```

### Управление и настройки

```ui-checklist
ok | Клавиши для очереди и вставки | Во время выполнения задачи можно настроить Enter для постановки сообщения в очередь или его вставки. Ctrl+Enter выполняет другое действие. В свободном диалоге сообщение отправляется сразу.
ok | Согласование по умолчанию и уровень рассуждений | Можно задать режим согласования для новых диалогов. При возврате к ранее использованной модели восстанавливается её сохранённый уровень рассуждений.
ok | Закрытие локального браузера | Закрытие панели браузера в рабочей области сразу закрывает страницы текущего диалога и освобождает их ресурсы.
```

### Поставщики и использование

```ui-checklist
ok | Уведомления о поставщиках | NodeAI появляется в списке после настройки. Для поставщиков, отмеченных как нестабильные, показывается предупреждение.
ok | Фильтр запросов по модели | В статистике использования можно фильтровать список последних запросов по модели.
ok | Тарифы по объёму и поставщику | При оценке затрат можно использовать цены по диапазонам токенов и задавать отдельную цену модели для конкретного поставщика.
```

### Заметки о выпусках

```ui-checklist
ok | Заметки о выпусках | Изменения в версиях с 0.1.14 по 0.1.17 снова сгруппированы в списки, чтобы их было легче просматривать.
```
