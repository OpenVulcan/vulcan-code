Vulcan Code 0.1.18 では、コンテキスト圧縮のエラーを修正し、メッセージの送信操作、ブラウザーの終了、利用料金の見積もりを改善しました。

### コンテキストと会話

```ui-checklist
ok | コンテキスト圧縮 | 手動圧縮には現在選択しているモデルを使います。残高不足や認証失敗などのエラーでは自動再試行を停止します。要約モデルがツールを要求した場合、そのプレビューが正しい圧縮リクエストに関連付けられます。
ok | 自動再試行の履歴 | 同じリクエストの自動再試行エラーを一つのカードにまとめ、試行ごとに確認できます。
ok | メモリーの失効通知 | 以前に添付したメモリーのコンテキストが失効したときに、会話内で知らせます。
```

### 操作と設定

```ui-checklist
ok | キューと割り込みのショートカット | タスクの実行中は、Enter でキューに追加するか割り込ませるかを設定できます。Ctrl+Enter はもう一方の操作です。タスクがないときはすぐに送信されます。
ok | 既定の承認と推論レベル | 新しい会話の既定の承認モードを設定できます。以前使ったモデルに戻すと、そのモデルに保存した推論レベルが復元されます。
ok | ローカルブラウザーを閉じる | ワークスペースのブラウザーパネルを閉じると、現在の会話のブラウザーページが閉じ、リソースが解放されます。
```

### プロバイダーと利用状況

```ui-checklist
ok | プロバイダーの通知 | NodeAI は設定するとプロバイダー一覧に表示されます。不安定とされるプロバイダーには警告が表示されます。
ok | モデルでリクエストを絞り込む | 利用統計の最近のリクエストをモデルで絞り込めます。
ok | 段階料金とプロバイダー別料金 | 利用料金の見積もりにトークン使用量に応じた段階料金を使えます。特定のプロバイダー向けにモデル料金を設定することもできます。
```
