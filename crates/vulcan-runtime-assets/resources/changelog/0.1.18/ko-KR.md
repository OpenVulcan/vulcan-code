Vulcan Code 0.1.18은 컨텍스트 압축 오류를 수정하고 메시지 전송 단축키, 브라우저 닫기, 사용량 비용 계산을 개선했습니다.

### 컨텍스트 및 대화

```ui-checklist
ok | 컨텍스트 압축 | 수동 압축에 현재 선택한 모델을 사용합니다. 잔액 부족이나 인증 실패 등의 오류가 발생하면 자동 재시도를 중단합니다. 요약 모델이 도구를 요청하면 미리보기를 올바른 압축 요청에 연결합니다.
ok | 자동 재시도 기록 | 한 요청의 자동 재시도 오류를 카드 하나에 모아 각 시도를 확인할 수 있습니다.
ok | 메모리 만료 알림 | 이전에 첨부한 메모리 컨텍스트가 만료되면 대화에 표시합니다.
```

### 조작 및 설정

```ui-checklist
ok | 대기열 및 끼워넣기 단축키 | 작업 중에는 Enter 키로 메시지를 대기열에 넣거나 끼워넣도록 설정할 수 있습니다. Ctrl+Enter 키는 다른 동작을 실행합니다. 대화가 유휴 상태이면 바로 전송합니다.
ok | 기본 승인 및 추론 수준 | 새 대화의 기본 승인 모드를 설정할 수 있습니다. 이전에 사용한 모델로 돌아가면 저장된 추론 수준을 복원합니다.
ok | 로컬 브라우저 닫기 | 작업 공간의 브라우저 패널을 닫으면 현재 대화의 브라우저 페이지를 바로 닫고 리소스를 해제합니다.
```

### 공급자 및 사용량

```ui-checklist
ok | 공급자 알림 | NodeAI는 설정한 후에 공급자 목록에 표시됩니다. 불안정으로 표시된 공급자에는 경고가 표시됩니다.
ok | 모델별 요청 필터 | 사용량 통계의 최근 요청 목록을 모델별로 필터링할 수 있습니다.
ok | 구간 요금 및 공급자별 가격 | 토큰 사용량 구간에 따른 가격으로 비용을 추정할 수 있습니다. 특정 공급자에 별도의 모델 가격을 설정할 수도 있습니다.
```
