Vulcan Code 0.1.18 修正了上下文壓縮的請求錯誤，並改善訊息傳送、瀏覽器關閉和用量計價。

### 上下文與工作階段

```ui-checklist
ok | 上下文壓縮 | 手動壓縮會使用目前選取的模型。遇到餘額不足或驗證失敗等明確錯誤時，會停止自動重試。摘要模型提出工具呼叫時，工具預覽會歸到正確的壓縮請求，避免因缺少請求編號而中斷。
ok | 自動重試記錄 | 同一請求的重試錯誤會集中顯示，可以在一張卡片中查看每次嘗試。
ok | 記憶失效提示 | 工作階段會清楚標示先前附加的記憶上下文已失效。
```

### 操作與設定

```ui-checklist
ok | 排隊與插隊快速鍵 | 任務執行時，可選擇用 Enter 排隊或插隊，Ctrl+Enter 執行另一種操作。工作階段閒置時會直接傳送。
ok | 預設核准與思考等級 | 可設定新工作階段的預設核准模式。切回曾使用的模型時，會恢復該模型儲存的思考等級。
ok | 關閉本機瀏覽器 | 按下工作區瀏覽器面板的關閉按鈕，會直接關閉目前工作階段的瀏覽器分頁並釋放資源。
```

### 供應商與用量統計

```ui-checklist
ok | 供應商提示 | 未設定的 NodeAI 會從供應商清單隱藏。標記為不穩定的供應商會顯示風險提示。
ok | 依模型查看請求 | 用量統計的最近請求清單支援依模型篩選。
ok | 階梯計價與供應商價格 | 用量估算可依模型的 Token 用量級距計價，也可為指定供應商單獨設定模型價格。
```
