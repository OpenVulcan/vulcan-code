Vulcan Code 0.1.19 добавляет Xiaomi MiMo, обновляет Alibaba Cloud Token Plan и упрощает работу с настройками, клавишами отправки и расходами.

### Модели и поставщики

```ui-checklist
ok | Xiaomi MiMo | Можно войти через браузер или использовать ключ API. Доступны баланс счёта API и остаток кредитов личного плана, а также диалог, распознавание и синтез речи, создание и клонирование голоса.
ok | Alibaba Cloud Token Plan | Обновлены список моделей и способы подключения для распознавания речи, синтеза речи и генерации видео.
ok | Возможности моделей | Обновлены сведения о входных данных и контексте некоторых моделей Open Design и OpenCode Go.
```

### Интерфейс и настройки

```ui-checklist
ok | Интерактивный предпросмотр | В настройках можно попробовать оформление, окно рассуждений, сворачивание инструментов, именование сессий и способы отправки сообщений.
ok | Клавиши в поле ввода | Подсказка для Enter и Ctrl+Enter учитывает текущую задачу и выбранный способ отправки. Во время выполнения задачи она остаётся видимой при вводе текста.
ok | Навигация в настройках | Для обновлений и заметок о выпусках предусмотрены отдельные вкладки. Раздел службы ИИ для других инструментов объясняет, как использовать Vulcan Code через MCP.
```

### Статистика использования

```ui-checklist
ok | Детализация расходов | При неполных данных видны известные промежуточные суммы и сервис каждого запроса. Суммы могут отображаться с тремя знаками после запятой. Обновлены справочные цены MiMo и Alibaba Cloud.
```
