Vulcan Code 0.1.19 新增小米 MiMo，更新阿里雲 Token Plan，並改善設定預覽、傳送快捷鍵及用量費用的顯示。

### 模型與供應商

```ui-checklist
ok | 小米 MiMo | 支援瀏覽器登入及 API Key。可查看按用量收費帳戶餘額及個人套餐餘額，並使用對話、語音辨識、語音合成、音色設計及聲音複製。
ok | 阿里雲 Token Plan | 更新模型清單，以及語音辨識、語音合成和影片生成的連線方式。
ok | 模型能力 | 更新 Open Design 及 OpenCode Go 部分模型的輸入能力及上下文說明。
```

### 介面與設定

```ui-checklist
ok | 互動預覽 | 在設定中預覽外觀、思考彈出視窗、工具收合、工作階段命名及訊息傳送方式。
ok | 傳送快捷鍵 | 輸入區按任務狀態和傳送偏好顯示 Enter 及 Ctrl+Enter 的操作。輸入草稿後仍可查看執行中的提示。
ok | 設定入口 | 在「軟件更新」切換更新和更新記錄分頁。「對外 AI 服務」說明如何讓其他工具透過 MCP 使用 Vulcan Code。
```

### 用量統計

```ui-checklist
ok | 費用明細 | 資料不完整時保留已知費用小計，標示用量所屬的服務入口，並支援顯示三位小數。更新 MiMo 及阿里雲的參考價格。
```
