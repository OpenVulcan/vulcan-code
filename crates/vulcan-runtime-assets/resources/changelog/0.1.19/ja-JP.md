Vulcan Code 0.1.19 では、Xiaomi MiMo に対応し、Alibaba Cloud Token Plan を更新しました。設定や送信ショートカット、利用料金も確認しやすくなりました。

### モデルとプロバイダー

```ui-checklist
ok | Xiaomi MiMo | ブラウザーでのログインと API キーに対応しました。API アカウントの残高や個人プランの残りクレジットを確認でき、チャット、音声認識、音声合成、声のデザイン、声のクローンを利用できます。
ok | Alibaba Cloud Token Plan | モデル一覧と、音声認識、音声合成、動画生成の接続方式を更新しました。
ok | モデルの機能 | Open Design と OpenCode Go の一部モデルについて、対応する入力とコンテキスト情報を更新しました。
```

### 画面と設定

```ui-checklist
ok | 操作できるプレビュー | 外観、推論ポップアップ、ツールの折りたたみ、セッション名、メッセージの送信方法を設定画面で試せます。
ok | 入力欄のショートカット | タスクの状態と送信設定に応じて Enter と Ctrl+Enter の動作を表示します。タスクの実行中は、入力を始めても案内を確認できます。
ok | 設定画面の案内 | ソフトウェア更新とリリースノートを別々のタブで表示します。外部ツール向け AI サービスでは、MCP 経由で Vulcan Code を使う方法を確認できます。
```

### 利用統計

```ui-checklist
ok | 料金の内訳 | データが不足していても計算できた小計を表示し、リクエストごとのサービスを確認できます。料金は小数第 3 位まで表示でき、MiMo と Alibaba Cloud の参考料金も更新しました。
```
