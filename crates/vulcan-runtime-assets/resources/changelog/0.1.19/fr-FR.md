Vulcan Code 0.1.19 ajoute Xiaomi MiMo, actualise Alibaba Cloud Token Plan et rend les réglages, les raccourcis et les coûts d’utilisation plus lisibles.

### Modèles et fournisseurs

```ui-checklist
ok | Xiaomi MiMo | Connectez-vous dans le navigateur ou utilisez une clé API. Consultez le solde de votre compte et les crédits de votre forfait personnel. MiMo prend en charge le dialogue, la reconnaissance et la synthèse vocales, la création de voix et le clonage vocal.
ok | Alibaba Cloud Token Plan | La liste des modèles et les connexions pour la reconnaissance vocale, la synthèse vocale et la génération vidéo ont été actualisées.
ok | Capacités des modèles | Les entrées acceptées et les informations de contexte de certains modèles d’Open Design et d’OpenCode Go ont été actualisées.
```

### Interface et réglages

```ui-checklist
ok | Aperçus interactifs | Essayez dans les réglages l’apparence, les fenêtres de raisonnement, le repli des outils, le nommage des sessions et les modes d’envoi.
ok | Raccourcis de saisie | Les indications pour Entrée et Ctrl+Entrée suivent la tâche active et vos préférences d’envoi. Elles restent visibles pendant la rédaction lorsque la tâche est en cours.
ok | Navigation dans les réglages | La mise à jour du logiciel sépare les mises à jour des notes de version. Le service IA pour les autres outils explique comment utiliser Vulcan Code via MCP.
```

### Statistiques d’utilisation

```ui-checklist
ok | Détail des coûts | Les sous-totaux connus restent visibles lorsque les données sont incomplètes. Le service de chaque requête est indiqué et les coûts peuvent s’afficher sur trois décimales. Les tarifs de référence MiMo et Alibaba Cloud sont actualisés.
```
