Vulcan Code 0.1.19 incorpora Xiaomi MiMo, actualiza Alibaba Cloud Token Plan y facilita la consulta de ajustes, atajos y costes de uso.

### Modelos y proveedores

```ui-checklist
ok | Xiaomi MiMo | Inicia sesión desde el navegador o usa una clave de API. Consulta el saldo de la cuenta y los créditos del plan personal. MiMo ofrece chat, reconocimiento y síntesis de voz, diseño de voces y clonación de voz.
ok | Alibaba Cloud Token Plan | Se han actualizado la lista de modelos y las conexiones para reconocimiento de voz, síntesis de voz y generación de vídeo.
ok | Capacidades de los modelos | Se han actualizado las capacidades de entrada y la información de contexto de determinados modelos de Open Design y OpenCode Go.
```

### Interfaz y ajustes

```ui-checklist
ok | Vistas previas interactivas | Prueba la apariencia, las ventanas de razonamiento, el plegado de herramientas, los nombres de sesión y el envío de mensajes desde Ajustes.
ok | Atajos del editor | Las indicaciones de Enter y Ctrl+Enter siguen la tarea activa y tu preferencia de envío. Durante una tarea, siguen visibles al escribir un borrador.
ok | Navegación en Ajustes | Actualización de software separa las actualizaciones de las notas de versión. El servicio de IA para otras herramientas explica cómo usar Vulcan Code mediante MCP.
```

### Estadísticas de uso

ok | Detalle de costes | Conserva los subtotales conocidos cuando faltan datos, muestra el servicio de cada solicitud y admite tres decimales. Se actualizaron los precios de referencia de MiMo y Alibaba Cloud.
