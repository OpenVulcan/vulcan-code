Vulcan Code 0.1.19 ergänzt Xiaomi MiMo, aktualisiert den Alibaba Cloud Token Plan und verbessert die Darstellung von Einstellungen, Tastenkürzeln und Nutzungskosten.

### Modelle und Anbieter

```ui-checklist
ok | Xiaomi MiMo | Die Anmeldung ist im Browser oder per API-Schlüssel möglich. Guthaben für API-Konten und persönliche Tarife sind einsehbar. MiMo unterstützt Chat, Spracherkennung, Sprachsynthese, Stimmgestaltung und das Klonen von Stimmen.
ok | Alibaba Cloud Token Plan | Die Modellliste und die Verbindungen für Spracherkennung, Sprachsynthese und Videogenerierung wurden aktualisiert.
ok | Modellfunktionen | Die Eingabefunktionen und Kontextangaben ausgewählter Modelle bei Open Design und OpenCode Go wurden aktualisiert.
```

### Oberfläche und Einstellungen

```ui-checklist
ok | Interaktive Vorschau | Darstellung, Denkfenster, eingeklappte Werkzeuge, Sitzungsnamen und das Senden von Nachrichten lassen sich in den Einstellungen ausprobieren.
ok | Tastenkürzel im Eingabefeld | Der Hinweis für Eingabe und Strg+Eingabe folgt der aktuellen Aufgabe und der Sendeeinstellung. Während einer Aufgabe bleibt er auch beim Tippen sichtbar.
ok | Navigation in den Einstellungen | Softwareupdates und Versionshinweise haben eigene Registerkarten. Unter KI-Dienst für andere Werkzeuge wird die Verwendung von Vulcan Code über MCP erklärt.
```

### Nutzungsstatistik

```ui-checklist
ok | Kostendetails | Bekannte Zwischensummen bleiben bei unvollständigen Daten sichtbar. Die Statistik zeigt den Dienst pro Anfrage und bis zu drei Nachkommastellen. Die Referenzpreise für MiMo und Alibaba Cloud wurden aktualisiert.
```
