O Vulcan Code 0.1.19 adiciona Xiaomi MiMo, atualiza o Alibaba Cloud Token Plan e facilita a leitura das configurações, dos atalhos e dos custos de uso.

### Modelos e provedores

```ui-checklist
ok | Xiaomi MiMo | Entre pelo navegador ou use uma chave de API. Consulte o saldo da conta e os créditos do plano pessoal. Use o MiMo para conversar, reconhecer e sintetizar fala, criar vozes e cloná-las.
ok | Alibaba Cloud Token Plan | Foram atualizadas a lista de modelos e as conexões para reconhecimento de fala, síntese de voz e geração de vídeo.
ok | Recursos dos modelos | As entradas aceitas e as informações de contexto de alguns modelos do Open Design e do OpenCode Go foram atualizadas.
```

### Interface e configurações

```ui-checklist
ok | Prévia interativa | Experimente a aparência, as janelas de raciocínio, o recolhimento de ferramentas, a nomeação de sessões e os modos de envio nas configurações.
ok | Atalhos do editor | As dicas de Enter e Ctrl+Enter acompanham a tarefa atual e a preferência de envio. Durante a tarefa, continuam visíveis enquanto você digita.
ok | Navegação nas configurações | A atualização de software separa atualizações e notas de versão em abas. O serviço de IA para outras ferramentas explica como usar o Vulcan Code via MCP.
```

### Estatísticas de uso

```ui-checklist
ok | Detalhes de custos | Os subtotais conhecidos continuam visíveis quando faltam dados. O serviço de cada solicitação é identificado e os custos podem ser exibidos com três casas decimais. Os preços de referência do MiMo e da Alibaba Cloud foram atualizados.
```
