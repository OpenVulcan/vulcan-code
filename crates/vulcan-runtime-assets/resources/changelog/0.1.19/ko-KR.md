### 모델 및 공급자

```ui-checklist
ok | Xiaomi MiMo | 브라우저 로그인과 API 키를 지원합니다. API 계정 잔액과 개인 플랜의 남은 크레딧을 확인하고 채팅, 음성 인식, 음성 합성, 음성 설계와 복제를 사용할 수 있습니다.
ok | Alibaba Cloud Token Plan | 모델 목록과 음성 인식, 음성 합성, 동영상 생성 연결 방식이 업데이트되었습니다.
ok | 모델 기능 | Open Design 및 OpenCode Go의 일부 모델에 대해 입력 기능과 컨텍스트 정보를 업데이트했습니다.
```

### 인터페이스 및 설정

```ui-checklist
ok | 대화형 미리보기 | 설정에서 모양, 추론 팝업, 도구 접기, 세션 이름 지정과 메시지 전송 방식을 미리 체험할 수 있습니다.
ok | 입력창 단축키 | 현재 작업과 전송 설정에 따라 Enter 및 Ctrl+Enter의 동작을 안내합니다. 작업 중에는 메시지를 입력해도 안내가 계속 표시됩니다.
ok | 설정 탐색 | 소프트웨어 업데이트와 릴리스 노트를 각 탭에서 확인할 수 있습니다. 외부 도구용 AI 서비스에서 MCP로 Vulcan Code를 사용하는 방법을 안내합니다.
```
