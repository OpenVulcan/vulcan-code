Vulcan Code 0.1.19 新增小米 MiMo 接入，更新阿里云 Token Plan，并让设置预览、发送快捷键和用量费用更容易看懂。

### 模型与供应商

```ui-checklist
ok | 小米 MiMo | 支持浏览器登录和 API Key。可查看按量账户余额和个人套餐余量，并使用 MiMo 对话、语音识别、语音合成、音色设计和声音克隆。
ok | 阿里云 Token Plan | 更新模型列表，以及语音识别、语音合成和视频生成的连接方式。
ok | 模型能力 | 更新 Open Design 和 OpenCode Go 部分模型的输入能力与上下文说明。
```

### 界面与设置

```ui-checklist
ok | 交互式预览 | 在设置中预览外观、思考弹窗、工具折叠、会话命名和消息发送方式。
ok | 发送快捷键 | 输入区会根据任务状态和发送偏好，显示 Enter 和 Ctrl+Enter 对应的操作。输入草稿后仍可查看运行中的提示。
ok | 设置入口 | 在「软件更新」中切换更新和更新记录页签。「对外 AI 服务」说明如何让其他工具通过 MCP 使用 Vulcan Code。
```

### 用量统计

```ui-checklist
ok | 费用明细 | 数据不完整时保留已知费用小计，标明用量对应的服务入口，并支持显示三位小数。更新了 MiMo 和阿里云的参考价格。
```
