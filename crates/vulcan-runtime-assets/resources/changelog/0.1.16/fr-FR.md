Vulcan Code 0.1.16 corrige un ralentissement important de la fenêtre de raisonnement sous Windows et améliore le défilement dans les paramètres des services de modèles.

### Correctifs

```ui-checklist
ok | Fenêtre de raisonnement sous Windows | Correction d’un ralentissement important de l’application de bureau Windows lors de l’actualisation en temps réel de la fenêtre de raisonnement, notamment dans les longues conversations.
ok | Liste des fournisseurs et détails | Dans les paramètres des services de modèles, la liste des fournisseurs et leurs détails défilent indépendamment dans la fenêtre. Sélectionner un autre fournisseur ramène le panneau de détails en haut.
```
