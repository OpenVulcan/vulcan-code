Vulcan Code 0.1.16 behebt eine starke Verlangsamung des Denkfensters unter Windows und verbessert das Scrollen in den Einstellungen für Modelldienste.

### Fehlerbehebungen

```ui-checklist
ok | Denkfenster unter Windows | Eine starke Verlangsamung der Windows-Desktop-App beim laufenden Aktualisieren des Denkfensters wurde behoben. Sie trat besonders in langen Unterhaltungen auf.
ok | Anbieterliste und Detailbereich | In den Einstellungen für Modelldienste lassen sich die Anbieterliste und der Detailbereich im Fenster unabhängig voneinander scrollen. Beim Wechsel des Anbieters springt der Detailbereich nach oben.
```
