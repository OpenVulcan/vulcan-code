Vulcan Code 0.1.16 corrige uma lentidão grave na janela de raciocínio do Windows e melhora a rolagem nas configurações de serviços de modelos.

### Correções

```ui-checklist
ok | Janela de raciocínio no Windows | Corrigimos uma lentidão grave no aplicativo para Windows durante a atualização em tempo real da janela de raciocínio, especialmente em conversas longas.
ok | Lista de provedores e detalhes | Nas configurações de serviços de modelos, a lista de provedores e os detalhes podem ser rolados separadamente dentro da janela. Ao selecionar outro provedor, o painel de detalhes volta ao topo.
```
