В Vulcan Code 0.1.16 исправлено сильное замедление окна рассуждений в Windows и улучшена прокрутка в настройках сервисов моделей.

### Исправления

```ui-checklist
ok | Окно рассуждений в Windows | Устранено сильное замедление приложения для Windows при обновлении всплывающего окна рассуждений в реальном времени, особенно в длинных диалогах.
ok | Список поставщиков и панель сведений | В настройках сервисов моделей список поставщиков и панель сведений прокручиваются независимо друг от друга. При выборе другого поставщика панель сведений возвращается к началу.
```
