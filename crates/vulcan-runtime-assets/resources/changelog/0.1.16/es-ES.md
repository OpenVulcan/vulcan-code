Vulcan Code 0.1.16 corrige una ralentización grave en la ventana de razonamiento de Windows y mejora el desplazamiento en la configuración de servicios de modelos.

### Correcciones

```ui-checklist
ok | Ventana de razonamiento en Windows | Se corrigió una ralentización grave en la aplicación de escritorio para Windows al actualizarse la ventana emergente de razonamiento en tiempo real, especialmente en conversaciones largas.
ok | Lista de proveedores y detalles | En la configuración de servicios de modelos, la lista de proveedores y sus detalles se desplazan de forma independiente dentro de la ventana. Al cambiar de proveedor, el panel de detalles vuelve al principio.
```
