Vulcan Code 0.1.16에서는 Windows 추론 팝업이 심하게 느려지는 문제를 수정하고 모델 서비스 설정의 스크롤 동작을 개선했습니다.

### 수정 사항

```ui-checklist
ok | Windows 실시간 추론 팝업 | Windows 데스크톱 앱에서 실시간 추론 팝업이 업데이트될 때 심하게 느려지는 문제를 수정했습니다. 이 문제는 긴 대화에서 특히 두드러졌습니다.
ok | 공급자 목록과 상세 정보 | 모델 서비스 설정에서 공급자 목록과 상세 정보 영역을 창 안에서 각각 스크롤할 수 있습니다. 다른 공급자를 선택하면 상세 정보가 맨 위에서 표시됩니다.
```
