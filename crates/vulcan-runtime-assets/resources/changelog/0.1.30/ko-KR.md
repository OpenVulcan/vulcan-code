Vulcan Code 0.1.30에는 절약 모드, ChatGPT 요금제 로그인, 설정 이전이 추가되었으며 MCP, 내장 브라우저와 대기 메시지 복구가 개선되었습니다.

### 세션 및 컨텍스트

```ui-checklist
ok | 세션별 절약 모드 | 일반 세션의 기록 보존 범위를 설정할 수 있습니다. 기본값에서는 처리가 완료된 턴이 40개에 도달하면 가장 오래된 턴 중 제외 가능한 20개를 이후 모델 요청에서 뺄 수 있습니다. 전체 타임라인은 계속 볼 수 있으며 기존 세션에서 처음 켜면 모델 요청이 한 번 더 발생할 수 있습니다.
ok | 실패 후 대기 메시지 보내기 | 실패한 턴의 처리가 끝나면 선택한 대기 메시지를 원래 첨부 파일과 모델 설정을 유지한 채 보낼 수 있습니다. 요청 검사 화면에 턴 요약, 보존된 기록과 메모리 만료가 표시됩니다.
```

```ui-checklist
ok | 분리된 OpenAI 연결 | OpenAI API, Codex, ChatGPT 요금제 계정을 별도로 연결할 수 있습니다. HTTP를 통한 Codex 로그인과 한도 조회가 복구되었고, ChatGPT 요금제의 첨부 파일과 일부 스트리밍 응답 문제가 해결되었습니다.
ok | 선택한 설정 이전 | 필요한 제공업체 인증 정보와 사용자 지정 제공업체를 암호로 보호되는 `.vc_mcfg` 파일로 내보낼 수 있습니다. 토큰이 교체되는 계정은 대상 기기에서 다시 로그인해야 합니다.
```
