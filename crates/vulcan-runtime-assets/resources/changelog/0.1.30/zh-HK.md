Vulcan Code 0.1.30 新增節約用量模式、ChatGPT 計劃登入及設定轉移，並改進 MCP、內置瀏覽器與失敗後的排隊訊息恢復。

### 工作階段與上下文

```ui-checklist
ok | 按工作階段啟用節約用量模式 | 一般工作階段可設定歷史視窗。預設達到 40 個已完成結算的回合時，從後續模型請求移除最早一批可裁剪的 20 個回合。原始時間線仍可查閱，有歷史的工作階段首次啟用時可能多一次模型請求。
ok | 失敗後發送排隊訊息 | 失敗回合結算後，可直接發送選取的排隊訊息，保留原有附件與模型設定。請求上下文面板亦會顯示回合摘要、保留情況及記憶到期提示。
```

### 帳戶與模型

```ui-checklist
ok | 獨立的 OpenAI 連接入口 | 可分別連接 OpenAI API、Codex 計劃與 ChatGPT 計劃。Codex 恢復使用 HTTP 登入及查詢配額，ChatGPT 計劃修正附件及部分串流回應。
ok | 選擇性轉移模型服務設定 | 可選取供應商憑證及自訂供應商，匯出為受密碼保護的 `.vc_mcfg` 檔案。使用輪替權杖的帳戶須在目標裝置重新登入。
ok | 用量與圖片編輯 | 階躍星辰 Step Plan 在國內及國際線路均可查詢用量。OpenAI API 新增 GPT Image 2 及 2.5 圖片編輯，Codex 計劃新增 GPT Image 2 參考圖片編輯。
```

### 工具與工作區

```ui-checklist
ok | 按專案使用 MCP 及 LuaSkills | MCP 伺服器可限制於指定專案並按需呼叫。從輸入框的 `#` 選單選擇可用的 MCP 或 LuaSkills，仍按目前工作階段的工具權限運作。
ok | 直接操作瀏覽器 | 可直接操作內置瀏覽器頁面。長對話展開時更穩定地保留閱讀位置，指令卡可同時顯示執行時間及逾時設定。
```

