Vulcan Code 0.1.30 では節約モード、ChatGPT プランのサインイン、設定の移行を追加し、MCP、内蔵ブラウザー、キューに入れたメッセージの復旧を改善しました。

### セッションとコンテキスト

```ui-checklist
ok | セッションごとの節約モード | 通常のセッションで履歴の保持範囲を設定できます。既定では、確定済みのターンが 40 件に達すると、古いものから対象となる 20 件を以後のモデルリクエストから外せます。元の履歴は引き続き表示でき、履歴があるセッションで初めて有効にするとモデルリクエストが 1 回増える場合があります。
ok | 失敗後にキューのメッセージを送信 | 失敗したターンの処理が完了したら、元の添付内容やモデル設定を保ったまま選択したメッセージを送信できます。リクエストの確認画面には、ターンの要約、保持された履歴、メモリの有効期限も表示されます。
```

### アカウントとモデル

```ui-checklist
ok | OpenAI の接続先を分離 | OpenAI API、Codex、ChatGPT プランに個別に接続できます。Codex の HTTP によるサインインと使用枠の確認を復旧し、ChatGPT プランの添付ファイルと一部のストリーミング応答を修正しました。
ok | 設定を選択して移行 | 選択した認証情報やカスタムプロバイダーを、パスワードで保護された `.vc_mcfg` にエクスポートできます。ローテーションされるトークンを使うアカウントは、移行先で再ログインが必要です。
ok | 使用量と画像編集 | StepFun の Step Plan の使用量を両地域で確認できます。OpenAI API の GPT Image 2 と 2.5 で画像編集、Codex の GPT Image 2 で参照画像を使った編集が可能です。
```

### ツールと作業環境

```ui-checklist
ok | プロジェクトごとの MCP と LuaSkills | MCP サーバーをプロジェクトに限定し、必要なときに呼び出せます。入力欄の `#` メニューから使用できる MCP や LuaSkills を選択できます。セッションの権限が適用されます。
ok | ブラウザーを直接操作 | 内蔵ブラウザーでページを直接操作できます。長い会話でも読み取り位置が安定して保たれ、コマンドカードには経過時間とタイムアウトが並びます。
```
