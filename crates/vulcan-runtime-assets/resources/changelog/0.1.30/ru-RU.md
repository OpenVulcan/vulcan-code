В Vulcan Code 0.1.30 появились режим экономии, вход через план ChatGPT и перенос конфигурации. Улучшены MCP, встроенный браузер и восстановление сообщений из очереди.

### Сеансы и контекст

```ui-checklist
ok | Режим экономии для отдельных сеансов | Для обычного сеанса можно настроить окно истории. По умолчанию после завершения 40 ходов из следующих запросов к модели можно исключить 20 самых ранних подходящих ходов. Полная история остаётся доступной. Включение режима в существующем сеансе может потребовать одного дополнительного запроса к модели.
ok | Отправка сообщений из очереди после ошибки | После завершения обработки неудачного хода можно отправить выбранное сообщение с исходными вложениями и настройками модели. Инспектор запроса показывает краткие итоги ходов, сохранённую историю и истечение срока действия памяти.
```

### Учётные записи и модели

```ui-checklist
ok | Отдельные подключения OpenAI | Учётные записи OpenAI API, Codex и плана ChatGPT подключаются отдельно. Вход в Codex и проверка квот снова работают по HTTP. В плане ChatGPT исправлена обработка вложений и некоторых потоковых ответов.
ok | Выборочный перенос настроек | Выбранные учётные данные и пользовательские поставщики экспортируются в защищённый паролем файл `.vc_mcfg`. Для учётных записей с обновляемыми токенами нужен повторный вход на целевом устройстве.
ok | Расход и редактирование изображений | Расход StepFun Step Plan доступен в обоих регионах. OpenAI API поддерживает редактирование с GPT Image 2 и 2.5, а Codex поддерживает редактирование по референсам с GPT Image 2.
```

### Инструменты и рабочая область

```ui-checklist
ok | Ярлыки MCP и LuaSkills для проекта | Доступ к серверам MCP можно ограничить выбранными проектами и использовать по требованию. Доступные элементы находятся в меню `#` поля ввода. Разрешения сеанса сохраняются.
ok | Прямая работа в браузере | Со страницами встроенного браузера можно взаимодействовать напрямую. Длинные диалоги лучше сохраняют позицию чтения. Карточки команд показывают время работы и предельное время ожидания.
```

### Обновление

```ui-checklist
ok | Автоматическое обновление данных | При открытии приложение обновляет базу данных и старые файлы сеансов и сохраняет резервную копию. Существующие обычные сеансы остаются в стандартном режиме до включения экономии.
ok | Установка и повторная попытка в Windows | Установщик 0.2.19 добавляет среду Visual C++ x64, если она отсутствует. При неудачной проверке запуска проверенные файлы сохраняются, а повторно загружаются только недостающие или повреждённые данные.
```
