Vulcan Code 0.1.30 新增節約用量模式、ChatGPT 方案登入與設定移轉，並改善 MCP、內建瀏覽器及失敗後的排隊訊息恢復。

### 工作階段與脈絡

```ui-checklist
ok | 依工作階段啟用節約用量模式 | 一般工作階段可設定歷史視窗。預設達到 40 個已結算回合時，從後續模型請求移除最早一批可裁剪的 20 個回合，原始時間軸仍可查閱。在已有歷史的工作階段首次啟用時，可能多一次模型請求。
ok | 失敗後傳送排隊訊息 | 失敗回合結算後，可直接傳送選取的排隊訊息，保留原附件及模型設定。請求脈絡面板也會顯示回合摘要、保留狀況和記憶到期提示。
```

### 帳號與模型

```ui-checklist
ok | 獨立的 OpenAI 連線入口 | 可分別連接 OpenAI API、Codex 方案與 ChatGPT 方案。Codex 恢復透過 HTTP 登入和查詢用量上限，ChatGPT 方案修正附件與部分串流回應。
ok | 選擇性移轉模型服務設定 | 可選取供應商憑證與自訂供應商，匯出為受密碼保護的 `.vc_mcfg` 檔案。使用輪替權杖的帳號須在目標裝置重新登入。
ok | 用量與圖片編輯 | 階躍星辰 Step Plan 可在國內及國際線路查詢用量。OpenAI API 新增 GPT Image 2 與 2.5 圖片編輯，Codex 方案新增 GPT Image 2 參考圖編輯。
```

### 工具與工作區

```ui-checklist
ok | 按專案使用 MCP 和 LuaSkills | MCP 伺服器可限定專案並按需呼叫，從輸入框的 `#` 選單選擇可用的 MCP 或 LuaSkills。工具權限依目前工作階段生效。
ok | 直接操作瀏覽器 | 可直接操作內建瀏覽器頁面。長對話展開時更穩定地保留閱讀位置，命令卡可同時顯示執行時間與逾時設定。
```

### 升級提示

```ui-checklist
ok | 自動升級舊資料 | 應用程式開啟資料庫或舊工作階段時會自動升級並保留升級前的備份。現有一般工作階段維持一般模式，可手動啟用節約用量模式。
ok | Windows 安裝與重試 | 安裝程式 0.2.19 可補裝缺少的 Visual C++ x64 執行階段。啟動檢查失敗時會保留已驗證的檔案，重試時只補下載缺少或損毀的部分。
```
