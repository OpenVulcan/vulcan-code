Vulcan Code 0.1.30 新增节约用量模式、ChatGPT 套餐登录和配置迁移，并改进 MCP、内置浏览器及失败后的消息恢复。

### 会话与上下文

```ui-checklist
ok | 按会话启用节约用量模式 | 可为普通会话设置历史窗口。默认达到 40 个已结算回合时，从后续模型请求中移出最早一批可裁剪的 20 个回合。原始时间线仍可查看，首次为有历史的会话启用时可能多一次模型请求。
ok | 失败后继续发送排队消息 | 失败回合结算后，可以直接发送选中的排队消息，保留附件和当时绑定的模型设置。请求上下文面板也会显示回合摘要、保留情况和记忆过期提示。
```

### 账号与模型

```ui-checklist
ok | 独立的 OpenAI 账号入口 | OpenAI API、Codex 套餐和 ChatGPT 套餐可分别连接。Codex 恢复通过 HTTP 登录与查询额度，ChatGPT 套餐修复了附件能力和部分流式响应。
ok | 按需迁移模型服务配置 | 可选取供应商凭据与自定义供应商，导出为受密码保护的 `.vc_mcfg` 文件。使用轮换令牌的账号需在目标设备重新登录。
ok | 用量与图片编辑 | 阶跃星辰 Step Plan 在国内、国际线路均可查询用量。OpenAI API 新增 GPT Image 2 与 2.5 图片编辑，Codex 套餐新增 GPT Image 2 参考图编辑。
```

### 工具与操作

```ui-checklist
ok | 按项目使用 MCP 和 LuaSkills | MCP 服务器可限定项目并设为按需调用，从输入框的 `#` 列表选择可用的 MCP 或 LuaSkills。工具权限仍按当前会话生效。
ok | 浏览器可直接操作 | 可直接操作内置浏览器页面。长对话展开时更稳定地保持阅读位置，命令卡可同时显示运行时长和超时设置。
```

### 升级提示

```ui-checklist
ok | 旧数据自动升级 | 首次打开时自动升级应用数据库与旧会话格式，并保存升级前的备份。已有普通会话保持常规模式，需手动启用节约用量。
ok | Windows 安装与重试 | 安装器 0.2.19 可补装缺失的 Visual C++ x64 运行库。启动检查失败后会保留已校验的文件，重试只补缺失或损坏的部分。
```
