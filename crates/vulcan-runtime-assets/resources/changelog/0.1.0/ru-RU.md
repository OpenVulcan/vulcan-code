Vulcan Code 0.1.0 — первая публичная предварительная версия: графическая ИИ-среда для написания кода и повседневных рабочих задач. Проекты, сессии, терминалы, браузер, ревью кода и коммиты Git собраны в одном месте.

```ui-kv
Выпуск | Предварительная версия
Клиенты | Настольное приложение, WebUI в браузере, терминальный клиент (TUI)
Языки интерфейса | 11
Пакеты | Python, Node.js и компоненты браузера в комплекте; установка одной командой
Лицензия | MIT
```

### Окно сжатия
Каждая сессия может в любой момент сменить окно сжатия через индикатор заполнения контекста в поле ввода, так что даже для длинной задачи не нужна новая сессия.

```ui-kv
Размеры | Пять ступеней, по умолчанию 200K, 256K, 272K, 373K и 500K токенов, их можно изменить в настройках
По модели | Выберите "По умолчанию (как у модели)", чтобы сжимать по окну текущей модели
Область действия | Меняет только момент автоматического сжатия, а не собственное окно контекста модели
Ручное сжатие | Запустите /compact для текущей сессии в любой момент
```

### Карточки инструментов и сворачивание
У каждого вида инструментов своя карточка, поэтому даже множество вызовов не заслоняет ответ.

```ui-checklist
ok | Специальные карточки | Файлы, команды, терминалы, субагенты, поиск, медиа, вопросы, переменные окружения, изменения конфигурации и многое другое
ok | Время и ссылки | Каждый вызов показывает, сколько он длился; файлы с карточки открываются прямо на панели файлов
ok | Сворачивание по мере надобности | Развёрнуто во время работы и свёрнуто по завершении; последовательные вызовы группируются под одной сводкой
ok | Переключение в любой момент | Выберите вариант по умолчанию в настройках или переключайте для каждой сессии через "Сворачивание инструментов" в поле ввода или /collapse
```

### Мультимодальность
В разделе "Мультимодальные расширения" каждой возможности назначается одна или несколько моделей; "Расширенные возможности" включают их для отдельной сессии.

```ui-cards
Веб | Веб-поиск и извлечение содержимого страниц
Понимание | Понимание изображений, видео и аудио
Генерация | Генерация изображений и видео; для изображений можно также использовать подписку Codex
Речь и музыка | Синтез и распознавание речи, генерация музыки и каверов
```

### Переменные окружения
Встроенное управление переменными окружения хранит секреты на вашем компьютере; ИИ видит только имена переменных.

```ui-checklist
ok | Три уровня | Глобальный уровень, уровень проекта и уровень сессии редактируются в интерфейсе; страницу можно показывать на боковой панели
ok | Значения скрыты | Значения никогда не показываются ни ИИ, ни в интерфейсе, а значения в результатах инструментов маскируются
ok | Заполнение по запросу | Если ИИ не хватает переменной, он запрашивает её у вас через форму, и значение никогда не проходит через беседу
ok | Автоматическая подстановка | Команды и терминалы получают переменные своего уровня; серверы MCP используют глобальные
```

### Модели субагентов
Субагенты используют только разрешённые вами модели.

```ui-kv
Два уровня | Системная настройка действует по умолчанию; каждая сессия может задать свою
Отмечена по умолчанию | Вызывающая модель включена по умолчанию, отметку можно снять
Вне списка | Сразу отклоняется и никогда не подменяется молча другой моделью
Настройки сессии | Меняйте в любой момент в настройках сессии под полем ввода или одним щелчком вернитесь к системному значению по умолчанию
```

### Рабочая среда

```ui-cards
Проекты и сессии | Много проектов и сессий рядом в удобном вам порядке, с панелями дерева файлов, ревью, памяти и субагентов
Терминалы проекта | Терминалы с вкладками; ИИ может удерживать долгие или интерактивные командные сессии
Панель файлов | Упоминайте файлы через @, перетаскивайте их в поле ввода, открывайте пути из терминалов и вывода, ищите и переходите к строке
Насыщенные ответы | Потоковый Markdown, код и диаграммы Mermaid; интерактивные ответы добавляют чек-листы, сравнения, графики, схемы и многое другое, а карточки решений вставляют или отправляют ваш ответ
Ветвление и повтор | Отредактируйте прежний вопрос, чтобы сгенерировать ответ заново, или ответвите новую сессию от любого завершённого хода
Палитра команд | Сочетания клавиш, поиск по беседе и копирование беседы в виде Markdown
Выделенные ассистенты | Сессии с фиксированным базовым промптом и замороженными настройками для одной повторяющейся задачи
```

### Работа над задачами

```ui-cards
Режим цели | Задайте цель и бюджет токенов; ИИ продолжает работу ход за ходом, его можно приостановить, возобновить или сбросить
Режим планирования | Сначала исследование и план, выполнение — только после вашего одобрения
Подсказки на ходу | Добавляйте указания или ставьте в очередь новые запросы, пока задача выполняется
Субагенты | Встроенные роли исследования и планирования и необязательные шаблоны ролей
Вопросы | Когда ИИ нужно решение, он спрашивает прямо в сессии с карточками вариантов
```

### Код, знания и память

```ui-cards
Навигация по коду | CodeKit читает актуальное рабочее дерево: символы, определения и ссылки
База знаний | Библиотеки, которые ИИ ведёт для вас, с постоянной историей и доступом по проектам
Память | Память в Markdown в папке пользователя или долговременная память MemoryMesh, которая извлекается перед каждым ходом и отображается в ходе работы
```

### Безопасность и ревью

```ui-checklist
ok | Режимы разрешений | Только просмотр, Изменение рабочей области, Автоодобрение и Полный доступ
ok | Конвейер одобрения | Правила, модель оценки и модель-рецензент; всё неочевидное передаётся вам
ok | Модель оценки | Работает на локальной модели, в облаке или через API
ok | Ревью diff | Единый и раздельный вид, изменения на уровне слов, индексирование и откат
ok | Git | Pull, сообщения коммитов от ИИ, коммит в текущую или новую ветку, затем push
```

### Расширение Vulcan Code

```ui-cards
Навыки | Навыки-промпты (SKILL.md) и программируемые пакеты LuaSkills, которые можно установить из LuaSkills Hub
MCP | Подключайте локальные и HTTP-серверы MCP или позвольте ИИ подключить сервер для одной сессии
Служба MCP | Другие ИИ-инструменты могут получать список сессий, отправлять сообщения и отвечать на вопросы, у каждого свой токен
Настройка ИИ | ИИ может добавлять для вас серверы MCP и провайдеров моделей: сначала он показывает предпросмотр и спрашивает вас, как того требует режим разрешений
Плагины | Плагины добавляют инструменты и собственные страницы, например ИИ-браузер и статистику использования
RTK | Сжимает вывод команд и контекст Git, чтобы экономить токены, и подсчитывает экономию
Модели | OpenAI, Anthropic, Gemini и другие семейства протоколов, встроенные и пользовательские провайдеры, отдельные модели для разных задач
```
