Vulcan Code 0.1.1 では、アプリ内アップデート、新しいインストール方法、任意のユーザーサービスが加わりました。

### アプリ内アップデート

```ui-checklist
ok | 確認とダウンロード | サービスが新しいバージョンを確認し、変更のあったファイルだけをダウンロードし、署名の検証に通ってから切り替えます
ok | 確認後に再起動 | デスクトップアプリ、ブラウザー WebUI、TUI のいずれでも利用可能な更新が表示され、確認すると新しいバージョンで再起動します
ok | 自動ロールバック | 新しいバージョンが起動できない場合、ランチャーが前のバージョンに戻し、アプリでお知らせします
ok | フルアップデート | フルインストールが必要な場合、アプリがインストーラーをダウンロードして実行し、完了後に自動で開き直します
```

### インストールとサービス

```ui-cards
セットアップ | 新しい vulcan-code-setup は Windows、macOS、Linux でユーザー単位にインストールし、デスクトップアプリ、ターミナルクライアント、メニュー、デスクトップショートカットを選べます
ユーザーサービス | サインイン時にサービスを起動できます：Windows のスタートアップ項目、macOS の LaunchAgent、Linux の systemd ユーザーサービス
ポート範囲 | サービスが使うポート範囲はセットアップの詳細設定で変更できます
ターミナルクライアント | 実行中のサービスがない場合、TUI はデスクトップアプリと同じくインストール済みのサービスを起動します
```

```ui-callout info 0.1.0 からのアップグレード
0.1.0 にはまだアプリ内アップデートがないため、インストーラーまたはインストールコマンドを再実行して 0.1.1 に更新してください。以降のバージョンはアプリ内で更新できます。
```
