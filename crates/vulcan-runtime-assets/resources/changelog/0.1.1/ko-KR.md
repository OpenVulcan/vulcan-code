Vulcan Code 0.1.1에는 앱 내 업데이트, 새로운 설치 방법, 선택형 사용자 서비스가 추가되었습니다.

### 앱 내 업데이트

```ui-checklist
ok | 확인과 다운로드 | 서비스가 새 버전을 확인하고 바뀐 파일만 내려받으며, 서명 검증을 통과한 뒤에만 전환합니다
ok | 확인 후 재시작 | 데스크톱 앱, 브라우저 WebUI, TUI 모두 사용 가능한 업데이트를 표시하고, 확인하면 새 버전으로 다시 시작합니다
ok | 자동 롤백 | 새 버전이 시작되지 않으면 런처가 이전 버전으로 되돌리고 앱에서 알려 줍니다
ok | 전체 업데이트 | 전체 설치가 필요하면 앱이 설치 프로그램을 내려받아 실행하고, 끝나면 자동으로 다시 엽니다
```

### 설치와 서비스

```ui-cards
설치 프로그램 | 새 vulcan-code-setup은 Windows, macOS, Linux에서 사용자 단위로 설치하며 데스크톱 앱, 터미널 클라이언트, 메뉴, 바탕 화면 바로 가기를 선택할 수 있습니다
사용자 서비스 | 로그인할 때 서비스를 시작할 수 있습니다: Windows 시작 항목, macOS LaunchAgent, Linux systemd 사용자 서비스
포트 범위 | 서비스가 사용하는 포트 범위는 설치 프로그램의 고급 설정에서 바꿀 수 있습니다
터미널 클라이언트 | 실행 중인 서비스가 없으면 TUI가 데스크톱 앱처럼 설치된 서비스를 시작합니다
```

```ui-callout info 0.1.0에서 업그레이드
0.1.0에는 아직 앱 내 업데이트가 없으므로 설치 프로그램이나 설치 명령을 다시 실행해 0.1.1로 올리세요. 이후 버전은 앱 안에서 업데이트할 수 있습니다.
```
