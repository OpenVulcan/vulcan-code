Vulcan Code 0.1.1 加入應用程式內更新，並帶來新的安裝方式與可選的使用者服務。

### 應用程式內更新

```ui-checklist
ok | 檢查與下載 | 服務檢查新版本，只下載有變更的檔案，簽章驗證通過後才切換
ok | 確認後重新啟動 | 桌面應用程式、瀏覽器 WebUI 與 TUI 都會顯示可用更新，確認後重新啟動進入新版本
ok | 自動復原 | 新版本無法啟動時，啟動器自動切回上一版本並在應用程式中提示
ok | 完整更新 | 需要完整安裝時，應用程式下載並執行安裝程式，結束後自動重新開啟
```

### 安裝與服務

```ui-cards
安裝程式 | 新的 vulcan-code-setup 在 Windows、macOS 與 Linux 上依使用者安裝，可選桌面應用程式、終端機用戶端、選單與桌面捷徑
使用者服務 | 可以把服務註冊為目前使用者的登入啟動項目：Windows 啟動項目、macOS LaunchAgent 或 Linux systemd 使用者服務
連接埠範圍 | 服務使用的連接埠範圍可以在安裝程式的進階設定中修改
終端機用戶端 | TUI 找不到執行中的服務時自動啟動已安裝的服務，與桌面應用程式一致
```

```ui-callout info 從 0.1.0 升級
0.1.0 尚無應用程式內更新，請重新執行安裝程式或安裝命令升級到 0.1.1；之後的版本可以直接在應用程式內更新。
```
