В Vulcan Code 0.1.1 появились обновления внутри приложения, новый способ установки и необязательная пользовательская служба.

### Обновления внутри приложения

```ui-checklist
ok | Проверка и загрузка | Служба проверяет новые версии, загружает только изменившиеся файлы и переключается лишь после проверки подписей
ok | Перезапуск после подтверждения | Настольное приложение, WebUI в браузере и TUI показывают доступные обновления и после подтверждения перезапускаются в новой версии
ok | Автоматический откат | Если новая версия не запускается, лаунчер возвращает предыдущую, а приложение сообщает об этом
ok | Полные обновления | Когда нужна полная установка, приложение загружает и запускает установщик, а по завершении открывается снова
```

### Установка и служба

```ui-cards
Программа установки | Новый vulcan-code-setup устанавливает для текущего пользователя в Windows, macOS и Linux; по выбору — настольное приложение, терминальный клиент, пункты меню и ярлык на рабочем столе
Пользовательская служба | Службу можно запускать при входе в систему: элемент автозагрузки Windows, LaunchAgent в macOS или пользовательская служба systemd в Linux
Диапазон портов | Порты службы можно изменить в дополнительных настройках программы установки
Терминальный клиент | Если служба не запущена, TUI запускает установленную службу, как и настольное приложение
```

```ui-callout info Обновление с 0.1.0
В 0.1.0 ещё нет обновлений внутри приложения: запустите установщик или команду установки снова, чтобы перейти на 0.1.1; следующие версии обновляются внутри приложения.
```
