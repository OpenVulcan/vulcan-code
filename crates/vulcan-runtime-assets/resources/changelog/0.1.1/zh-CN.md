Vulcan Code 0.1.1 加入应用内更新，并带来新的安装方式与可选的用户服务。

### 应用内更新

```ui-checklist
ok | 检查与下载 | 服务检查新版本，只下载有变化的文件，签名校验通过后才切换
ok | 确认后重启 | 桌面应用、浏览器 WebUI 与 TUI 都会显示可用更新，确认后重启进入新版本
ok | 自动回退 | 新版本无法启动时，启动器自动切回上一版本并在应用中提示
ok | 完整更新 | 需要完整安装时，应用下载并运行安装包，结束后自动重新打开
```

### 安装与服务

```ui-cards
安装器 | 新的 vulcan-code-setup 在 Windows、macOS 与 Linux 上按用户安装，可选桌面应用、终端客户端、菜单与桌面快捷方式
用户服务 | 可以把服务注册为当前用户的登录启动项：Windows 启动项、macOS LaunchAgent 或 Linux systemd 用户服务
端口范围 | 服务使用的端口范围可以在安装器的高级设置中修改
终端客户端 | TUI 找不到运行中的服务时自动启动已安装的服务，与桌面应用一致
```

```ui-callout info 从 0.1.0 升级
0.1.0 还没有应用内更新，请重新运行安装包或安装命令升级到 0.1.1；之后的版本可以直接在应用内更新。
```
