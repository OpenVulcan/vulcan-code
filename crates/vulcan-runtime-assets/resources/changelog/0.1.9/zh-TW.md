Vulcan Code 0.1.9 修正了長工作階段傳送訊息後長時間停在請求中、無法停止的問題，並修正了 Linux 與 macOS 上的兩個桌面端問題。

### 更新到此版本

```ui-checklist
ok | 增量更新 | 從 0.1.8 更新時只下載有變化的檔案；更早的版本仍以完整更新的方式安裝
ok | 安裝器安裝 | 以安裝器安裝的版本請執行 vulcan-code-setup update 更新；應用程式會給出這項提示，而不是提供下載
```

### 工作階段

```ui-checklist
ok | 不再卡住 | 歷史分成多個分段的長工作階段（例如工具輸出很多的工作階段）傳送訊息後不再長時間停在請求中，停止按鈕也能立即生效
ok | 重新啟動後接續 | 重新啟動應用程式後，這類工作階段先前的回覆仍以模型的原始格式（包括思考內容）傳回模型，而不是退回為一般文字
```

### Linux 與 macOS

```ui-checklist
ok | 拖曳視窗 | 在 Linux 上，視窗從最大化還原後可以立即拖曳標題列移動視窗
ok | 內建瀏覽器 | 在 Linux 與 macOS 上，安裝後的內建瀏覽器可以正常使用
```
