Vulcan Code 0.1.9는 긴 세션에서 메시지를 보낸 뒤 요청 중 상태로 몇 분간 멈추고 중지할 수도 없던 문제를 고치고, Linux와 macOS의 데스크톱 앱 문제 두 가지를 고쳤습니다.

### 이 버전으로 업데이트

```ui-checklist
ok | 증분 업데이트 | 0.1.8에서 업데이트하면 바뀐 파일만 내려받습니다. 그보다 이전 버전은 계속 전체 업데이트로 설치됩니다
ok | 설치 프로그램으로 설치한 경우 | 설치 프로그램으로 설치한 버전은 vulcan-code-setup update로 업데이트합니다. 앱은 다운로드를 제공하는 대신 이를 안내합니다
```

### 세션

```ui-checklist
ok | 더 이상 멈추지 않음 | 기록이 여러 세그먼트에 걸친 긴 세션(도구 출력이 많은 세션 등)에서 메시지를 보낸 뒤 몇 분씩 기다리지 않으며, 중지 버튼도 바로 동작합니다
ok | 다시 시작한 뒤 | 앱을 다시 시작해도 이런 세션의 이전 응답은 사고 내용을 포함한 모델 고유의 형식으로 모델에 다시 전달되며, 일반 텍스트로 바뀌지 않습니다
```

### Linux와 macOS

```ui-checklist
ok | 창 이동 | Linux에서 최대화된 창을 복원한 직후에도 제목 표시줄로 창을 옮길 수 있습니다
ok | 내장 브라우저 | Linux와 macOS에서 설치된 내장 브라우저를 사용할 수 있습니다
```
