Vulcan Code 0.1.9 修复了长会话发送消息后长时间停在请求中、无法停止的问题，并修复了 Linux 与 macOS 上的两个桌面端问题。

### 更新到此版本

```ui-checklist
ok | 增量更新 | 从 0.1.8 更新时只下载有变化的文件；更早的版本仍以完整更新的方式安装
ok | 安装器安装 | 用安装器安装的版本请运行 vulcan-code-setup update 更新；应用会给出这一提示，而不是提供下载
```

### 会话

```ui-checklist
ok | 不再卡住 | 历史分成多个分段的长会话（例如工具输出很多的会话）发送消息后不再长时间停在请求中，停止按钮也能立即生效
ok | 重启后续接 | 重启应用后，这类会话此前的回复仍以模型的原始格式（包括思考内容）发回模型，而不是退回为普通文本
```

### Linux 与 macOS

```ui-checklist
ok | 拖动窗口 | 在 Linux 上，窗口从最大化恢复后可以立即拖动标题栏移动窗口
ok | 内置浏览器 | 在 Linux 与 macOS 上，安装后的内置浏览器可以正常使用
```
