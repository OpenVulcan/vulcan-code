Vulcan Code 0.1.9 исправляет длинные сеансы, которые после отправки сообщения по нескольку минут оставались на запросе и не останавливались, а также две проблемы настольного приложения в Linux и macOS.

### Обновление до этой версии

```ui-checklist
ok | Инкрементное обновление | При обновлении с 0.1.8 загружаются только изменённые файлы; более ранние версии по-прежнему устанавливаются полным обновлением
ok | Установки через установщик | Установки, сделанные программой установки, обновляются командой vulcan-code-setup update; приложение сообщает об этом вместо предложения загрузки
```

### Сеансы

```ui-checklist
ok | Без зависаний | Длинные сеансы, история которых занимает несколько сегментов, например с большим выводом инструментов, больше не ждут минутами после отправки сообщения, а кнопка остановки срабатывает сразу
ok | После перезапуска | После перезапуска приложения прежние ответы таких сеансов по-прежнему отправляются модели в её собственном формате вместе с рассуждениями, а не простым текстом
```

### Linux и macOS

```ui-checklist
ok | Перемещение окна | В Linux заголовок окна снова перемещает окно сразу после восстановления из развёрнутого состояния
ok | Встроенный браузер | В Linux и macOS установленный встроенный браузер работает
```
