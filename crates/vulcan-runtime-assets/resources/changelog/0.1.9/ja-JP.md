Vulcan Code 0.1.9 では、長いセッションでメッセージ送信後にリクエスト中のまま数分間止まり、停止もできなくなる問題を修正し、Linux と macOS のデスクトップアプリの問題を 2 つ修正しました。

### このバージョンへの更新

```ui-checklist
ok | 差分更新 | 0.1.8 からの更新では変更されたファイルだけをダウンロードします。それより前のバージョンは引き続き完全更新としてインストールされます
ok | セットアップによるインストール | セットアッププログラムでインストールした場合は vulcan-code-setup update で更新します。アプリはダウンロードを提示する代わりにその旨を表示します
```

### セッション

```ui-checklist
ok | 止まらなくなりました | 履歴が複数のセグメントにまたがる長いセッション（ツール出力の多いセッションなど）で、メッセージ送信後に数分間待たされることがなくなり、停止ボタンもすぐに効きます
ok | 再起動後 | アプリを再起動しても、こうしたセッションの以前の応答は思考内容を含むモデル本来の形式でモデルに送り返され、プレーンテキストには戻りません
```

### Linux と macOS

```ui-checklist
ok | ウィンドウの移動 | Linux で最大化から元に戻した直後でも、タイトルバーでウィンドウを移動できます
ok | 内蔵ブラウザー | Linux と macOS で、インストールした内蔵ブラウザーが使えるようになりました
```
