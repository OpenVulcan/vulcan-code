Vulcan Code 0.1.15 修正上下文壓縮遺失輸入的問題，並支援符合條件的未完成回合在手動壓縮後繼續。

### 上下文壓縮修正

```ui-checklist
ok | 保留完整輸入 | 壓縮請求保留完整的對話歷程、工具結果和原生媒體。完整輸入超過模型的上下文上限時會回報錯誤，避免根據遭裁剪的歷程產生摘要。
ok | 手動壓縮未完成回合 | 工作階段沒有活動請求時，可以對符合條件的未完成回合執行手動壓縮。壓縮保留原任務及排隊輸入，完成後可繼續原任務。
ok | 壓縮後傳送排隊訊息 | 手動壓縮期間，點選插入的排隊訊息會在壓縮成功後依點選順序自動傳送。壓縮失敗、停止或程序重新啟動時，訊息仍保留在佇列。
```

### 其他改進

```ui-checklist
ok | 子代理思考級別與佇列同步 | 子代理可指定目標模型支援的思考級別。修正子代理回傳、排隊輸入和待傳送面板之間的狀態同步。
ok | 按小時檢視用量 | 用量統計保留選取的時間範圍，並以小時呈現短時間範圍的用量。
ok | 桌面與介面修正 | 桌面端返回上一頁時，啟動載入頁不會重新出現。網頁端檔案提示視窗會配合視窗寬度，網頁端與終端機端都能正確顯示檢查結果中的 ok 狀態。
```
