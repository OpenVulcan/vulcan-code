В Vulcan Code 0.1.15 сжатие контекста сохраняет полный ввод и позволяет продолжить подходящие незавершённые ходы после ручного сжатия.

### Исправления сжатия контекста

```ui-checklist
ok | Полный ввод при сжатии | Запрос на создание сводки сохраняет полную историю разговора, результаты инструментов и исходные медиафайлы. Если полный ввод превышает предел контекста модели, сжатие сообщает об ошибке и сохраняет историю.
ok | Ручное сжатие незавершённых ходов | Подходящие незавершённые ходы можно сжимать вручную, пока нет активного запроса. Исходная задача и ввод в очереди сохраняются, поэтому после сжатия работу можно продолжить.
ok | Сообщения из очереди после сжатия | Сообщения из очереди, выбранные для вставки во время ручного сжатия, отправляются в порядке выбора после успешного завершения сжатия. При сбое или остановке сжатия, а также при перезапуске процесса сообщения остаются в очереди.
```

### Другие улучшения

```ui-checklist
ok | Уровень рассуждений субагентов и очередь | Субагенты могут использовать уровень рассуждений, поддерживаемый целевой моделью. Результаты субагентов, ввод в очереди и панель ожидающих сообщений остаются синхронизированными.
ok | Почасовая статистика использования | Статистика использования сохраняет выбранный период и показывает почасовые данные для коротких периодов.
ok | Исправления приложения и интерфейса | При возврате назад в настольном приложении экран загрузки больше не открывается. В веб-интерфейсе диалоги о файлах подстраиваются под ширину окна, а веб-клиент и терминальный клиент показывают результаты ok как успешные проверки.
```
