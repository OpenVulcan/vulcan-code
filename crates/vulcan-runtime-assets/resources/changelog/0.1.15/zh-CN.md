Vulcan Code 0.1.15 修复上下文压缩丢失输入的问题，并支持对符合条件的未完成回合手动压缩后继续。

### 上下文压缩修复

```ui-checklist
ok | 保留完整输入 | 压缩请求保留完整的对话历史、工具结果和原生媒体。完整输入超出模型上下文上限时会报告错误，避免基于被裁剪的历史生成摘要。
ok | 手动压缩未完成回合 | 会话没有活动请求时，可以对符合条件的未完成回合执行手动压缩。压缩保留原任务和排队输入，完成后可继续原任务。
ok | 压缩后发送排队消息 | 手动压缩期间，点击插入的排队消息会在压缩成功后按点击顺序自动发送。如果压缩失败、停止或进程重启，消息仍保留在队列。
```

### 其他改进

```ui-checklist
ok | 子代理思考档位与队列同步 | 子代理可指定目标模型支持的思考档位。修复子代理返回、排队输入和待发送面板之间的状态同步。
ok | 按小时查看用量 | 用量统计保留已选时间范围，短时间范围按小时绘制用量。
ok | 桌面与界面修复 | 桌面端后退时不会重新打开启动加载页。网页端文件提示框适应窗口宽度，网页端与终端端都能正确显示检查结果中的 ok 状态。
```
