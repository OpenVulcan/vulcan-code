Vulcan Code 0.1.15에서는 컨텍스트 압축에서 전체 입력을 유지하고, 조건을 충족하는 미완료 턴은 수동 압축 후 이어서 진행할 수 있습니다.

### 컨텍스트 압축 수정

```ui-checklist
ok | 압축 시 전체 입력 유지 | 요약 요청에 전체 대화 기록, 도구 결과, 네이티브 미디어를 유지합니다. 전체 입력이 모델의 컨텍스트 한도를 초과하면 오류를 표시하고 기록을 보존합니다.
ok | 미완료 턴 수동 압축 | 실행 중인 요청이 없으면 조건을 충족하는 미완료 턴을 수동으로 압축할 수 있습니다. 원래 작업과 대기 중인 입력이 유지되므로 압축 후 작업을 이어서 진행할 수 있습니다.
ok | 압축 후 대기 메시지 전송 | 수동 압축 중 삽입을 선택한 대기 메시지는 압축이 성공한 후 선택한 순서대로 전송됩니다. 압축이 실패하거나 중지되거나 프로세스가 재시작되면 메시지는 대기열에 남습니다.
```

### 기타 개선

```ui-checklist
ok | 하위 에이전트 추론 수준과 대기열 | 하위 에이전트는 대상 모델이 지원하는 추론 수준을 지정할 수 있습니다. 하위 에이전트의 결과, 대기 입력, 전송 대기 패널의 상태가 일치하도록 수정했습니다.
ok | 시간대별 사용량 | 사용량 통계는 선택한 기간을 유지하고 짧은 기간의 사용량을 시간 단위로 표시합니다.
ok | 데스크톱과 인터페이스 수정 | 데스크톱 앱에서 뒤로 가도 시작 로딩 화면이 다시 열리지 않습니다. 웹 파일 알림창이 창 너비에 맞춰지며, 웹과 터미널에서 ok 검사 결과가 성공으로 표시됩니다.
```
