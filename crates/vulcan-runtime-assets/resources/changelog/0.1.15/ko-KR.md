### 컨텍스트 압축 수정

- 요약 요청에 전체 대화 기록, 도구 결과, 네이티브 미디어를 유지합니다. 전체 입력이 모델의 컨텍스트 한도를 초과하면 오류를 표시하고 기록을 보존합니다.
- 실행 중인 요청이 없으면 조건을 충족하는 미완료 턴을 수동으로 압축할 수 있습니다. 원래 작업과 대기 중인 입력이 유지되므로 압축 후 작업을 이어서 진행할 수 있습니다.

### 기타 개선

- 하위 에이전트는 대상 모델이 지원하는 추론 수준을 지정할 수 있습니다. 하위 에이전트의 결과, 대기 입력, 전송 대기 패널의 상태가 일치하도록 수정했습니다.
- 사용량 통계는 선택한 기간을 유지하고 짧은 기간의 사용량을 시간 단위로 표시합니다.
- 데스크톱 앱에서 뒤로 가도 시작 로딩 화면이 다시 열리지 않습니다. 웹 파일 알림창이 창 너비에 맞춰지며, 웹과 터미널에서 `ok` 검사 결과가 성공으로 표시됩니다.
