Vulcan Code 0.1.15 では、コンテキスト圧縮で入力全体を保持し、条件を満たす未完了のターンを手動圧縮後に再開できるようにしました。

### コンテキスト圧縮の修正

```ui-checklist
ok | 圧縮時に入力全体を保持 | 要約リクエストに会話履歴全体、ツールの結果、ネイティブメディアを保持します。完全な入力がモデルのコンテキスト上限を超えた場合はエラーを表示し、履歴を保持します。
ok | 未完了ターンの手動圧縮 | 実行中のリクエストがなければ、条件を満たす未完了のターンを手動で圧縮できます。元のタスクとキューに入っている入力は保持され、圧縮後にタスクを再開できます。
ok | 圧縮後の送信待ちメッセージ | 手動圧縮中に挿入を選んだ送信待ちメッセージは、圧縮が正常に完了した後に選択した順序で送信されます。圧縮の失敗や停止、プロセスの再起動時にはキューに残ります。
```

### その他の改善

```ui-checklist
ok | サブエージェントの推論レベルとキュー | サブエージェントは対象モデルが対応する推論レベルを指定できます。サブエージェントの結果、キュー内の入力、送信待ちパネルの状態が同期するよう修正しました。
ok | 時間単位の使用量 | 使用量統計は選択した期間を保持し、短い期間の使用量を時間単位で表示します。
ok | デスクトップと画面表示の修正 | デスクトップアプリで前の画面に戻っても起動画面が再表示されません。Web のファイル確認ダイアログはウィンドウ幅に合わせて調整され、Web とターミナルでは ok の検査結果が成功として表示されます。
```
