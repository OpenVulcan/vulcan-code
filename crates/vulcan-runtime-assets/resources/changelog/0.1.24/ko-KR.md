Vulcan Code 0.1.24는 첨부 파일 처리와 모델 전환 시 대화 복구를 개선하고, 내장 브라우저와 터미널 로그의 문제를 수정했습니다.

### 대화 및 입력

```ui-checklist
ok | 파일 끌어다 놓기와 붙여넣기 | 첨부 파일 미리보기를 복원했습니다. 모델이 업로드할 수 없는 파일도 원래 경로를 확인할 수 있으면 참조로 보낼 수 있습니다. 보낸 파일 참조는 본문과 별도로 펼칠 수 있습니다.
ok | 모델 전환 및 복구 | 모델을 바꿔도 기존 대화 기록을 보존합니다. 추론을 안전하게 재생할 수 없으면 화면에 보이는 메시지를 새 대화 초안으로 가져와 검토 후 보낼 수 있습니다.
ok | 압축 표시 및 스크롤 | 진행 중인 컨텍스트 압축을 별도로 표시합니다. 대화의 맨 아래를 따라가는 동안 새 텍스트가 계속 보입니다.
```

### 내장 브라우저

```ui-checklist
ok | 페이지 표시 및 편집 | 스타일시트와 팝업 리소스 로딩을 수정하고 편집을 개선했습니다. 웹페이지에서 비밀번호 표시를 전환해도 내장 브라우저에서는 비밀번호를 가립니다.
```

### 로그 및 공급자

```ui-checklist
ok | 터미널 로그 | 줄바꿈과 잘린 출력에 걸친 비밀 값의 마스킹을 개선했습니다. 마스킹을 사용할 수 없을 때도 백그라운드 작업을 중지할 수 있습니다.
ok | 공급자 오류 | 오류 카드에 읽기 쉬운 메시지와 도움말 링크를 유지하고, 자격 증명이 들어간 URL을 가립니다.
ok | 공급자 호환성 | Alibaba Cloud Model Studio Token Plan은 임시 OSS 업로드를 시도하지 않습니다. OpenVulcan 임베딩을 쓰는 지식 베이스 요청을 수정했습니다.
```
