Vulcan Code 0.1.24 улучшает работу с вложениями и восстановление бесед при смене модели, а также исправляет встроенный браузер и журналы терминала.

### Беседы и ввод

```ui-checklist
ok | Перетаскивание и вставка файлов | Восстановлен предпросмотр вложений. Если известен исходный путь, файл, который модель не может загрузить, можно отправить как ссылку на файл. Отправленные ссылки раскрываются отдельно от текста сообщения.
ok | Смена модели и восстановление | При смене модели исходная история сохраняется. Если рассуждения нельзя безопасно воспроизвести, видимые сообщения можно перенести в черновик новой беседы и проверить перед отправкой.
ok | Сжатие контекста и прокрутка | Текущее сжатие контекста отображается отдельно. При прокрутке вслед за концом беседы новый текст остаётся виден.
```

### Встроенный браузер

```ui-checklist
ok | Отображение и редактирование | Исправлена загрузка таблиц стилей и ресурсов всплывающих окон, улучшено редактирование. Во встроенном браузере пароли остаются скрытыми, когда страница переключает их видимость.
```

### Журналы и поставщики моделей

```ui-checklist
ok | Журналы терминала | Улучшено маскирование сохранённых секретов на переносах строк и в обрезанном выводе. Фоновые задания можно остановить, даже если маскирование недоступно.
ok | Ошибки поставщика | Карточки сохраняют читаемые сообщения и ссылки на справку и скрывают URL с учётными данными.
ok | Совместимость с поставщиками | Alibaba Cloud Model Studio Token Plan больше не пытается временно загружать файлы в OSS. Исправлены запросы баз знаний, использующих эмбеддинги OpenVulcan.
```
