Vulcan Code 0.1.24 改善附件處理和切換模型時的對話復原，並修正內建瀏覽器與終端機記錄的問題。

### 對話與輸入

```ui-checklist
ok | 拖放與貼上檔案 | 恢復附件預覽。模型無法上傳的檔案若有原始路徑，仍可當成參照傳送。已傳送的檔案參照可在正文外展開。
ok | 切換模型與復原 | 切換模型時保留原對話歷史。遇到無法安全重播的推理記錄，可將可見的問答帶到新對話的草稿，確認後再送出。
ok | 壓縮與捲動 | 進行中的脈絡壓縮會獨立顯示。跟隨底部時，新產生的內容會持續顯示。
```

### 內建瀏覽器

```ui-checklist
ok | 網頁顯示與操作 | 修正樣式和彈出視窗資源的載入，改善輸入與編輯。即使網頁切換密碼可見性，內建瀏覽器仍會遮住密碼。
```

### 日誌與模型服務

```ui-checklist
ok | 終端機日誌 | 改善歷史日誌的遮蔽，涵蓋跨行和裁切邊界的密鑰值。暫時無法遮蔽時，仍可停止背景工作。
ok | 上游錯誤 | 錯誤卡會保留供應商可讀的訊息與說明連結，並遮蔽含有憑證的網址。
ok | 供應商相容性 | 阿里雲百煉 Token Plan 不再嘗試暫存 OSS 上傳。修正使用 OpenVulcan 嵌入服務的知識庫請求。
```
