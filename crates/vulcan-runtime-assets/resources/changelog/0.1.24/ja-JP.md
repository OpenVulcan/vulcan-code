Vulcan Code 0.1.24 では、添付ファイルとモデル切り替え時の会話復旧を改善し、内蔵ブラウザーと端末ログの問題を修正しました。

### 会話と入力

```ui-checklist
ok | ファイルのドロップと貼り付け | 添付ファイルのプレビューを復元しました。モデルがアップロードできないファイルも、元のパスを取得できる場合は参照として送信できます。送信済みの参照は本文とは別に展開できます。
ok | モデル切り替えと復旧 | モデルを切り替えても元の会話履歴を保持します。推論を安全に再生できない場合は、表示されているメッセージを新しい会話の下書きに移し、確認してから送信できます。
ok | 圧縮表示とスクロール | 実行中のコンテキスト圧縮を別に表示します。会話の末尾を追従している間は新しいテキストが表示され続けます。
```

### 内蔵ブラウザー

```ui-checklist
ok | ページ表示と編集 | スタイルシートやポップアップのリソース読み込みを修正し、編集を改善しました。ページがパスワードの表示を切り替えても、内蔵ブラウザーではマスクを維持します。
```

### ログとプロバイダー

```ui-checklist
ok | 端末ログ | 改行を含む値や出力の切り詰め箇所に対する秘密情報のマスクを改善しました。マスク処理が利用できない場合でもバックグラウンドジョブを停止できます。
ok | プロバイダーエラー | エラーカードに読みやすいメッセージとヘルプリンクを残し、認証情報を含む URL をマスクします。
ok | プロバイダーの互換性 | Alibaba Cloud Model Studio の Token Plan では一時 OSS アップロードを試行しなくなりました。OpenVulcan の埋め込みを使うナレッジベースのリクエストを修正しました。
```
