Vulcan Code 0.1.24 改进了附件处理和切换模型时的会话恢复，并修复了内置浏览器和终端日志的问题。

### 会话与输入

```ui-checklist
ok | 拖放与粘贴文件 | 恢复附件预览。模型不支持上传、但客户端能取得原始路径的文件可作为引用发送。已发送的文件引用可在正文之外展开。
ok | 切换模型与恢复 | 切换模型时保留原会话历史。遇到无法安全回放的推理记录时，可以把可见问答带到新会话的草稿里，检查后再发送。
ok | 压缩与滚动 | 进行中的上下文压缩单独显示，跟随底部时会继续显示新生成的内容。
```

### 内置浏览器

```ui-checklist
ok | 页面显示与交互 | 修复样式和弹出窗口资源的加载，改善输入和编辑。网页切换密码可见性时，内置浏览器仍会遮盖密码。
```

### 日志与模型服务

```ui-checklist
ok | 终端日志 | 改进历史日志的脱敏，覆盖跨行和裁剪边界处的密钥值。即使暂时无法脱敏，仍可停止后台任务。
ok | 上游错误 | 错误卡保留供应商的可读消息和帮助链接，并遮盖携带凭据的 URL。
ok | 供应商兼容性 | 阿里云百炼 Token Plan 不再尝试临时 OSS 上传。修复使用 OpenVulcan 嵌入服务时的知识库请求。
```
