Vulcan Code 0.1.20에는 OpenVulcan 클라우드 음성 받아쓰기와 프로젝트 연결 폴더가 추가되었으며, 대기 중인 턴의 복구와 공급자 오류 진단이 개선되었습니다.

### 음성 입력 및 작업 공간

```ui-checklist
ok | 클라우드 음성 받아쓰기 | 서비스를 제공하는 사이트에서 OpenVulcan에 로그인하면 사용할 수 있습니다. 마이크 설정에서 사이트 추천 모델, 원하는 클라우드 모델 또는 설정된 공급자의 음성 인식 모델을 선택할 수 있습니다.
ok | 녹음 단축키 | 음성 입력 단축키를 지정하고 인식 언어와 모델이 지원하는 옵션을 선택할 수 있습니다.
ok | 프로젝트 연결 폴더 | 프로젝트 홈에서 로컬 폴더를 추가하면 파일 패널에서 탐색하거나 대화에서 파일을 열 수 있습니다. 연결된 Git 저장소는 프로젝트 변경 목록에 표시됩니다.
```

### 대화 및 메모리

```ui-checklist
ok | 대기 중인 턴 복구 | 저장된 턴은 기존 제출 ID와 설정을 유지한 채 다시 실행됩니다. 기존 대화의 목표도 한 번만 시작됩니다.
ok | 대화 분기 | 대화가 실행 중일 때 완료된 턴에서 분기를 만들 수 있습니다. 실행이 끝나면 대화에 남아 있는 도구 카드에 최종 상태가 표시됩니다.
ok | 메모리 벡터 재구축 | 임베딩 모델이 요청당 받을 수 있는 입력 수에 맞춰 일괄 처리합니다. 미리 보기에 실제 실행과 동일한 배치 수가 표시됩니다.
```

### 모델 및 오류 진단

```ui-checklist
ok | 공급자 모델 검색 | 선택한 내장 공급자 계정에서 대화 모델 후보를 가져와 새 모델 양식에 선택한 정보를 채울 수 있습니다.
ok | Alibaba Cloud 모델 | Token Plan에 Qwen4.0 Max Preview를 추가하고 베이징과 싱가포르의 Model Studio 엔드포인트에 Qwen3.8 모델을 추가했습니다.
ok | 오류 세부 정보 및 재시도 | 오류 카드에 요약을 표시하며 전체 JSON을 복사하거나 현재 오류를 재시도 목록에 추가할 수 있습니다. 각 규칙은 개별 편집이 가능하며 키워드와 정규식을 지원합니다.
```
