Vulcan Code 0.1.20 では、OpenVulcan のクラウド文字起こしとプロジェクトの追加フォルダーに対応し、キューの復元とプロバイダーのエラー調査を改善しました。

### 音声入力とワークスペース

```ui-checklist
ok | クラウド文字起こし | サービスを提供するサイトで OpenVulcan にサインインすると利用できます。マイク設定で、サイトの推奨モデル、任意のクラウドモデル、設定済みプロバイダーの音声認識モデルを選べます。
ok | 録音ショートカット | 音声入力のショートカットを設定し、認識言語やモデルが対応するオプションを選べます。
ok | プロジェクトの追加フォルダー | プロジェクトのホームからローカルフォルダーを追加し、ファイルパネルで閲覧したり、会話からファイルを開いたりできます。追加した Git リポジトリはプロジェクトの変更一覧に表示されます。
```

### 会話とメモリ

```ui-checklist
ok | キューの復元 | 保存済みのターンは、元の送信 ID と設定を使って再開します。既存の会話のゴールも一度だけ開始されます。
ok | 会話の分岐 | 会話の実行中に、完了済みのターンから分岐できます。会話内のツールカードは実行終了後に最終状態を表示します。
ok | メモリベクトルの再構築 | 埋め込みモデルが 1 回のリクエストで受け付ける件数に合わせて処理し、プレビューに実行時と同じバッチ数を表示します。
```

### モデルとトラブルシューティング

```ui-checklist
ok | プロバイダーのモデル検索 | 選択した組み込みプロバイダーのアカウントから会話モデルの候補を取得し、選択内容を新規モデルのフォームに入力できます。
ok | Alibaba Cloud のモデル | Token Plan に Qwen4.0 Max Preview、北京とシンガポールの Model Studio エンドポイントに Qwen3.8 シリーズを追加しました。
ok | エラー詳細と再試行 | エラーカードに要約を表示し、完全な JSON のコピーや現在のエラーの再試行リストへの追加ができます。ルールは個別に編集でき、キーワードと正規表現に対応します。
```
