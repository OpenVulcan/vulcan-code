Vulcan Code 0.1.20 新增 OpenVulcan 雲端語音轉錄和專案附加資料夾，並改善佇列回合復原及供應商錯誤排查。

### 語音輸入與工作區

```ui-checklist
ok | 雲端語音轉錄 | 在提供服務的站點登入 OpenVulcan 後即可使用。麥克風設定可選擇站點推薦模型、指定雲端模型，或已設定供應商的語音辨識模型。
ok | 錄音快速鍵 | 可自訂語音輸入快速鍵，並選擇辨識語言與模型支援的參數。
ok | 專案附加資料夾 | 從專案首頁加入其他本機資料夾，即可在檔案面板瀏覽，並從對話開啟檔案。附加的 Git 儲存庫會出現在專案變更清單中。
```

### 對話與記憶

```ui-checklist
ok | 復原佇列回合 | 已儲存的佇列回合會沿用原本的提交識別與設定繼續執行。既有對話中的目標也只會啟動一次。
ok | 對話分支 | 對話仍在執行時，可從已完成的回合建立分支。工具執行結束後，保留在對話中的工具卡會顯示最終狀態。
ok | 重建記憶向量 | 依照嵌入模型單次請求允許的輸入數量分批，預覽批次數與實際執行一致。
```

### 模型與錯誤排查

```ui-checklist
ok | 探索供應商模型 | 可從所選的內建供應商帳戶取得候選對話模型，並將選擇填入新增模型表單。
ok | 阿里雲模型 | Token Plan 新增 Qwen4.0 Max Preview，百煉北京和新加坡端點新增 Qwen3.8 系列模型。
ok | 錯誤詳情與重試 | 錯誤卡提供摘要，可複製完整 JSON 或將目前錯誤加入重試清單。重試規則可逐條編輯，支援關鍵字和正規表示式。
```
