Vulcan Code 0.1.20 新增 OpenVulcan 云端语音转写和项目附属文件夹，并改进会话排队恢复与供应商错误排查。

### 语音输入与工作区

```ui-checklist
ok | 云端语音转写 | 在开通服务的站点登录 OpenVulcan 后，可用云端转写。麦克风设置可选站点推荐模型、指定云端模型或已配置供应商的语音识别模型。
ok | 录音快捷键 | 在语音输入设置中自定义快捷键，也可选择识别语言和模型支持的识别参数。
ok | 项目附属文件夹 | 在项目首页添加其他本机目录，可在文件面板中浏览并从会话打开其中的文件。附属 Git 仓库会出现在项目的变更列表中。
```

### 会话与记忆

```ui-checklist
ok | 恢复排队消息 | 已保存的排队回合恢复派发时沿用原来的提交身份和设置，已有会话的目标也只启动一次。
ok | 会话分支 | 会话仍在运行时，可以从已经完成的回合创建分支。工具执行结束后，保留在会话中的工具卡会显示最终状态。
ok | 记忆向量重建 | 按嵌入模型每次允许的输入数量分批处理，预览中的批次数与执行一致。
```

### 模型与错误排查

```ui-checklist
ok | 供应商模型发现 | 可从所选系统供应商账户获取候选对话模型，并将选择填入新增模型表单。
ok | 阿里云模型 | Token Plan 新增 Qwen4.0 Max Preview，百炼北京和新加坡入口新增 Qwen3.8 系列模型。
ok | 错误详情与重试 | 错误卡显示简要诊断，可一键复制完整 JSON 或把当前错误加入重试列表。重试规则支持逐条编辑，可用关键词或正则表达式匹配。
```
