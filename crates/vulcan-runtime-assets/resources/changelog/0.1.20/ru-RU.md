В Vulcan Code 0.1.20 появились облачная расшифровка речи OpenVulcan и подключаемые папки проекта. Также улучшены восстановление очереди и диагностика ошибок провайдеров.

### Голосовой ввод и рабочая область

```ui-checklist
ok | Облачная расшифровка речи | Войдите в OpenVulcan на сайте, где доступна эта услуга. В настройках микрофона можно выбрать рекомендованную сайтом модель, конкретную облачную модель или модель распознавания речи настроенного провайдера.
ok | Горячая клавиша записи | Настройте сочетание клавиш для голосового ввода, выберите язык распознавания и параметры, поддерживаемые моделью.
ok | Подключаемые папки проекта | Добавляйте локальные папки с главной страницы проекта, просматривайте их в панели файлов и открывайте файлы из бесед. Подключённые репозитории Git появятся в списке изменений проекта.
```

### Беседы и память

```ui-checklist
ok | Восстановление очереди | Сохранённые шаги беседы возобновляются с исходным идентификатором отправки и прежними настройками. Цели в существующих беседах также запускаются один раз.
ok | Ветвление бесед | Создавайте ветки от завершённых шагов во время выполнения беседы. Карточки инструментов в беседе показывают итоговое состояние после завершения работы.
ok | Перестроение векторов памяти | Размер пакета учитывает число элементов, которое модель эмбеддингов принимает за запрос. В предварительном просмотре указано число пакетов, используемое при перестроении.
```

### Модели и диагностика ошибок

```ui-checklist
ok | Поиск моделей провайдера | Получайте список моделей для бесед из выбранной учётной записи встроенного провайдера и заполняйте форму новой модели данными выбранного варианта.
ok | Модели Alibaba Cloud | В Token Plan добавлена Qwen4.0 Max Preview. В Model Studio для Пекина и Сингапура добавлены модели Qwen3.8.
ok | Подробности ошибок и повторные попытки | Карточки показывают краткую диагностику, позволяют скопировать полный JSON и добавить текущую ошибку в список повторных попыток. Правила редактируются по отдельности и поддерживают ключевые слова и регулярные выражения.
```
