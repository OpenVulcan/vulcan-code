Vulcan Code 0.1.12 では、再インストールが必要な更新もアプリ内で完了するようになり、macOS のウィンドウボタンとアイコン、一部のプロバイダーがタイトルや検証のリクエストを拒否する問題を修正しました。

### このバージョンへの更新

```ui-checklist
ok | 差分更新 | 0.1.8 から 0.1.11 までからの更新では変更されたファイルだけをダウンロードします。それより前のバージョンは引き続き完全更新でインストールされます
ok | 再インストールもアプリ内で完了 | 今後、再インストールが必要な更新でも公式サイトへは移動しません。変更されたファイルだけをダウンロードし、インストール済みのブラウザー、Electron、Node などの基本リソースはそのまま再利用し、再起動時にセットアッププログラムが更新を完了します
ok | Windows インストーラー版 | Windows インストーラーでインストールしたコピーでは、このような更新に完全なインストーラーではなく小さな署名済み更新パッケージを使います
```

### インターフェース

```ui-checklist
ok | macOS のウィンドウボタン | システムのウィンドウボタンだけを残し、最小化・最大化・閉じるが二重に表示されなくなりました。緑のボタンでシステムのタイル表示とフルスクリーンのメニューが再び使えます
ok | macOS のアイコン | Dock と未起動時のアイコンが他のアプリと同じ大きさになりました
ok | モデルサービスのアカウントカード | カードにインターフェースの拡大率に従う最小幅を設け、クォータの行が複数行に折り返されなくなりました
ok | セットアップガイド | OpenVulcan にサインインしていて判定モデルが未設定の場合、判定のステップでクラウド判定モデルがあらかじめ選択されます。確認するまで保存されません
```

### モデルとプロバイダー

```ui-checklist
ok | リクエストの修正 | セッションタイトル、設定でのモデル検証、専任アシスタントのプロンプト下書きがキャッシュスコープを送るようになり、OpenCode Go が 400 を返したり、Codex Responses Lite が拒否したりしなくなりました
ok | クラウドプラットフォーム | CommandCode、OpenCode Go、Open Design、OpenRouter、TokenRhythm をクラウドプラットフォームに分類しました。共有のモデル情報は公式、クラウドプラットフォーム、中継の順に採用します
ok | コアモデル一覧 | モデル自体の機能と上限はコアモデル一覧に一度だけ記録され、各プロバイダーのルールがそれを継承します。プロバイダーマニフェストの状態ページは、そこから継承したフィールドを示します
```
