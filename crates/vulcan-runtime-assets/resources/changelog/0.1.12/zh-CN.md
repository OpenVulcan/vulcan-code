Vulcan Code 0.1.12 让需要重新安装的更新也在应用内完成，并修复了 macOS 窗口按钮与图标，以及部分供应商拒绝标题和验证请求的问题。

### 更新到此版本

```ui-checklist
ok | 增量更新 | 从 0.1.8 至 0.1.11 更新时只下载有变化的文件；更早的版本仍以完整更新的方式安装
ok | 应用内完成重新安装 | 今后需要重新安装的更新不再转到官网下载：只下载有变化的文件，已安装的浏览器、Electron、Node 等基础资源直接复用，重启后由安装程序自动完成
ok | Windows 安装版 | 由 Windows 安装器安装的副本，今后的此类更新使用小型签名更新包，不再下载完整安装器
```

### 界面

```ui-checklist
ok | macOS 窗口按钮 | 只保留系统的窗口按钮，不再重复显示自绘的最小化、最大化与关闭按钮，绿色按钮恢复系统的平铺与全屏菜单
ok | macOS 图标 | 程序坞与未运行时的应用图标与其他应用大小一致
ok | 模型服务账户卡片 | 卡片有了随界面缩放的最小宽度，额度行不再挤成多行
ok | 设置向导 | 已登录 OpenVulcan 账户且尚未配置判定模型时，判定步骤默认选中云端判定模型；确认前不会保存
```

### 模型与供应商

```ui-checklist
ok | 请求修复 | 会话标题、设置中的模型验证与专职助手的提示词草拟现在带上缓存范围，OpenCode Go 不再返回 400，Codex Responses Lite 也不再拒绝这些请求
ok | 云平台分类 | CommandCode、OpenCode Go、Open Design、OpenRouter 与 TokenRhythm 归为云平台；共享的模型信息按官方、云平台、中转的顺序采用
ok | 核心模型清单 | 模型本身的能力与上限统一记录在核心模型清单中，由各供应商规则继承；供应商清单状态页会标出继承自核心清单的字段
```
