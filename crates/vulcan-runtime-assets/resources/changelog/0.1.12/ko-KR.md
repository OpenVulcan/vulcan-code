Vulcan Code 0.1.12는 다시 설치해야 하는 업데이트도 앱 안에서 마치고, macOS 창 버튼과 아이콘, 일부 공급자가 제목 및 검증 요청을 거부하던 문제를 고칩니다.

### 이 버전으로 업데이트

```ui-checklist
ok | 증분 업데이트 | 0.1.8부터 0.1.11까지에서 업데이트하면 변경된 파일만 내려받습니다. 그 이전 버전은 계속 전체 업데이트로 설치됩니다
ok | 앱 안에서 재설치 완료 | 앞으로 다시 설치해야 하는 업데이트도 웹사이트로 보내지 않습니다. 변경된 파일만 내려받고 이미 설치된 브라우저, Electron, Node 같은 기본 리소스는 그대로 재사용하며, 다시 시작할 때 설치 프로그램이 업데이트를 마칩니다
ok | Windows 설치 프로그램 사본 | Windows 설치 프로그램으로 설치한 사본은 이런 업데이트를 전체 설치 프로그램 대신 작은 서명된 업데이트 패키지로 받습니다
```

### 인터페이스

```ui-checklist
ok | macOS 창 버튼 | 시스템 창 버튼만 남겨 최소화, 최대화, 닫기 버튼이 두 번 보이지 않으며, 녹색 버튼에서 시스템 타일 배치와 전체 화면 메뉴를 다시 쓸 수 있습니다
ok | macOS 아이콘 | Dock과 앱이 꺼져 있을 때의 아이콘 크기가 다른 앱과 같아졌습니다
ok | 모델 서비스 계정 카드 | 카드에 인터페이스 배율을 따르는 최소 너비가 생겨 할당량 행이 여러 줄로 접히지 않습니다
ok | 설정 가이드 | OpenVulcan에 로그인되어 있고 판정 모델이 설정되지 않았으면 판정 단계에서 클라우드 판정 모델이 미리 선택됩니다. 확인하기 전에는 저장되지 않습니다
```

### 모델과 공급자

```ui-checklist
ok | 요청 수정 | 세션 제목, 설정의 모델 검증, 전담 어시스턴트의 프롬프트 초안 작성이 이제 캐시 범위를 보내므로 OpenCode Go가 400을 반환하거나 Codex Responses Lite가 거부하지 않습니다
ok | 클라우드 플랫폼 | CommandCode, OpenCode Go, Open Design, OpenRouter, TokenRhythm을 클라우드 플랫폼으로 분류했습니다. 공유 모델 정보는 공식, 클라우드 플랫폼, 중계 순으로 채택합니다
ok | 핵심 모델 목록 | 모델 자체의 기능과 한도는 핵심 모델 목록에 한 번만 기록되고 각 공급자 규칙이 이를 상속합니다. 공급자 매니페스트 상태 페이지는 여기서 상속한 필드를 표시합니다
```
