Vulcan Code 0.1.12 завершает внутри приложения обновления, требующие переустановки, и исправляет кнопки окна и значок в macOS, а также запросы заголовков и проверки, которые отклоняли некоторые провайдеры.

### Обновление до этой версии

```ui-checklist
ok | Инкрементное обновление | При обновлении с версий от 0.1.8 до 0.1.11 загружаются только изменённые файлы; более ранние версии по-прежнему устанавливаются полным обновлением
ok | Переустановка внутри приложения | Будущие обновления, требующие переустановки, больше не отправляют вас на сайт: загружаются только изменённые файлы, установленные базовые ресурсы — браузер, Electron, Node — используются повторно, а программа установки завершает обновление при перезапуске
ok | Копии, установленные установщиком Windows | Копия, установленная установщиком Windows, получает такие обновления в виде небольшого подписанного пакета обновления вместо полного установщика
```

### Интерфейс

```ui-checklist
ok | Кнопки окна в macOS | Остались только системные кнопки окна, поэтому «свернуть», «развернуть» и «закрыть» больше не показываются дважды, а зелёная кнопка снова открывает системное меню мозаики и полноэкранного режима
ok | Значок в macOS | Значок в Dock и у закрытого приложения теперь того же размера, что и у других приложений
ok | Карточки учётных записей сервисов моделей | У карточек появилась минимальная ширина, учитывающая масштаб интерфейса, поэтому строки квот больше не переносятся на несколько строк
ok | Мастер настройки | Если вы вошли в OpenVulcan и модель-арбитр не настроена, на шаге арбитра заранее выбрана облачная модель; ничего не сохраняется, пока вы не подтвердите
```

### Модели и провайдеры

```ui-checklist
ok | Исправленные запросы | Заголовки сеансов, проверка модели в настройках и черновики промптов для выделенных ассистентов теперь передают область кэша, поэтому OpenCode Go больше не возвращает 400, а Codex Responses Lite их не отклоняет
ok | Облачные платформы | CommandCode, OpenCode Go, Open Design, OpenRouter и TokenRhythm отнесены к облачным платформам; общие сведения о моделях берутся сначала у официальных провайдеров, затем у облачных платформ, затем у посредников
ok | Список базовых моделей | Возможности и ограничения самой модели записаны один раз в списке базовых моделей, который наследуют правила провайдеров; страница состояния манифестов провайдеров отмечает унаследованные из него поля
```
