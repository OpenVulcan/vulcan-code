Vulcan Code 0.1.3 behebt zwei Details der In-App-Updates.

### In-App-Updates

```ui-checklist
ok | Nach dem Neustart | Bei einem Update im Browser zeigt die Update-Seite die neue Version, sobald die Seite wieder verbunden ist, und der Neustart-Hinweis schließt sich; das gilt für Updates ab 0.1.3
ok | Update-Einstellungen | Wird eine Einstellung auf ihren Standard zurückgesetzt, wird sie aus der Konfigurationsdatei entfernt, statt den Standard zu speichern
```
