Vulcan Code 0.1.3 исправляет две детали обновлений в приложении.

### Обновления в приложении

```ui-checklist
ok | После перезапуска | При обновлении из браузера страница обновлений показывает новую версию сразу после переподключения, а уведомление о перезапуске закрывается; это действует для обновлений начиная с 0.1.3
ok | Настройки обновлений | Возврат настройки к значению по умолчанию удаляет её из файла конфигурации, а не сохраняет значение по умолчанию
```
