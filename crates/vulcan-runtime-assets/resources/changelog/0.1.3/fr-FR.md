Vulcan Code 0.1.3 corrige deux détails des mises à jour intégrées.

### Mises à jour intégrées

```ui-checklist
ok | Après le redémarrage | Lors d'une mise à jour depuis un navigateur, la page de mise à jour affiche la nouvelle version dès que la page se reconnecte, et l'avis de redémarrage se ferme ; cela s'applique aux mises à jour à partir de 0.1.3
ok | Paramètres de mise à jour | Remettre un paramètre à sa valeur par défaut le retire du fichier de configuration au lieu d'enregistrer la valeur par défaut
```
