Vulcan Code 0.1.4 では、すばやく更新できる入口を追加し、モデルアカウントの残高と使用量をステータスバーに表示し、小さな画面でもダイアログを使えるようにしました。

### 更新

```ui-checklist
ok | 更新ボタン | 新しいバージョンがあると、サイドバーの Vulcan Code の名前の横に「更新」ボタンが表示されます。開くと更新内容を確認でき、設定を開かずにダウンロードと再起動ができます
ok | スキップしたバージョン | 複数のバージョンをまたいで更新するとき、プレビューにはスキップした各バージョンの更新内容が新しい順に表示されます。0.1.4 以降からの更新で有効です
```

### 会話とステータスバー

```ui-checklist
ok | 会話が揺れない | リクエスト送信中、メモリ想起中、ツール呼び出しの準備中などの表示が入力欄の上に浮かぶようになり、切り替わっても会話が上下に動かなくなりました
ok | モデルアカウント | ステータスバーにアカウントの残高、残りクォータの小さなバー、またはその両方を表示します。どちらも報告しないアカウントは名前だけを表示し、「残高 -」は表示されなくなりました
```

### 小さな画面

```ui-checklist
ok | ダイアログ | 下部にボタンがあるダイアログは、高さの低い画面では内容がスクロールし、ボタンに常に手が届きます。長期メモリのクイック設定と Ask の承認も含みます
ok | 長期メモリのクイック設定 | モデルの手順で各用途を 1 行に表示し、すべてが 1 画面に収まります
```

### Git

```ui-checklist
ok | プル | ローカルブランチと上流の両方に新しいコミットがあるとき、Git のヒントではなく、双方のコミット数を示して状況を説明します
ok | コミット設定 | コミットメッセージのモデルを保存したあと、未保存の変更があるという表示が残らなくなりました
```
