Vulcan Code 0.1.4 新增快捷更新入口，在状态栏显示模型账号的余额与用量，并让对话框在小屏幕上保持可用。

### 更新

```ui-checklist
ok | 更新按钮 | 有新版本时，侧栏 Vulcan Code 名称旁会出现“更新”按钮，点开即可查看更新内容，并直接下载、重启，无需进入设置
ok | 跳过的版本 | 一次更新跨越多个版本时，预览会按从新到旧列出每个被跳过版本的更新内容；从 0.1.4 开始的更新生效
```

### 对话与状态栏

```ui-checklist
ok | 对话不再跳动 | “正在请求”“正在记忆召回”“正在构造工具请求”等提示改为悬浮在输入框上方，切换时对话不再上下跳动
ok | 模型账号 | 状态栏显示账号的余额、剩余额度小进度条，或两者都显示；两者都没有的账号只显示名称，不再出现“余额 -”
```

### 小屏幕

```ui-checklist
ok | 对话框 | 底部带按钮的对话框在矮屏幕上会滚动内容，按钮始终可以点到，包括长期记忆快速配置与 Ask 审批
ok | 长期记忆快速配置 | 模型一步中每个用途占一行，一屏即可全部显示
```

### Git

```ui-checklist
ok | 拉取 | 本地分支与上游都有新提交时，拉取会说明两侧各有多少个提交，而不是显示 Git 的提示
ok | 提交设置 | 保存提交说明模型后，页面不再提示有未保存的修改
```
