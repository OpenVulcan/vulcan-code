Vulcan Code 0.1.4 añade una forma rápida de actualizar, muestra en la barra de estado lo que informa tu cuenta de modelo y mantiene los cuadros de diálogo utilizables en pantallas pequeñas.

### Actualizaciones

```ui-checklist
ok | Botón de actualización | Cuando hay una versión más reciente, aparece un botón de actualización junto al nombre de Vulcan Code en la barra lateral; muestra las novedades y descarga y reinicia sin abrir la configuración
ok | Versiones omitidas | Cuando una actualización omite versiones, su vista previa muestra las notas de cada versión omitida, de la más reciente a la más antigua; se aplica a las actualizaciones desde la 0.1.4
```

### Conversación y barra de estado

```ui-checklist
ok | Conversación estable | Los avisos de envío de una solicitud, recuperación de memoria y preparación de una llamada a herramienta ahora flotan sobre el cuadro de entrada, así que la conversación ya no salta cuando cambian
ok | Cuenta de modelo | La barra de estado muestra el saldo de la cuenta, una pequeña barra con la cuota restante o ambos; una cuenta que no informa ninguno muestra solo su nombre en lugar de «Saldo -»
```

### Pantallas pequeñas

```ui-checklist
ok | Cuadros de diálogo | Los cuadros de diálogo con botones en la parte inferior desplazan su contenido en pantallas bajas, de modo que sus botones siguen al alcance, incluida la configuración rápida de la memoria a largo plazo y las aprobaciones de Ask
ok | Configuración rápida de la memoria a largo plazo | El paso de modelos muestra cada uso en una sola fila, así que todos caben en una pantalla
```

### Git

```ui-checklist
ok | Pull | Cuando la rama local y su upstream han avanzado los dos, el pull lo explica con el número de commits de cada lado en lugar de mostrar las sugerencias de Git
ok | Configuración de commits | Después de guardar el modelo de los mensajes de commit, la página ya no indica que hay cambios sin guardar
```
