Vulcan Code 0.1.4 добавляет быстрый способ обновиться, показывает в строке состояния то, что сообщает учётная запись модели, и сохраняет удобство диалогов на маленьких экранах.

### Обновления

```ui-checklist
ok | Кнопка обновления | Когда доступна более новая версия, рядом с названием Vulcan Code на боковой панели появляется кнопка обновления; она показывает, что нового, и скачивает обновление и перезапускает приложение без открытия настроек
ok | Пропущенные версии | Когда обновление пропускает версии, в его предпросмотре показаны примечания каждой пропущенной версии, от новых к старым; это действует для обновлений начиная с 0.1.4
```

### Беседа и строка состояния

```ui-checklist
ok | Беседа без скачков | Подсказки об отправке запроса, извлечении памяти и подготовке вызова инструмента теперь парят над полем ввода, поэтому беседа больше не прыгает при их смене
ok | Учётная запись модели | Строка состояния показывает баланс учётной записи, небольшую полосу с оставшейся квотой или и то и другое; учётная запись, которая не сообщает ни того ни другого, показывает только своё имя вместо «Баланс -»
```

### Маленькие экраны

```ui-checklist
ok | Диалоги | Диалоги с кнопками внизу прокручивают содержимое на невысоких экранах, поэтому кнопки остаются доступными, включая быструю настройку долговременной памяти и подтверждения Ask
ok | Быстрая настройка долговременной памяти | На шаге моделей каждое назначение занимает одну строку, поэтому все они помещаются на один экран
```

### Git

```ui-checklist
ok | Получение изменений | Когда и локальная ветка, и вышестоящая продвинулись вперёд, при получении изменений это объясняется числом коммитов с каждой стороны вместо подсказок Git
ok | Настройки коммитов | После сохранения модели для сообщений коммитов страница больше не сообщает о несохранённых изменениях
```
