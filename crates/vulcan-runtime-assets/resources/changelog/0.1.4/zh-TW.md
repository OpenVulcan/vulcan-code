Vulcan Code 0.1.4 新增快捷更新入口，在狀態列顯示模型帳號的餘額與用量，並讓對話框在小螢幕上保持可用。

### 更新

```ui-checklist
ok | 更新按鈕 | 有新版本時，側欄 Vulcan Code 名稱旁會出現「更新」按鈕，點開即可查看更新內容，並直接下載、重新啟動，無需進入設定
ok | 跳過的版本 | 一次更新跨越多個版本時，預覽會依由新到舊列出每個被跳過版本的更新內容；自 0.1.4 起的更新生效
```

### 對話與狀態列

```ui-checklist
ok | 對話不再跳動 | 「正在請求」「正在記憶召回」「正在建構工具請求」等提示改為懸浮在輸入框上方，切換時對話不再上下跳動
ok | 模型帳號 | 狀態列顯示帳號的餘額、剩餘額度小進度條，或兩者都顯示；兩者都沒有的帳號只顯示名稱，不再出現「餘額 -」
```

### 小螢幕

```ui-checklist
ok | 對話框 | 底部帶按鈕的對話框在矮螢幕上會捲動內容，按鈕始終可以點到，包括長期記憶快速設定與 Ask 審核
ok | 長期記憶快速設定 | 模型步驟中每個用途佔一列，一個畫面即可全部顯示
```

### Git

```ui-checklist
ok | 拉取 | 本機分支與上游都有新提交時，拉取會說明兩側各有多少個提交，而不是顯示 Git 的提示
ok | 提交設定 | 儲存提交說明模型後，頁面不再提示有未儲存的變更
```
