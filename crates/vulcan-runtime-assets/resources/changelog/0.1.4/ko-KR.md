Vulcan Code 0.1.4는 빠른 업데이트 입구를 추가하고, 모델 계정의 잔액과 사용량을 상태 표시줄에 보여 주며, 작은 화면에서도 대화 상자를 쓸 수 있게 했습니다.

### 업데이트

```ui-checklist
ok | 업데이트 버튼 | 새 버전이 있으면 사이드바의 Vulcan Code 이름 옆에 업데이트 버튼이 나타납니다. 열면 새로운 내용을 확인하고 설정을 열지 않고도 다운로드와 재시작을 할 수 있습니다
ok | 건너뛴 버전 | 여러 버전을 건너뛰어 업데이트할 때 미리 보기에서 건너뛴 각 버전의 변경 내용을 최신순으로 보여 줍니다. 0.1.4부터의 업데이트에 적용됩니다
```

### 대화와 상태 표시줄

```ui-checklist
ok | 흔들리지 않는 대화 | 요청 전송, 메모리 회상, 도구 호출 준비 같은 표시가 입력창 위에 떠 있도록 바뀌어, 바뀔 때 대화가 위아래로 움직이지 않습니다
ok | 모델 계정 | 상태 표시줄에 계정의 잔액, 남은 할당량을 나타내는 작은 막대, 또는 둘 다를 보여 줍니다. 둘 다 없는 계정은 이름만 보여 주며 "잔액 -"이 더 이상 나타나지 않습니다
```

### 작은 화면

```ui-checklist
ok | 대화 상자 | 아래쪽에 버튼이 있는 대화 상자는 높이가 낮은 화면에서 내용이 스크롤되어 버튼을 항상 누를 수 있습니다. 장기 메모리 빠른 설정과 Ask 승인도 포함됩니다
ok | 장기 메모리 빠른 설정 | 모델 단계에서 용도마다 한 줄로 보여 주어 모두 한 화면에 들어갑니다
```

### Git

```ui-checklist
ok | 풀 | 로컬 브랜치와 업스트림 모두에 새 커밋이 있으면 Git의 힌트 대신 양쪽의 커밋 수로 상황을 설명합니다
ok | 커밋 설정 | 커밋 메시지 모델을 저장한 뒤 저장하지 않은 변경이 있다는 표시가 더 이상 남지 않습니다
```
