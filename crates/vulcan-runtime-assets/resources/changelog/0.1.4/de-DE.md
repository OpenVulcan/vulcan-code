Vulcan Code 0.1.4 bietet einen schnellen Weg zum Aktualisieren, zeigt in der Statusleiste, was Ihr Modellkonto meldet, und hält Dialoge auf kleinen Bildschirmen bedienbar.

### Updates

```ui-checklist
ok | Update-Schaltfläche | Ist eine neuere Version verfügbar, erscheint in der Seitenleiste neben dem Namen Vulcan Code eine Update-Schaltfläche; sie zeigt die Neuerungen und lädt herunter und startet neu, ohne die Einstellungen zu öffnen
ok | Übersprungene Versionen | Überspringt ein Update Versionen, zeigt seine Vorschau die Hinweise jeder übersprungenen Version, die neueste zuerst; dies gilt für Updates ab 0.1.4
```

### Unterhaltung und Statusleiste

```ui-checklist
ok | Ruhige Unterhaltung | Die Hinweise zum Senden einer Anfrage, zum Abrufen von Erinnerungen und zum Vorbereiten eines Tool-Aufrufs schweben jetzt über dem Eingabefeld, sodass die Unterhaltung bei einem Wechsel nicht mehr springt
ok | Modellkonto | Die Statusleiste zeigt das Guthaben des Kontos, einen kleinen Balken mit dem verbleibenden Kontingent oder beides; ein Konto, das keines von beiden meldet, zeigt nur seinen Namen statt „Guthaben -“
```

### Kleine Bildschirme

```ui-checklist
ok | Dialoge | Dialoge mit Schaltflächen am unteren Rand scrollen ihren Inhalt auf niedrigen Bildschirmen, sodass die Schaltflächen erreichbar bleiben, auch bei der Schnelleinrichtung des Langzeitgedächtnisses und bei Ask-Freigaben
ok | Schnelleinrichtung des Langzeitgedächtnisses | Der Modellschritt zeigt jeden Zweck in einer Zeile, sodass alle auf einen Bildschirm passen
```

### Git

```ui-checklist
ok | Pull | Haben sich der lokale Branch und sein Upstream beide weiterentwickelt, erklärt ein Pull dies mit der Anzahl der Commits auf jeder Seite, statt die Hinweise von Git anzuzeigen
ok | Commit-Einstellungen | Nach dem Speichern des Modells für Commit-Nachrichten meldet die Seite keine ungespeicherten Änderungen mehr
```
