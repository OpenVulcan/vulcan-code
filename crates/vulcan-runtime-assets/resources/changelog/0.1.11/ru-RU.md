Vulcan Code 0.1.11 добавляет отзывы, центр сообщений и способ исправить проблему на своём устройстве, а также обновляет модели OpenAI, TokenRhythm, OpenCode Go и OpenDesign.

### Обновление до этой версии

```ui-checklist
ok | Инкрементное обновление | При обновлении с 0.1.8, 0.1.9 или 0.1.10 загружаются только изменённые файлы; более ранние версии по-прежнему устанавливаются полным обновлением
ok | База данных приложения | При первом запуске база данных приложения сохраняется в резервную копию и затем автоматически переводится на новую структуру, ничего делать не нужно
```

### Отзывы и сообщения

```ui-checklist
ok | Отправить отзыв | После входа через «Отправить отзыв» можно сообщить о проблеме или предложить улучшение; перед отправкой секреты, пути, имя пользователя, URL и личные данные отфильтровываются на устройстве, и вы видите точное содержимое, которое будет отправлено
ok | Сообщение из карточки ошибки | Если беседа завершается ошибкой, её карточка предлагает отправить сообщение в один клик; только для сбоев, которые может вызвать Vulcan Code, а не для входа, баланса, ограничений частоты, сбоев сервиса, тайм-аутов, политики содержимого или отмены
ok | Центр сообщений | «Центр сообщений» показывает объявления, личные сообщения и ответы сопровождающих на ваши отзывы; важные объявления также показываются баннером
ok | Исправить на этом устройстве | Выберите папку — рабочая копия vulcan-code будет подготовлена как проект, и откроется беседа с навыком исправления; ничего не отправляется и не публикуется, пока вы не подтвердите pull request в этой беседе
ok | Пункты GitHub | В меню учётной записи появились «Предложить на GitHub (issue)» и «Создать pull request на GitHub»
ok | Терминальный клиент | Страница отзывов есть и в терминальном клиенте
```

### Модели и провайдеры

```ui-checklist
ok | OpenAI | Восемь моделей публичного API объявляют строгий структурированный вывод json_schema; GPT-5.6 Sol/Terra/Luna, GPT-6 Sol/Luna и GPT-6.1 Terra умеют отключать рассуждения
ok | TokenRhythm | Добавлены DeepSeek V4.1 Flash 1017, LongCat 2.0, MiniMax M3.1 Flash и тестовые модели Egg-Alpha и Neohorse 1 9B, удалены minimax-m2.5 и mimo-v2.5-pro; объявлен структурированный вывод, модели Messages теперь передают силу рассуждений и умеют их отключать, DeepSeek V4 Pro 0813 и GLM-5.2 переходят на Responses, а Kimi K2.6 — на Chat
ok | OpenCode Go | Добавлены Gemini 4 Argon, Hy4 и бесплатные модели Beam, Iceman и Crouton; десять моделей объявляют структурированный вывод
ok | OpenDesign | GPT-6 Luna теперь использует Responses, а Claude Haiku 5.5 — Messages; добавлены deepseek-v4.1-flash-eco, hy4-preview, minimax-m3.1-flash и 14 чат-моделей Plus/Pro/Max; генерация изображений через GPT Image 2, Nano Banana 2/2 Lite и Seedream 5.0/5.0 Pro доступна в тарифах, которые её включают; уровни рассуждений показывают только то, что публикует каждый поставщик
ok | Модели памяти | Больше моделей умеют отключать рассуждения и возвращать структурированный вывод, поэтому больше из них можно выбрать моделями памяти
```
