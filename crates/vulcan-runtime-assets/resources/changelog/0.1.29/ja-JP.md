Vulcan Code 0.1.29 では、外部 MCP の長時間ツール呼び出しにハートビートを追加し、OpenAI のモデルカタログを更新しました。

### 外部 MCP

```ui-checklist
ok | 長時間の呼び出しにハートビート | クライアントが SSE に対応している場合、長時間の呼び出し中は定期的にハートビートを送信し、無通信による切断を減らします。ツールが完了すると、同じリクエストに最終結果が返ります。
ok | 長時間のコマンドをバックグラウンドで実行 | クライアントが設定したリクエストの待ち時間は引き続き適用されます。フォアグラウンドの Shell リクエストが切断されると、サービスはプロセスツリーを終了します。時間がかかるコマンドは `background: true` で開始し、同じ `sid` の `shell_job` で結果を確認できます。`shell_job` の権限が必要です。
ok | トークンの問題を見分けやすく | サービスログでは、認証ヘッダーの欠落や形式の誤りと、無効なトークンを区別します。手動で行ったトークンの更新も記録し、ログに残るのは診断の種類またはクライアント ID のみです。
```
