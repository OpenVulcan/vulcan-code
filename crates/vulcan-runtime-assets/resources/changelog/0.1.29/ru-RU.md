В Vulcan Code 0.1.29 добавлены сигналы поддержания соединения для длительных вызовов внешних инструментов MCP и обновлён каталог моделей OpenAI.

### Внешний MCP

```ui-checklist
ok | Поддержание соединения при длительных вызовах | Если клиент принимает SSE, длительный вызов периодически отправляет сигналы активности, чтобы соединение реже прерывалось из-за простоя. По завершении работы инструмента окончательный результат приходит в ответ на тот же запрос.
ok | Длительные команды в фоне | Ограничение времени ожидания со стороны клиента по-прежнему действует. При разрыве соединения во время выполнения Shell на переднем плане служба завершает дерево процессов. Запускайте длительные команды с `background: true` и проверяйте результат через `shell_job` с тем же `sid`. Требуется разрешение `shell_job`.
ok | Более понятная диагностика токенов | Журнал службы различает отсутствующие или неверно оформленные заголовки аутентификации и недействительные токены, а также фиксирует замену токена вручную. В журнале остаётся только категория ошибки или идентификатор клиента.
```

### Модели

```ui-checklist
ok | GPT-6.2 Sol и Astra | Обе модели доступны через OpenAI API и по подписке Codex. Подписки Codex используют размер контекстного окна из каталога моделей.
ok | GPT Image 2.6 | Flare и Sunburst теперь доступны в списке медиамоделей OpenAI.
```
