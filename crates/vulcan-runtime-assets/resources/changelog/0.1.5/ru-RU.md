В Vulcan Code 0.1.5 у каждой модели появилось собственное окно сжатия по умолчанию, настольное приложение запускается в одном окне, а частоту проверки обновлений можно выбрать.

### Окно контекста

```ui-checklist
ok | Значение по умолчанию для модели | Для каждой включённой модели диалога можно задать своё окно сжатия по умолчанию для новых сессий: системное значение, следовать модели, фиксированная ступень или свой размер; существующие сессии не меняются
ok | Свои окна | Свой размер задаётся числом токенов или с K для тысяч (например, 235K), не меньше 100K и не больше окна модели; выбор окна рядом с полем ввода тоже может переключиться на свой размер
ok | Смена модели | При смене модели в сессии предлагается окно по умолчанию целевой модели, и ничего не меняется до вашего подтверждения; окно, которое целевая модель не вмещает, теперь переходит к следованию модели, а не блокирует смену
ok | Терминальный интерфейс | В настройках TUI также можно задать окно по умолчанию для каждой модели
```

### Обновления

```ui-checklist
ok | Частота проверки | Выберите, как часто автоматически проверять обновления: каждый час, каждые 6 часов, каждые 12 часов или раз в день, по умолчанию каждые 6 часов; изменение действует без перезапуска
ok | Страница обновления программы | Страница обновления программы в настройках перестроена: сначала текущая версия с проверкой и восстановлением, затем настройки обновления и в конце найденное обновление с описанием каждой входящей в него версии, от новых к старым; диалог обновления показывает тот же список версий
ok | Перезапуск в Linux | В Linux Core, запущенный из настольного приложения, после обновления перезапускается, а не зависает на «Перезапуск»
```

### Настольное приложение

```ui-checklist
ok | Запуск в одном окне | Отдельное окно запуска больше не открывается; рабочее окно показывает экран запуска с реальными этапами и ошибками, а когда Core готов, открывает интерфейс на месте
ok | Оформление при запуске | Экран запуска использует язык и оформление с прошлого раза; при первом запуске — системные
ok | Значок приложения | Док Linux и Dock macOS показывают значок Vulcan Code вместо общего; повторное открытие приложения выводит на передний план запускающееся окно
```

### Исправления

```ui-checklist
ok | Модели эмбеддингов | Модели эмбеддингов с настраиваемым размером вывода (например, Qwen3-Embedding-8B, от 32 до 4096 измерений) больше не отклоняют каждый ответ
ok | Компоненты ответа | Выноски без тона и строки находок из четырёх ячеек теперь отображаются, а не превращаются обратно в блоки кода, и в WebUI, и в TUI
```

### Установщик

```ui-checklist
ok | Установка одной командой в macOS | Скрипт установки, запущенный через конвейер curl в macOS, теперь может читать клавиатуру
ok | Приложение macOS | У приложения macOS, которое создаёт установщик, есть значок, а в конце установщик сообщает, где находится приложение
ok | Пункт меню Linux | Пункт меню Linux соответствует запущенному окну, поэтому закреплённый в доке значок открывает приложение
```
