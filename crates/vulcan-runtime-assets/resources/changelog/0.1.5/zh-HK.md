Vulcan Code 0.1.5 讓每個模型擁有自己的預設壓縮視窗，桌面端改為在同一個視窗內啟動，並可設定自動檢查更新的頻率。

### 上下文視窗

```ui-checklist
ok | 按模型預設 | 可以為每個已啟用的對話模型分別設定新對話的預設壓縮視窗：使用系統預設、跟隨模型、固定檔位或自訂大小；現有對話不受影響
ok | 自訂視窗 | 自訂大小可直接填寫 Token 數或以 K 表示千（如 235K），不小於 100K、不超過模型視窗；輸入框旁的視窗選擇亦可直接切換到自訂大小
ok | 切換模型 | 對話中切換模型時，會詢問是否改用目標模型的預設視窗，確認後才會更改；目前視窗放不進目標模型時，自動改為跟隨模型，不再拒絕切換
ok | 終端介面 | TUI 設定中同樣可以按模型設定預設視窗
```

### 更新

```ui-checklist
ok | 檢查頻率 | 可以設定自動檢查更新的頻率：每小時、每 6 小時、每 12 小時或每天，預設每 6 小時；修改後即時生效，無需重新啟動
ok | 軟件更新頁面 | 設定中的軟件更新頁面重新排列：先是目前版本與檢查、修復，然後是更新設定，最後是找到的新版本及其帶來的每個版本的更新內容，由新到舊；更新對話框使用同一份版本清單
ok | Linux 重新啟動 | 在 Linux 上由桌面端啟動的 Core 更新後會正常重新啟動，不再停在「正在重新啟動」
```

### 桌面端

```ui-checklist
ok | 單視窗啟動 | 不再另外彈出啟動視窗；工作台視窗直接顯示啟動畫面與實際的啟動階段和失敗原因，Core 就緒後在原視窗中開啟介面
ok | 啟動外觀 | 啟動畫面沿用上次使用的語言與外觀主題；首次啟動跟隨系統
ok | 程式圖示 | Linux 程式塢與 macOS Dock 顯示 Vulcan Code 的圖示，不再顯示通用圖示；再次開啟應用程式時會切換到正在啟動的視窗
```

### 修正

```ui-checklist
ok | 向量模型 | 輸出維度可調的向量模型（如 Qwen3-Embedding-8B 的 32 至 4096 維）不再拒絕每一次回傳結果
ok | 回答元件 | 未指定色調的提示區塊與四欄的發現清單列現在可以正常顯示，不再退回為程式碼區塊；WebUI 與 TUI 均已修正
```

### 安裝程式

```ui-checklist
ok | macOS 一鍵安裝 | 在 macOS 上透過 curl 管道執行安裝腳本時，安裝程式可以正常讀取鍵盤輸入
ok | macOS 應用程式 | 安裝產生的 macOS 應用程式帶有圖示，安裝完成時會說明應用程式所在的位置
ok | Linux 選單項目 | Linux 選單項目與運行中的視窗對應，釘選到程式塢的圖示可以正常開啟應用程式
```
