Vulcan Code 0.1.5 让每个模型拥有自己的默认压缩窗口，桌面端改为在同一个窗口内启动，并可以设置自动检查更新的频率。

### 上下文窗口

```ui-checklist
ok | 按模型默认 | 可以为每个已启用的会话模型单独设置新会话的默认压缩窗口：使用系统默认、跟随模型、固定档位或自定义大小；已有会话不受影响
ok | 自定义窗口 | 自定义大小可直接填写 Token 数或用 K 表示千（如 235K），不小于 100K、不超过模型窗口；输入框旁的窗口选择也可以直接切换到自定义大小
ok | 切换模型 | 会话中切换模型时，会提示是否改用目标模型的默认窗口，确认后才会改变；当前窗口放不进目标模型时，自动改为跟随模型，不再拒绝切换
ok | 终端界面 | TUI 设置中同样可以按模型设置默认窗口
```

### 更新

```ui-checklist
ok | 检查频率 | 可以设置自动检查更新的频率：每小时、每 6 小时、每 12 小时或每天，默认每 6 小时；修改后立即生效，无需重启
ok | 软件更新页面 | 设置中的软件更新页面重新排列：先是当前版本与检查、修复，然后是更新设置，最后是发现的新版本及其带来的每个版本的更新内容，从新到旧；更新对话框使用同一份版本列表
ok | Linux 重启 | 在 Linux 上由桌面端启动的 Core 更新后会正常重启，不再停在“正在重启”
```

### 桌面端

```ui-checklist
ok | 单窗口启动 | 不再单独弹出启动窗口；工作台窗口直接显示启动画面与真实的启动阶段和失败原因，Core 就绪后在原窗口中打开界面
ok | 启动外观 | 启动画面沿用上次使用的语言与外观主题；首次启动跟随系统
ok | 程序图标 | Linux 程序坞与 macOS 程序坞显示 Vulcan Code 的图标，不再显示通用图标；再次打开应用时会切换到正在启动的窗口
```

### 修复

```ui-checklist
ok | 向量模型 | 输出维度可调的向量模型（如 Qwen3-Embedding-8B 的 32 至 4096 维）不再拒绝每一次返回结果
ok | 回答组件 | 未指定色调的提示块与四列的发现清单行现在可以正常显示，不再退回为代码块；WebUI 与 TUI 均已修复
```

### 安装程序

```ui-checklist
ok | macOS 一键安装 | 在 macOS 上通过 curl 管道运行安装脚本时，安装程序可以正常读取键盘输入
ok | macOS 应用 | 安装生成的 macOS 应用带有图标，安装完成时会说明应用所在的位置
ok | Linux 菜单项 | Linux 菜单项与运行中的窗口对应，固定到程序坞的图标可以正常打开应用
```
