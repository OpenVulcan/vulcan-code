Vulcan Code 0.1.5에서는 모델마다 기본 압축 창을 지정할 수 있고, 데스크톱 앱이 하나의 창에서 시작되며, 업데이트 자동 확인 주기를 선택할 수 있습니다.

### 컨텍스트 창

```ui-checklist
ok | 모델별 기본값 | 활성화된 대화 모델마다 새 세션의 기본 압축 창을 따로 지정할 수 있습니다: 시스템 기본값, 모델 따르기, 고정 단계 또는 사용자 지정 크기. 기존 세션에는 영향이 없습니다
ok | 사용자 지정 창 | 사용자 지정 크기는 토큰 수 또는 천을 뜻하는 K(예: 235K)로 입력하며, 100K 이상이고 모델 창을 넘을 수 없습니다. 입력창 옆의 창 선택에서도 사용자 지정 크기로 바꿀 수 있습니다
ok | 모델 전환 | 세션 중 모델을 바꾸면 대상 모델의 기본 창을 사용할지 묻고, 확인하기 전에는 아무것도 바뀌지 않습니다. 현재 창이 대상 모델에 맞지 않으면 전환을 막지 않고 모델 따르기로 돌아갑니다
ok | 터미널 화면 | TUI 설정에서도 모델별 기본 창을 지정할 수 있습니다
```

### 업데이트

```ui-checklist
ok | 확인 주기 | 업데이트 자동 확인 주기를 선택할 수 있습니다: 1시간, 6시간, 12시간 또는 하루마다. 기본값은 6시간이며 변경은 다시 시작하지 않아도 적용됩니다
ok | 소프트웨어 업데이트 페이지 | 설정의 소프트웨어 업데이트 페이지 순서를 바꿨습니다: 먼저 현재 버전과 확인·복구, 다음으로 업데이트 설정, 마지막으로 찾은 업데이트와 그에 포함된 각 버전의 업데이트 내용을 최신순으로 보여 줍니다. 업데이트 대화 상자도 같은 버전 목록을 사용합니다
ok | Linux 재시작 | Linux에서 데스크톱 앱이 시작한 Core가 업데이트 후 "다시 시작하는 중"에 멈추지 않고 정상적으로 다시 시작합니다
```

### 데스크톱 앱

```ui-checklist
ok | 하나의 창으로 시작 | 별도의 시작 창을 더 이상 열지 않습니다. 작업 공간 창이 시작 화면과 실제 시작 단계 및 실패 원인을 보여 주고, Core가 준비되면 같은 창에서 화면을 엽니다
ok | 시작 화면 모양 | 시작 화면은 지난번에 사용한 언어와 모양을 따릅니다. 처음 시작할 때는 시스템을 따릅니다
ok | 앱 아이콘 | Linux 독과 macOS Dock에 일반 아이콘 대신 Vulcan Code 아이콘이 표시됩니다. 앱을 다시 열면 시작 중인 창이 앞으로 나옵니다
```

### 수정

```ui-checklist
ok | 임베딩 모델 | 출력 차원을 조절할 수 있는 임베딩 모델(예: Qwen3-Embedding-8B, 32~4096차원)이 더 이상 모든 응답을 거부하지 않습니다
ok | 답변 구성 요소 | 톤을 지정하지 않은 콜아웃과 4칸짜리 발견 사항 행이 코드 블록으로 돌아가지 않고 제대로 표시됩니다. WebUI와 TUI 모두 수정되었습니다
```

### 설치 프로그램

```ui-checklist
ok | macOS 한 줄 설치 | macOS에서 curl 파이프로 설치 스크립트를 실행해도 키보드 입력을 읽을 수 있습니다
ok | macOS 앱 | 설치 프로그램이 만드는 macOS 앱에 아이콘이 있으며, 설치가 끝나면 앱의 위치를 알려 줍니다
ok | Linux 메뉴 항목 | Linux 메뉴 항목이 실행 중인 창과 연결되어, 독에 고정한 아이콘으로 앱을 열 수 있습니다
```
