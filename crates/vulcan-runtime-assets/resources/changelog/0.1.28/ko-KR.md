Vulcan Code 0.1.28은 외부 MCP 클라이언트에 전용 작업 공간과 호출 기록을 추가하고, 최소 버전보다 낮은 관리형 ROOT 스킬을 시작할 때 업데이트합니다.

### 외부 MCP

```ui-checklist
ok | 전용 프로젝트와 세션 | 외부 클라이언트는 작업 디렉터리를 등록하고 자체 세션을 만들 수 있습니다. 파일, CodeKit, 셸 및 지식 베이스 도구는 세션 ID에 연결된 작업 공간을 사용합니다.
ok | 백그라운드 명령과 터미널 | 관련 권한을 받은 클라이언트는 MCP 세션에서 백그라운드 명령을 실행하고 작업을 확인하거나 중지할 수 있으며, 터미널 세션도 사용할 수 있습니다.
ok | 선택적 호출 기록 | 클라이언트별로 기록을 켜면 인수, 결과 및 상태를 확인할 수 있습니다. 클라이언트, 프로젝트 또는 세션으로 기록을 필터링할 수 있습니다.
```

### 업그레이드

```ui-checklist
ok | 독립 MCP 도구에는 세션 ID가 필요 | `vc_mcp_project`로 프로젝트를 등록하고 `vc_mcp_session`으로 세션을 만든 다음, 반환된 `sid`를 독립 도구에 전달합니다. 작업 디렉터리는 세션에서 결정합니다.
```

### 스킬 및 개발자 검증

```ui-checklist
ok | 시작할 때 관리형 ROOT 스킬 업데이트 | CodeKit, Vulcan Curl, Vulcan Work가 최소 버전보다 낮으면 설정된 소스에서 업데이트합니다. 실패하면 사용 가능한 버전을 유지하고 다음 시작 시 다시 시도합니다.
ok | VMM 정책 HTTP 인수 테스트 | 개발자는 `make test-vmm-http`로 WebUI 정책 컨트롤과 로컬 서비스 사이의 HTTP 동작을 검증할 수 있습니다.
```
