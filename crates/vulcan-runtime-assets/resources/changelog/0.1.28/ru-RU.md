В Vulcan Code 0.1.28 появились отдельные рабочие пространства и журнал вызовов для внешних клиентов MCP. Управляемые навыки ROOT обновляются при запуске, если версия ниже требуемой.

### Внешний MCP

```ui-checklist
ok | Отдельные проекты и сеансы | Внешние клиенты могут регистрировать рабочие каталоги и создавать собственные сеансы. Инструменты для файлов, CodeKit, оболочки и баз знаний используют рабочее пространство, связанное с идентификатором сеанса.
ok | Фоновые команды и терминалы | При наличии соответствующих разрешений клиенты могут запускать фоновые команды, просматривать или останавливать задания и использовать сеансы терминала.
ok | Необязательный журнал вызовов | Включите запись для нужного клиента, чтобы просматривать аргументы, результаты и состояния. Журнал можно фильтровать по клиенту, проекту или сеансу.
```

### Обновление

```ui-checklist
ok | Отдельные вызовы MCP требуют идентификатор сеанса | Зарегистрируйте проект через `vc_mcp_project`, создайте сеанс через `vc_mcp_session` и передавайте его `sid` отдельным инструментам. Сеанс определяет рабочий каталог.
```

### Навыки и проверки для разработчиков

```ui-checklist
ok | Обновление управляемых навыков ROOT при запуске | CodeKit, Vulcan Curl и Vulcan Work обновляются из настроенного источника, когда установленная версия ниже минимальной. При сбое сохраняется рабочая версия, а при следующем запуске выполняется повторная попытка.
ok | Приёмочный HTTP-тест политик VMM | Команда `make test-vmm-http` проверяет взаимодействие элементов управления политиками WebUI с локальной службой по HTTP.
```
