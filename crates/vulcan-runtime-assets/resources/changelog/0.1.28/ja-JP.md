Vulcan Code 0.1.28 では、外部 MCP クライアント専用のワークスペースと呼び出し履歴を追加し、必要なバージョンを下回る管理対象の ROOT スキルを起動時に更新します。

### 外部 MCP

```ui-checklist
ok | 専用のプロジェクトとセッション | 外部クライアントは作業ディレクトリを登録し、独自のセッションを作成できます。ファイル、CodeKit、シェル、ナレッジベースのツールはセッション ID に紐づくワークスペースを使います。
ok | バックグラウンドコマンドとターミナル | 個別の権限を持つクライアントは、MCP セッションでバックグラウンドコマンドを実行し、ジョブの確認や停止、ターミナルの利用ができます。
ok | 任意の呼び出し履歴 | クライアントごとに記録を有効にすると、引数、結果、ステータスを確認できます。クライアント、プロジェクト、セッションで絞り込めます。
```

### アップグレード

```ui-checklist
ok | 独立した MCP ツールにはセッション ID が必要 | `vc_mcp_project` でプロジェクトを登録し、`vc_mcp_session` でセッションを作成して、返された `sid` を独立ツールに渡します。作業ディレクトリはセッションで決まります。
```

### スキルと開発時の検証

```ui-checklist
ok | 管理対象の ROOT スキルを起動時に更新 | CodeKit、Vulcan Curl、Vulcan Work が必要な最小バージョンを下回る場合、設定済みの配布元から更新します。失敗時は使用可能なバージョンを維持し、次回の起動時に再試行します。
ok | VMM ポリシーの HTTP 受け入れテスト | 開発者は `make test-vmm-http` を実行して、WebUI のポリシー操作とローカルサービスの HTTP 通信を検証できます。
```
