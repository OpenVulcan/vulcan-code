Vulcan Code 0.1.10 исправляет редактирование и ветвление в длинных сессиях, продолжает ходы при ограничениях частоты и некорректных аргументах инструментов и улучшает карточки команд и компоненты ответов.

### Обновление до этой версии

```ui-checklist
ok | Инкрементное обновление | При обновлении с 0.1.8 или 0.1.9 загружаются только изменённые файлы; более ранние версии по-прежнему устанавливаются полным обновлением
ok | Установка через установщик | Установки, сделанные программой установки, обновляются командой vulcan-code-setup update; приложение сообщает об этом вместо предложения загрузки
```

### Сессии

```ui-checklist
ok | Редактирование и ветвление | В длинных сессиях, история которых занимает несколько сегментов, редактирование отправленного сообщения и ветвление от хода больше не завершаются ошибкой provider_source fingerprint mismatch
ok | Некорректные аргументы инструментов | Вызов инструмента с нечитаемыми аргументами получает результат с ошибкой, и ход продолжается, а не завершается на второй ошибке; обрезанные аргументы отмечаются как, вероятно, слишком длинные
ok | Ограничения частоты | HTTP 429 повторяется по расписанию для ограничений частоты, если включено «Ждать и повторять при ограничении частоты», а не завершает ход; исчерпанный баланс по-прежнему останавливает работу
```

### Инструменты и ответы

```ui-checklist
ok | Заголовки команд | Аргумент описания shell_command теперь короткий заголовок длиной не более 80 символов; это не даёт некоторым моделям, например MiniMax-M3.1-Flash, ломать вызов инструмента на этом аргументе
ok | Карточки фоновых задач | Карточки shell_job показывают назначение команды после идентификатора задачи, поэтому при ожидании видно, какую команду ждут; терминальный клиент так же подписывает строки команд и задач
ok | Компоненты ответов | Третья ячейка строки ui-kv показывается как примечание под значением, а изменение со знаком, например +5, в ui-metrics — как изменение, и весь компонент больше не показывается как код
```

### Модели и память

```ui-checklist
ok | OpenCode Go DeepSeek | deepseek-v4-pro и deepseek-v4.1-flash умеют отключать рассуждения, поэтому их можно выбрать моделями памяти
ok | Пояснение о модели памяти | Настройки теперь объясняют, почему в списке только модели с отключаемыми рассуждениями: модель памяти вызывается до и после каждого ответа, и рассуждения каждый раз добавляли бы ожидание и расход
```
