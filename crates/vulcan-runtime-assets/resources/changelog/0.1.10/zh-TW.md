Vulcan Code 0.1.10 修正了長工作階段中編輯訊息與分叉失敗的問題，回合不再因限流或格式錯誤的工具參數而中斷，並改善了命令卡片與回答元件。

### 更新到此版本

```ui-checklist
ok | 增量更新 | 從 0.1.8 或 0.1.9 更新時只下載有變化的檔案；更早的版本仍以完整更新的方式安裝
ok | 安裝器安裝 | 以安裝器安裝的版本請執行 vulcan-code-setup update 更新；應用程式會給出這項提示，而不是提供下載
```

### 工作階段

```ui-checklist
ok | 編輯與分叉 | 在歷史分成多個分段的長工作階段中，編輯已傳送的訊息或從某個回合分叉不再出現 provider_source fingerprint mismatch 錯誤
ok | 工具參數錯誤 | 模型寫出無法解析的工具參數時，會收到錯誤結果並繼續，回合不再因第二次出錯而結束；參數被截斷時會提示可能是內容過長
ok | 限流重試 | HTTP 429 限流會在開啟「遇到速率限制時等待後重試」時依速率限制重試間隔重試，不再直接結束回合；餘額不足仍會停止
```

### 工具與回答

```ui-checklist
ok | 命令標題 | shell_command 的說明參數改為簡短標題（最多 80 個字元），避免部分模型（如 MiniMax-M3.1-Flash）在這個參數處寫壞工具呼叫
ok | 背景工作卡片 | shell_job 卡片在工作編號後顯示該命令的用途，等待時能看出在等哪條命令；終端客戶端的命令列與工作列也依用途顯示
ok | 回答元件 | ui-kv 列的第三格顯示為值下方的備註，ui-metrics 中帶正負號的變化值（如 +5）正常顯示，不再整塊退回為程式碼
```
