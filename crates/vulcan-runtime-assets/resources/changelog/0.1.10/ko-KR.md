Vulcan Code 0.1.10은 긴 세션에서 메시지 편집과 분기가 실패하던 문제를 고치고, 속도 제한이나 잘못된 도구 인수로 턴이 끝나지 않게 하며, 명령 카드와 답변 컴포넌트를 개선합니다.

### 이 버전으로 업데이트

```ui-checklist
ok | 증분 업데이트 | 0.1.8 또는 0.1.9에서 업데이트하면 변경된 파일만 내려받습니다. 그 이전 버전은 계속 전체 업데이트로 설치됩니다
ok | 설치 프로그램으로 설치한 경우 | 설치 프로그램으로 설치했다면 vulcan-code-setup update로 업데이트합니다. 앱은 다운로드를 제공하지 않고 이를 안내합니다
```

### 세션

```ui-checklist
ok | 편집과 분기 | 기록이 여러 세그먼트에 걸친 긴 세션에서 보낸 메시지를 편집하거나 턴에서 분기할 때 더 이상 provider_source fingerprint mismatch 오류로 실패하지 않습니다
ok | 잘못된 도구 인수 | 인수를 해석할 수 없는 도구 호출은 오류 결과를 받고 턴이 계속되며, 두 번째 오류에서 끝나지 않습니다. 잘린 인수는 너무 길었을 가능성이 있다고 알려 줍니다
ok | 속도 제한 | HTTP 429 속도 제한은 턴을 끝내지 않고 "속도 제한 시 대기 후 재시도"가 켜져 있으면 속도 제한 재시도 간격에 따라 재시도됩니다. 잔액 부족은 계속 중지됩니다
```

### 도구와 답변

```ui-checklist
ok | 명령 제목 | shell_command의 설명 인수는 최대 80자의 짧은 제목으로 바뀌었습니다. MiniMax-M3.1-Flash 같은 일부 모델이 이 인수에서 도구 호출을 망가뜨리지 않게 합니다
ok | 백그라운드 작업 카드 | shell_job 카드가 작업 ID 뒤에 명령의 용도를 보여 주므로 대기 중에 어떤 명령을 기다리는지 알 수 있습니다. 터미널 클라이언트의 명령 행과 작업 행도 같은 방식으로 표시합니다
ok | 답변 컴포넌트 | ui-kv 행의 세 번째 칸은 값 아래 메모로, ui-metrics의 +5 같은 부호 있는 변화는 변화량으로 표시되며 컴포넌트 전체가 코드로 되돌아가지 않습니다
```
