Vulcan Code 0.1.10 では、長いセッションでのメッセージ編集と分岐の失敗を修正し、レート制限や不正なツール引数でターンが止まらないようにし、コマンドカードと回答コンポーネントを改善しました。

### このバージョンへの更新

```ui-checklist
ok | 差分更新 | 0.1.8 または 0.1.9 からの更新では変更されたファイルだけをダウンロードします。それより前のバージョンは引き続き完全更新でインストールされます
ok | セットアップでのインストール | セットアッププログラムでインストールした場合は vulcan-code-setup update で更新します。アプリはダウンロードを提示せず、その旨を表示します
```

### セッション

```ui-checklist
ok | 編集と分岐 | 履歴が複数のセグメントにまたがる長いセッションで、送信済みメッセージの編集やターンからの分岐が provider_source fingerprint mismatch エラーで失敗しなくなりました
ok | 不正なツール引数 | 解析できない引数のツール呼び出しにはエラー結果が返され、2 回目でターンが終了せずに続行します。途中で切れた引数は長すぎた可能性があると伝えます
ok | レート制限 | HTTP 429 のレート制限は「レート制限時に待機して再試行」がオンのときレート制限の間隔で再試行され、ターンは終了しません。残高不足の場合は引き続き停止します
```

### ツールと回答

```ui-checklist
ok | コマンドのタイトル | shell_command の説明引数は最大 80 文字の短いタイトルになりました。MiniMax-M3.1-Flash などの一部モデルがこの引数でツール呼び出しを壊すのを防ぎます
ok | バックグラウンドジョブのカード | shell_job カードはジョブ ID の後にコマンドの目的を表示するため、待機中にどのコマンドを待っているかが分かります。ターミナルクライアントのコマンド行とジョブ行も同様に表示します
ok | 回答コンポーネント | ui-kv 行の 3 つ目のセルは値の下の注記として、ui-metrics の +5 のような符号付きの変化は変化量として表示され、コンポーネント全体がコード表示に戻らなくなりました
```

### モデルとメモリ

```ui-checklist
ok | OpenCode Go DeepSeek | deepseek-v4-pro と deepseek-v4.1-flash は思考をオフにできるため、メモリモデルとして選択できます
ok | メモリモデルの説明 | メモリモデルの設定に、思考をオフにできるモデルだけが表示される理由を記載しました。メモリモデルは毎回の回答の前後に呼び出されるため、思考を有効にすると待ち時間と使用量が増えます
```
