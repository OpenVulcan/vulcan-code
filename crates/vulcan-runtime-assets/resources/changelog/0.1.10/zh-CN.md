Vulcan Code 0.1.10 修复了长会话中编辑消息和分叉失败的问题，回合不再因限流或格式错误的工具参数而中断，并改进了命令卡片与回答组件。

### 更新到此版本

```ui-checklist
ok | 增量更新 | 从 0.1.8 或 0.1.9 更新时只下载有变化的文件；更早的版本仍以完整更新的方式安装
ok | 安装器安装 | 用安装器安装的版本请运行 vulcan-code-setup update 更新；应用会给出这一提示，而不是提供下载
```

### 会话

```ui-checklist
ok | 编辑与分叉 | 在历史分成多个分段的长会话中，编辑已发送的消息或从某个回合分叉不再报 provider_source fingerprint mismatch 错误
ok | 工具参数出错 | 模型写出无法解析的工具参数时，会收到错误结果并继续，回合不再因第二次出错而结束；参数被截断时会提示可能是内容过长
ok | 限流重试 | HTTP 429 限流会在开启「被限流时等待后重试」时按限流重试间隔重试，不再直接结束回合；余额不足仍会停止
```

### 工具与回答

```ui-checklist
ok | 命令标题 | shell_command 的说明参数改为简短标题（最多 80 个字符），避免部分模型（如 MiniMax-M3.1-Flash）在这个参数处写坏工具调用
ok | 后台任务卡片 | shell_job 卡片在任务编号后显示该命令的用途，等待时能看出在等哪条命令；终端客户端的命令行与任务行也按用途显示
ok | 回答组件 | ui-kv 行的第三格显示为值下方的备注，ui-metrics 中带正负号的变化值（如 +5）正常显示，不再整块退回为代码
```

### 模型与记忆

```ui-checklist
ok | OpenCode Go DeepSeek | deepseek-v4-pro 与 deepseek-v4.1-flash 可以关闭思考，因此可以选作记忆模型
ok | 记忆模型说明 | 记忆模型设置直接说明为什么只能选可关闭思考的模型：每次回复前后都要调用记忆模型，开启思考会增加等待和用量
```
