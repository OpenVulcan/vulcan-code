Vulcan Code 0.1.2 ist eine Wartungsversion, die Installieren und Entfernen reibungsloser macht.

### Installation

```ui-checklist
ok | Befehle sofort verfügbar | Nach dem PowerShell-Installationsbefehl funktionieren vulcan-tui und vulcan-code-setup im selben Fenster; unter Linux und macOS zeigt das Setup-Programm die Zeile, mit der sie in der aktuellen Shell funktionieren
ok | Benutzerdienst | Eine Installation mit dem Dienst, der bei der Anmeldung startet, bleibt unter Windows nicht mehr bei „Dienst wird registriert“ stehen
ok | Entfernen im laufenden Betrieb | Beim Entfernen werden zuerst die laufende Desktop-App, der Dienst und der Terminal-Client beendet, dann wird alles Installierte entfernt
ok | Windows-Installationsprogramm | Das Installationsprogramm enthält jetzt das Setup-Programm 0.2.3
```
