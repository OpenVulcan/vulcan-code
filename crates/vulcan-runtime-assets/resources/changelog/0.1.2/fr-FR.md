Vulcan Code 0.1.2 est une version de maintenance qui rend l'installation et la désinstallation plus fluides.

### Installation

```ui-checklist
ok | Commandes immédiates | Après la commande d'installation PowerShell, vulcan-tui et vulcan-code-setup fonctionnent dans la même fenêtre ; sous Linux et macOS, le programme d'installation affiche la ligne qui les rend disponibles dans le shell actuel
ok | Service utilisateur | L'installation avec le service qui démarre à l'ouverture de session ne s'arrête plus à « Enregistrement du service » sous Windows
ok | Désinstallation en cours d'exécution | La désinstallation ferme d'abord l'application de bureau, le service et le client terminal en cours d'exécution, puis supprime tout ce qui a été installé
ok | Programme d'installation Windows | Le programme d'installation inclut désormais l'outil d'installation 0.2.3
```
