Vulcan Code 0.1.2 es una versión de mantenimiento que hace más fluidas la instalación y la desinstalación.

### Instalación

```ui-checklist
ok | Comandos al instante | Tras el comando de instalación de PowerShell, vulcan-tui y vulcan-code-setup funcionan en la misma ventana; en Linux y macOS el programa de instalación muestra la línea que los hace funcionar en el shell actual
ok | Servicio de usuario | Instalar con el servicio que se inicia al iniciar sesión ya no se detiene en «Registrando el servicio» en Windows
ok | Desinstalar en ejecución | Al desinstalar, primero se cierran la aplicación de escritorio, el servicio y el cliente de terminal en ejecución, y después se elimina todo lo instalado
ok | Instalador de Windows | El instalador incluye ahora el programa de instalación 0.2.3
```
