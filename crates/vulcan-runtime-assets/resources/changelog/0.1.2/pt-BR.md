O Vulcan Code 0.1.2 é uma versão de manutenção que torna a instalação e a remoção mais tranquilas.

### Instalação

```ui-checklist
ok | Comandos na hora | Depois do comando de instalação do PowerShell, vulcan-tui e vulcan-code-setup funcionam na mesma janela; no Linux e no macOS o programa de instalação mostra a linha que os faz funcionar no shell atual
ok | Serviço do usuário | Instalar com o serviço que inicia quando você entra no sistema não para mais em "Registrando o serviço" no Windows
ok | Remover em execução | Ao remover, o aplicativo de desktop, o serviço e o cliente de terminal em execução são fechados primeiro, e depois tudo o que foi instalado é removido
ok | Instalador do Windows | O instalador agora inclui o programa de instalação 0.2.3
```
