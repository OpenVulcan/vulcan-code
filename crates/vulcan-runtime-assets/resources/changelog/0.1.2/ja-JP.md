Vulcan Code 0.1.2 は、インストールとアンインストールをよりスムーズにするメンテナンスリリースです。

### インストール

```ui-checklist
ok | すぐに使えるコマンド | PowerShell のインストールコマンドの後、同じウィンドウで vulcan-tui と vulcan-code-setup を使えます。Linux と macOS では、現在のシェルですぐに使うためのコマンドをセットアッププログラムが表示します
ok | ユーザーサービス | Windows でサインイン時に起動するサービス付きでインストールしても、「サービスを登録しています」で止まらなくなりました
ok | 実行中のアンインストール | アンインストール時は、実行中のデスクトップアプリ、サービス、ターミナルクライアントを先に終了してから、インストールしたものをすべて削除します
ok | Windows インストーラー | インストーラーにセットアッププログラム 0.2.3 が含まれるようになりました
```
