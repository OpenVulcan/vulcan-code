Vulcan Code 0.1.2 是一個維護版本，令安裝與解除安裝更順暢。

### 安裝

```ui-checklist
ok | 指令即時可用 | 以 PowerShell 安裝指令安裝後，vulcan-tui 與 vulcan-code-setup 在同一視窗中即可使用；在 Linux 與 macOS 上，安裝程式會提供令目前 Shell 即時可用的指令
ok | 用戶服務 | 在 Windows 上選擇登入時啟動的服務進行安裝，不再停在「正在登記服務」
ok | 執行中解除安裝 | 解除安裝時先關閉正在執行的桌面應用程式、服務與終端客戶端，再移除安裝的全部內容
ok | Windows 安裝程式 | 安裝程式現在內置安裝工具 0.2.3
```
