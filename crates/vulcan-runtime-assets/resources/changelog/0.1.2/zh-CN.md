Vulcan Code 0.1.2 是一个维护版本，让安装与卸载更顺畅。

### 安装

```ui-checklist
ok | 命令立即可用 | 用 PowerShell 安装命令安装后，vulcan-tui 与 vulcan-code-setup 在同一窗口中即可使用；在 Linux 与 macOS 上，安装器给出让当前 Shell 立即可用的命令
ok | 用户服务 | 在 Windows 上选择登录时启动的服务进行安装，不再停在“正在注册服务”
ok | 运行中卸载 | 卸载时先关闭正在运行的桌面应用、服务与终端客户端，再移除安装的全部内容
ok | Windows 安装包 | 安装包现在内置安装器 0.2.3
```
