Vulcan Code 0.1.2는 설치와 제거를 더 매끄럽게 만드는 유지 관리 릴리스입니다.

### 설치

```ui-checklist
ok | 바로 쓰는 명령 | PowerShell 설치 명령 후 같은 창에서 vulcan-tui와 vulcan-code-setup을 사용할 수 있습니다. Linux와 macOS에서는 현재 셸에서 바로 쓰기 위한 명령을 설치 프로그램이 알려 줍니다
ok | 사용자 서비스 | Windows에서 로그인할 때 시작되는 서비스와 함께 설치해도 더 이상 "서비스 등록 중"에서 멈추지 않습니다
ok | 실행 중 제거 | 제거할 때 실행 중인 데스크톱 앱, 서비스, 터미널 클라이언트를 먼저 닫은 뒤 설치한 모든 항목을 삭제합니다
ok | Windows 설치 관리자 | 설치 관리자에 설치 프로그램 0.2.3이 포함됩니다
```
