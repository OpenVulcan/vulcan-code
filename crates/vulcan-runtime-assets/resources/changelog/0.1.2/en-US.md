Vulcan Code 0.1.2 is a maintenance release that makes installing and removing Vulcan Code smoother.

### Installation

```ui-checklist
ok | Commands at once | After the PowerShell install command, vulcan-tui and vulcan-code-setup work in the same window; on Linux and macOS the setup program prints the line that makes them work in the current shell
ok | User service | Installing with the service that starts when you sign in no longer stops at "Registering the service" on Windows
ok | Uninstall while running | Uninstalling first closes the running desktop app, service and terminal client, then removes everything it installed
ok | Windows installer | The installer now includes setup program 0.2.3
```
