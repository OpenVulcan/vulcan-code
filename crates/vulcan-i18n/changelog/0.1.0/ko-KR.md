Vulcan Code 0.1.0은 첫 공개 프리뷰입니다. 코드 작성과 일상 업무를 위한 그래픽 AI 워크벤치로, 프로젝트, 세션, 터미널, 브라우저, 코드 검토, Git 커밋을 한곳에서 다룹니다.

```ui-kv
릴리스 | 프리뷰
클라이언트 | 데스크톱 앱, 브라우저 WebUI, 터미널 클라이언트(TUI)
인터페이스 언어 | 11개
패키지 | Python, Node.js, 브라우저 구성 요소 포함, 명령 하나로 설치
라이선스 | MIT
```

### 주요 기능

````ui-tabs
### 압축 창
모든 세션은 입력 영역의 컨텍스트 용량 다이얼에서 언제든 압축 창을 바꿀 수 있어, 긴 작업도 새 세션을 열 필요가 없습니다.

```ui-kv
크기 | 5단계, 기본값은 200K, 256K, 272K, 373K, 500K 토큰이며 설정에서 수정 가능
모델 따르기 | "기본값(모델 따름)"을 선택하면 현재 모델의 창 기준으로 압축합니다
적용 범위 | 자동 압축이 일어나는 시점만 바뀌며, 모델 자체의 컨텍스트 창은 바뀌지 않습니다
수동 압축 | 언제든 /compact로 현재 세션을 압축합니다
```

### 도구 카드와 접기
도구 종류마다 전용 카드가 있어, 도구 호출이 많아도 답변이 묻히지 않습니다.

```ui-checklist
ok | 전용 카드 | 파일, 명령, 터미널, 하위 에이전트, 검색, 미디어, 질문, 환경 변수, 구성 변경 등
ok | 소요 시간과 링크 | 호출마다 걸린 시간을 표시하고, 카드의 파일은 파일 패널에서 바로 열립니다
ok | 필요할 때 접기 | 실행 중에는 펼치고 끝나면 접으며, 연속 호출은 하나의 요약 아래로 묶습니다
ok | 언제든 전환 | 설정에서 기본값을 고르거나, 입력 영역의 "도구 접기" 또는 /collapse로 세션별로 전환합니다
```

### 멀티모달
"멀티모달 확장"에서 기능마다 모델을 하나 또는 여러 개 지정하고, "확장 기능"으로 세션별로 켭니다.

```ui-cards
웹 | 웹 검색과 페이지 본문 추출
이해 | 이미지, 동영상, 오디오 이해
생성 | 이미지와 동영상 생성, 이미지는 Codex 구독으로도 생성할 수 있습니다
음성과 음악 | 음성 합성과 전사, 음악 생성과 커버
```

### 환경 변수
내장된 환경 변수 관리로 비밀 값은 내 컴퓨터에 남고, AI는 변수 이름만 봅니다.

```ui-checklist
ok | 세 가지 계층 | 전역, 프로젝트, 세션 계층을 화면에서 편집하며, 이 페이지를 사이드바에 표시할 수 있습니다
ok | 값은 숨김 | 값은 AI나 화면에 절대 표시되지 않으며, 도구 결과에 나타난 값은 가려집니다
ok | 요청 시 입력 | AI에게 필요한 변수가 없으면 양식으로 입력을 요청하며, 값은 대화를 거치지 않습니다
ok | 자동 주입 | 명령과 터미널은 해당 계층의 변수를 받고, MCP 서버는 전역 변수를 사용합니다
```

### 하위 에이전트 모델
하위 에이전트는 허용한 모델만 사용합니다.

```ui-kv
두 단계 | 시스템 설정이 기본값이며, 세션마다 따로 설정할 수 있습니다
기본 선택 | 호출한 모델이 기본으로 포함되며, 선택을 해제할 수 있습니다
범위 밖 | 바로 거부하며, 다른 모델로 몰래 바꾸지 않습니다
세션 설정 | 입력란 아래의 "세션 설정"에서 언제든 바꾸거나, 한 번의 클릭으로 시스템 기본값으로 되돌릴 수 있습니다
```
````

### 워크벤치

```ui-cards
프로젝트와 세션 | 여러 프로젝트와 세션을 원하는 순서로 나란히 두고, 파일 트리, 검토, 메모리, 하위 에이전트 패널을 함께 사용합니다
프로젝트 터미널 | 여러 탭의 터미널. AI가 오래 실행되거나 상호작용이 필요한 명령 세션을 유지할 수 있습니다
파일 패널 | @로 파일을 언급하고, 입력 영역으로 끌어 놓고, 터미널과 출력의 경로를 열며, 찾기와 줄 이동을 지원합니다
풍부한 답변 | Markdown, 코드, Mermaid 다이어그램을 스트리밍으로 표시합니다. 인터랙티브 답변은 체크리스트, 비교, 차트, 흐름 등을 더하고, 결정 카드는 답장을 입력란에 넣거나 바로 보냅니다
분기와 재시도 | 이전 질문을 편집해 다시 생성하거나, 완료된 어느 턴에서든 새 세션으로 분기합니다
명령 팔레트 | 키보드 단축키, 대화 내 찾기, 대화를 Markdown으로 복사
전담 어시스턴트 | 기본 프롬프트를 고정하고 설정을 동결한 세션으로, 반복되는 한 가지 작업을 맡습니다
```

### 작업 진행

```ui-cards
목표 모드 | 목표와 토큰 예산을 정하면 AI가 턴마다 계속 작업하며, 일시 중지, 재개, 지우기가 가능합니다
계획 모드 | 먼저 탐색하고 계획을 작성한 뒤, 승인하면 실행합니다
끼어들기 | 작업이 실행되는 동안 지시를 추가하거나 후속 요청을 대기열에 넣습니다
하위 에이전트 | 기본 제공 탐색·계획 역할과 선택형 역할 템플릿
질문 | AI가 결정이 필요하면 세션 안에서 선택지 카드로 묻습니다
```

### 코드, 지식, 메모리

```ui-cards
코드 탐색 | CodeKit이 실시간 작업 트리에서 심볼, 정의, 참조를 읽습니다
지식 베이스 | AI가 대신 관리하는 라이브러리로, 기록이 영구 보존되며 프로젝트별로 접근을 허용합니다
메모리 | 사용자 폴더의 Markdown 메모리, 또는 매 턴 전에 회상되어 작업 과정에 표시되는 MemoryMesh 장기 메모리
```

### 안전과 검토

```ui-checklist
ok | 권한 모드 | 보기 전용, 작업 공간 수정, 자동 승인, 전체 권한
ok | 승인 파이프라인 | 규칙, 판정 모델, 검토 모델을 거치며, 확실하지 않은 것은 모두 사용자에게 넘깁니다
ok | 판정 모델 | 로컬 모델, 클라우드 또는 API로 실행합니다
ok | Diff 검토 | 통합 보기와 분할 보기, 단어 단위 변경, 스테이징과 되돌리기
ok | Git | 풀, AI가 작성하는 커밋 메시지, 현재 브랜치나 새 브랜치에 커밋한 뒤 푸시
```
