Vulcan Code 0.1.0은 첫 공개 프리뷰입니다. 프로젝트, 대화, 터미널, 브라우저, 코드 리뷰, Git 커밋을 한곳에 모은 그래픽 AI 코딩 워크벤치입니다.

```ui-kv
릴리스 | 프리뷰
클라이언트 | 데스크톱 앱, 브라우저 WebUI, 터미널 클라이언트(TUI)
인터페이스 언어 | 11개
라이선스 | MIT
```

### 워크벤치

```ui-cards
프로젝트와 대화 | 여러 프로젝트와 대화를 나란히 열고 파일 트리, 리뷰, 메모리, 서브에이전트 패널을 함께 사용합니다
프로젝트 터미널 | 여러 탭의 터미널. AI가 오래 실행되거나 상호작용이 필요한 명령 세션을 유지할 수 있습니다
풍부한 답변 | Markdown, 코드, Mermaid 다이어그램, 도구 카드를 스트리밍으로 표시하고, 인터랙티브 답변은 발견 사항, 비교, 차트, 흐름 같은 시각 컴포넌트를 더합니다
분기와 재시도 | 이전 질문을 편집해 다시 생성하거나, 완료된 어느 턴에서든 새 대화로 분기합니다
전담 어시스턴트 | 기본 프롬프트를 고정하고 설정을 동결한 대화로, 반복되는 한 가지 작업을 맡습니다
```

### 작업 진행

```ui-cards
목표 모드 | 목표와 Token 예산을 정하면 AI가 턴마다 계속 작업하며, 일시 중지, 재개, 초기화할 수 있습니다
계획 모드 | 먼저 탐색하고 계획을 작성한 뒤, 승인하면 실행합니다
실행 중 안내 | 작업이 진행되는 동안 지시를 추가하거나 후속 요청을 대기열에 넣습니다
서브에이전트 | 기본 제공 탐색·계획 역할과 선택형 역할 템플릿을 제공하며, 각각 허용한 모델만 사용합니다
질문 | AI가 결정이 필요할 때 대화 안에서 선택지 카드로 묻습니다
```

### 코드, 지식, 메모리

```ui-cards
코드 탐색 | CodeKit이 실시간 작업 트리에서 심볼, 정의, 참조를 직접 읽습니다
지식 베이스 | AI가 관리해 주는 자료 모음으로, 기록이 영구 보존되며 프로젝트별로 접근을 허용합니다
메모리 | 사용자 폴더에 저장되는 Markdown 메모리, 또는 매 턴 전에 회상하는 MemoryMesh 장기 메모리
```

### 안전과 리뷰

```ui-checklist
ok | 권한 모드 | 보기 전용, 작업 공간 수정, 자동 승인, 전체 권한
ok | 승인 파이프라인 | 규칙, 판정 모델, 검토 모델을 거치며 확실하지 않은 것은 모두 사용자에게 넘깁니다
ok | Diff 리뷰 | 통합 보기와 분할 보기, 단어 단위 변경, 스테이징과 되돌리기
ok | Git 커밋 | AI가 메시지를 작성하고 현재 브랜치나 새 브랜치에 커밋한 뒤 푸시합니다
ok | 비밀 보호 | 환경 변수 값은 AI나 화면에 절대 표시되지 않습니다
```

### Vulcan Code 확장

```ui-cards
스킬 | 프롬프트 스킬(`SKILL.md`)과 프로그래밍 가능한 LuaSkills 패키지
MCP | 로컬 및 HTTP MCP 서버에 연결하거나, AI가 한 대화에서만 서버에 연결하도록 할 수 있습니다
MCP 서비스 | 다른 AI 도구가 대화 목록 조회, 메시지 전송, 질문 답변을 할 수 있으며 도구마다 고유한 Token을 사용합니다
플러그인 | 플러그인은 AI 브라우저, 사용량 통계처럼 도구와 자체 페이지를 추가합니다
모델 | OpenAI, Anthropic, Gemini 등 여러 프로토콜 계열과 기본 제공 및 사용자 지정 공급자를 지원하며, 용도별로 다른 모델을 쓸 수 있습니다
```
