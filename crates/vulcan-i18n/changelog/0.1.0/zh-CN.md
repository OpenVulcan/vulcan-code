Vulcan Code 0.1.0 是首个公开预览版：一款图形界面的 AI 工作台，既能写代码，也能处理日常工作任务。项目、会话、终端、浏览器、代码审查和 Git 提交都在同一处。

```ui-kv
版本类型 | 预览版
客户端 | 桌面应用、浏览器 WebUI、终端客户端（TUI）
界面语言 | 11 种
安装包 | 内置 Python、Node.js 与浏览器组件，一条命令即可安装
许可证 | MIT
```

### 本版重点

````ui-tabs
### 压缩窗口
每个会话都能在输入区的上下文容量表盘上随时切换压缩窗口，长任务不必另开会话。

```ui-kv
可选档位 | 五档，默认 200K、256K、272K、373K、500K Token，可在设置中修改
跟随模型 | 选择“默认（跟随模型）”即按当前模型的窗口压缩
作用范围 | 只改变自动压缩的时机，不改变模型本身的上下文窗口
手动压缩 | 随时用 /compact 压缩当前会话
```

### 工具卡与折叠
每类工具都有专属卡片，工具调用再多也不会淹没回答。

```ui-checklist
ok | 专属工具卡 | 文件、命令、终端、子代理、搜索、媒体、提问、环境变量与配置变更等各有专门卡片
ok | 耗时与跳转 | 每次调用都显示耗时，卡片中的文件可以直接在文件面板打开
ok | 按需折叠 | 运行时展开，完成后自动收起；连续调用归为一组并显示摘要
ok | 随时切换 | 在设置中选默认行为，也可以用输入区的“工具折叠”或 /collapse 按会话切换
```

### 多模态
在“多模态能力扩展”中为每项能力配置模型：可以只用一个，也可以同时配置多个；会话内的“扩展能力”按会话开关。

```ui-cards
网页 | 网页搜索与正文提取
理解 | 图像、视频与音频理解
生成 | 图像与视频生成，图像也可以使用 Codex 订阅
语音与音乐 | 语音合成与转写、音乐生成与翻唱
```

### 环境变量
内置的环境变量管理让密钥留在本机，AI 只知道变量名。

```ui-checklist
ok | 三层管理 | 全局、项目与会话三层，直接在界面中增改，页面可以显示在侧栏
ok | 值不外露 | 值永远不会显示给 AI 或界面，工具结果中出现的值会被遮蔽
ok | 按需填写 | AI 缺少某个变量时请你在表单中填写，值不经过对话
ok | 自动注入 | 命令与终端获得对应层级的变量，MCP 服务器使用全局变量
```

### 子代理模型
子代理只会使用你允许的模型。

```ui-kv
两级范围 | 系统级设置为默认，会话可以单独设置
默认勾选 | 发起调用的模型默认在内，可以取消
超出范围 | 直接拒绝，不会悄悄换成别的模型
会话设置 | 在输入框下方的“会话设置”中随时调整，也可以一键恢复系统默认
```
````

### 工作台

```ui-cards
项目与会话 | 多项目、多会话并行，可以调整会话顺序，搭配文件树、审查、记忆与子代理面板
项目终端 | 多标签终端；AI 可以持有长时间运行或需要交互的命令会话
文件面板 | @ 引用文件、拖入输入区、从终端和输出中打开路径，支持查找与跳转到行
丰富的回答 | 流式渲染 Markdown、代码与 Mermaid 图；互动回答提供清单、对比、图表、流程等组件，决策卡可以直接插入或发送回复
分叉与重试 | 编辑历史问题重新生成，或从任意已完成的回合分叉出新会话
命令面板 | 快捷键、会话内查找，以及把会话复制为 Markdown
专职助手 | 基础提示词固定、设置冻结的会话，专门处理一类重复工作
```

### 推进任务

```ui-cards
目标模式 | 设定目标和 Token 预算，AI 按回合持续推进，可暂停、恢复或清除
计划模式 | 先探索并写出计划，你确认后再执行
执行中引导 | 任务运行时可以追加说明，或排队后续请求
子代理 | 内置探索、计划等角色，另有可选角色模板
结构化提问 | AI 需要你决定时，在会话内以选项卡片提问
```

### 代码、知识与记忆

```ui-cards
代码导航 | CodeKit 直接读取实时工作树：符号、定义与引用
知识库 | 由 AI 为你维护的资料库，历史永久保留，可按项目授权
记忆 | 保存在用户目录的 Markdown 记忆，或在每回合前召回的 MemoryMesh 长期记忆，召回内容显示在工作过程中
```

### 安全与审查

```ui-checklist
ok | 权限模式 | 仅可查看、工作区修改、自动审批与完全权限
ok | 审批管线 | 确定性规则、判定模型与复核模型；拿不准的一律交给你
ok | 判定模型 | 可以使用本地模型、云端或 API
ok | Diff 审查 | 统一与分栏视图、字词级差异、暂存与还原
ok | Git | 拉取、AI 生成提交信息、提交到当前或新分支，并可推送
```

### 扩展 Vulcan Code

```ui-cards
技能 | 提示词技能（SKILL.md）与可编程的 LuaSkills 技能包，可以从 LuaSkills Hub 安装
MCP | 连接本地与 HTTP MCP 服务器，也可以让 AI 为单个会话临时连接
MCP 服务 | 其他 AI 工具可以列出会话、发送消息、回答提问，每个工具一枚令牌
AI 配置 | AI 可以帮你添加 MCP 服务器与模型供应商，改动前先给出预览并按权限模式请你确认
插件 | 插件可以提供工具和自己的页面，例如 AI 浏览器与用量统计
RTK | 压缩命令输出与 Git 上下文，节省 Token 并统计节省量
模型 | OpenAI、Anthropic、Gemini 等协议族，内置与自定义供应商，不同用途可选不同模型
```
