Vulcan Code 0.1.0 是首个公开预览版：一款图形界面的 AI Coding 工作台，把项目、会话、终端、浏览器、代码审查和 Git 提交放在同一处。

```ui-kv
版本类型 | 预览版
客户端 | 桌面应用、浏览器 WebUI、终端客户端（TUI）
界面语言 | 11 种
许可证 | MIT
```

### 工作台

```ui-cards
项目与会话 | 多项目、多会话并行，搭配文件树、审查、记忆与子代理面板
项目终端 | 多标签终端；AI 可以持有长时间运行或需要交互的命令会话
丰富的回答 | 流式渲染 Markdown、代码、Mermaid 图与工具卡片；互动回答还能使用问题清单、对比、图表、流程等可视组件
分叉与重试 | 编辑历史问题重新生成，或从任意已完成的回合分叉出新会话
专职助手 | 基础提示词固定、设置冻结的会话，专门处理一类重复工作
```

### 推进任务

```ui-cards
目标模式 | 设定目标和 Token 预算，AI 按回合持续推进，可暂停、恢复或清除
计划模式 | 先探索并写出计划，你确认后再执行
执行中引导 | 任务运行时可以追加说明，或排队后续请求
子代理 | 内置探索、计划等角色，另有可选角色模板，每个都只使用你允许的模型
结构化提问 | AI 需要你决定时，在会话内以选项卡片提问
```

### 代码、知识与记忆

```ui-cards
代码导航 | CodeKit 直接读取实时工作树：符号、定义与引用
知识库 | 由 AI 为你维护的资料库，历史永久保留，可按项目授权
记忆 | 保存在用户目录的 Markdown 记忆，或在每回合前召回的 MemoryMesh 长期记忆
```

### 安全与审查

```ui-checklist
ok | 权限模式 | 仅可查看、工作区修改、自动审批与完全权限
ok | 审批管线 | 确定性规则、判定模型与复核模型；拿不准的一律交给你
ok | Diff 审查 | 统一与分栏视图、字词级差异、暂存与还原
ok | Git 提交 | AI 生成提交信息，提交到当前分支或新分支，并可推送
ok | 机密保护 | 环境变量的值永远不会显示给 AI 或界面
```

### 扩展 Vulcan Code

```ui-cards
技能 | 提示词技能（`SKILL.md`）与可编程的 LuaSkills 技能包
MCP | 连接本地与 HTTP MCP 服务器，也可以让 AI 为单个会话临时连接
MCP 服务 | 其他 AI 工具可以列出会话、发送消息、回答提问，每个工具一枚令牌
插件 | 插件可以提供工具和自己的页面，例如 AI 浏览器与用量统计
模型 | OpenAI、Anthropic、Gemini 等协议族，内置与自定义供应商，不同用途可选不同模型
```

```ui-callout info 预览版说明
0.1.x 各版本之间保存的数据格式仍可能变化。按版本逐步迁移数据的升级从 0.2 开始提供。
```
