Vulcan Code 0.1.0 是首個公開預覽版：一款圖形介面的 AI 工作台，既能寫程式，也能處理日常工作任務。專案、對話、終端機、瀏覽器、程式碼審查和 Git 提交都集中在同一處。

```ui-kv
版本類型 | 預覽版
用戶端 | 桌面應用程式、瀏覽器 WebUI、終端機用戶端（TUI）
介面語言 | 11 種
安裝套件 | 內建 Python、Node.js 與瀏覽器元件，一行指令即可安裝
授權條款 | MIT
```

### 本版重點

````ui-tabs
### 壓縮視窗
每個對話都能在輸入區的上下文容量表盤上隨時切換壓縮視窗，長任務不必另開對話。

```ui-kv
可選檔位 | 五個檔位，預設為 200K、256K、272K、373K、500K Token，可在設定中修改
跟隨模型 | 選擇「預設（跟隨模型）」即依目前模型的視窗壓縮
作用範圍 | 只改變自動壓縮的時機，不改變模型本身的上下文視窗
手動壓縮 | 隨時以 /compact 壓縮目前對話
```

### 工具卡片與摺疊
每類工具都有專屬卡片，工具呼叫再多也不會淹沒回答。

```ui-checklist
ok | 專屬工具卡片 | 檔案、指令、終端機、子代理、搜尋、媒體、提問、環境變數與設定變更等各有專門卡片
ok | 耗時與跳轉 | 每次呼叫都會顯示耗時，卡片中的檔案可直接在檔案面板開啟
ok | 依需求摺疊 | 執行時展開，完成後自動收合；連續呼叫歸為一組並顯示摘要
ok | 隨時切換 | 在設定中選擇預設行為，也可以用輸入區的「工具摺疊」或 /collapse 依對話切換
```

### 多模態
在「多模態能力擴充」中為每項能力設定模型：可以只用一個，也可以同時設定多個；對話內的「擴充能力」可依對話開關。

```ui-cards
網頁 | 網頁搜尋與內文擷取
理解 | 圖片、影片與音訊理解
生成 | 圖片與影片生成，圖片也可以使用 Codex 訂閱
語音與音樂 | 語音合成與轉寫、音樂生成與翻唱
```

### 環境變數
內建的環境變數管理讓金鑰留在本機，AI 只知道變數名稱。

```ui-checklist
ok | 三層管理 | 全域、專案與對話三層，直接在介面中新增修改，頁面可顯示在側欄
ok | 值不外露 | 值永遠不會顯示給 AI 或介面，工具結果中出現的值會被遮蔽
ok | 依需求填寫 | AI 缺少某個變數時會請你在表單中填寫，值不經過對話
ok | 自動注入 | 指令與終端機取得對應層級的變數，MCP 伺服器使用全域變數
```

### 子代理模型
子代理只會使用你允許的模型。

```ui-kv
兩級範圍 | 系統層級設定為預設，對話可以另外設定
預設勾選 | 發起呼叫的模型預設包含在內，可以取消
超出範圍 | 直接拒絕，不會悄悄換成其他模型
對話設定 | 可隨時在輸入區下方的對話設定中修改，也可以一鍵改回系統預設
```
````

### 工作台

```ui-cards
專案與對話 | 多專案、多對話並行，可調整對話順序，搭配檔案樹、審查、記憶與子代理面板
專案終端機 | 多分頁終端機；AI 可以保有長時間執行或需要互動的指令工作階段
檔案面板 | 以 @ 引用檔案、拖入輸入區、從終端機和輸出中開啟路徑，支援尋找與跳至指定行
豐富的回答 | 串流呈現 Markdown、程式碼與 Mermaid 圖表；互動回答提供清單、比較、圖表、流程等元件，決策卡片可直接插入或傳送回覆
分支與重試 | 編輯先前的問題重新產生，或從任一已完成的回合分支出新對話
命令面板 | 鍵盤快速鍵、對話內尋找，以及將對話複製為 Markdown
專職助手 | 基礎提示詞固定、設定凍結的對話，專門處理一類重複性工作
```

### 推進任務

```ui-cards
目標模式 | 設定目標和 Token 預算，AI 逐回合持續推進，可暫停、繼續或清除
計畫模式 | 先探索並寫出計畫，經你確認後再執行
執行中引導 | 任務執行時可以補充說明，或排入後續請求
子代理 | 內建探索、計畫等角色，另有可選的角色範本
結構化提問 | AI 需要你做決定時，會在對話內以選項卡片提問
```

### 程式碼、知識與記憶

```ui-cards
程式碼導覽 | CodeKit 直接讀取即時工作樹：符號、定義與引用
知識庫 | 由 AI 為你維護的資料庫，歷史永久保留，可依專案授權
記憶 | 儲存在使用者目錄的 Markdown 記憶，或在每回合前召回的 MemoryMesh 長期記憶，召回內容會顯示在工作過程中
```

### 安全與審查

```ui-checklist
ok | 權限模式 | 僅可查看、工作區修改、自動審批與完全權限
ok | 審批管線 | 確定性規則、判定模型與複核模型；拿不準的一律交給你
ok | 判定模型 | 可使用本機模型、雲端或 API
ok | Diff 審查 | 統一與分欄檢視、文字層級差異、暫存與還原
ok | Git | 拉取、AI 產生提交訊息、提交到目前分支或新分支，並可推送
```

### 擴充 Vulcan Code

```ui-cards
技能 | 提示詞技能（SKILL.md）與可程式化的 LuaSkills 技能套件，可從 LuaSkills Hub 安裝
MCP | 連接本機與 HTTP MCP 伺服器，也可以讓 AI 為單一對話臨時連接
MCP 服務 | 其他 AI 工具可以列出對話、傳送訊息、回答提問，每個工具各有一組權杖
AI 設定 | AI 可以幫你新增 MCP 伺服器與模型供應商，變更前先提供預覽，並依權限模式請你確認
外掛 | 外掛可以提供工具和專屬頁面，例如 AI 瀏覽器與用量統計
RTK | 壓縮指令輸出與 Git 上下文，節省 Token 並統計節省量
模型 | OpenAI、Anthropic、Gemini 等協定家族，內建與自訂供應商，不同用途可選用不同模型
```
