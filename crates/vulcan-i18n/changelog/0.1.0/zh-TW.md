Vulcan Code 0.1.0 是首個公開預覽版：一款圖形介面的 AI 程式開發工作台，把專案、對話、終端機、瀏覽器、程式碼審查和 Git 提交集中在同一處。

```ui-kv
版本類型 | 預覽版
用戶端 | 桌面應用程式、瀏覽器 WebUI、終端機用戶端（TUI）
介面語言 | 11 種
授權條款 | MIT
```

### 工作台

```ui-cards
專案與對話 | 多專案、多對話並行，搭配檔案樹、審查、記憶與子代理面板
專案終端機 | 多分頁終端機；AI 可以保有長時間執行或需要互動的指令工作階段
豐富的回答 | 串流呈現 Markdown、程式碼、Mermaid 圖表與工具卡片；互動回答還能使用發現、比較、圖表、流程等視覺化元件
分叉與重試 | 編輯先前的問題重新產生，或從任一已完成的回合分叉出新對話
專職助手 | 基礎提示詞固定、設定凍結的對話，專門處理一類重複性工作
```

### 推進任務

```ui-cards
目標模式 | 設定目標和 Token 預算，AI 逐回合持續推進，可暫停、繼續或清除
計畫模式 | 先探索並寫出計畫，經你確認後再執行
執行中引導 | 任務執行時可以補充說明，或排入後續請求
子代理 | 內建探索、計畫等角色，另有可選的角色範本，每個都只使用你允許的模型
結構化提問 | AI 需要你做決定時，會在對話內以選項卡片提問
```

### 程式碼、知識與記憶

```ui-cards
程式碼導覽 | CodeKit 直接讀取即時工作樹：符號、定義與引用
知識庫 | 由 AI 為你維護的資料庫，歷史永久保留，可依專案授權
記憶 | 儲存在使用者目錄的 Markdown 記憶，或在每回合前召回的 MemoryMesh 長期記憶
```

### 安全與審查

```ui-checklist
ok | 權限模式 | 僅可查看、工作區修改、自動審批與完全權限
ok | 審批管線 | 規則、判定模型與複核模型；拿不準的一律交給你
ok | Diff 審查 | 統一與並排檢視、字詞層級差異、暫存與還原
ok | Git 提交 | AI 產生提交訊息，提交到目前分支或新分支，並可推送
ok | 機密保護 | 環境變數的值永遠不會顯示給 AI 或介面
```

### 擴充 Vulcan Code

```ui-cards
技能 | 提示詞技能（`SKILL.md`）與可程式化的 LuaSkills 技能套件
MCP | 連接本機與 HTTP MCP 伺服器，也可以讓 AI 為單一對話臨時連接
MCP 服務 | 其他 AI 工具可以列出對話、傳送訊息、回答提問，每個工具各有一組權杖
外掛 | 外掛可以提供工具和專屬頁面，例如 AI 瀏覽器與用量統計
模型 | OpenAI、Anthropic、Gemini 等協定家族，內建與自訂供應商，不同用途可選用不同模型
```
