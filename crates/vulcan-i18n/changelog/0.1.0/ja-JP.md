Vulcan Code 0.1.0 は最初の公開プレビュー版です。プロジェクト、会話、ターミナル、ブラウザー、コードレビュー、Git コミットをひとつにまとめた、グラフィカルな AI コーディングワークベンチです。

```ui-kv
リリース | プレビュー版
クライアント | デスクトップアプリ、ブラウザー WebUI、ターミナルクライアント（TUI）
表示言語 | 11 言語
ライセンス | MIT
```

### ワークベンチ

```ui-cards
プロジェクトと会話 | 複数のプロジェクトと会話を並行して扱い、ファイルツリー、レビュー、メモリ、サブエージェントのパネルを備えます
プロジェクトターミナル | 複数タブのターミナル。AI は長時間実行や対話型のコマンドセッションを保持できます
リッチな回答 | Markdown、コード、Mermaid 図、ツールカードをストリーミング表示。インタラクティブ回答では検出結果・比較・グラフ・フローなどの視覚コンポーネントも使えます
分岐と再試行 | 過去の質問を編集して再生成したり、完了した任意のターンから新しい会話を分岐できます
専任アシスタント | ベースプロンプトを固定し設定を凍結した会話で、繰り返し発生するひとつの作業に専念します
```

### 作業を進める

```ui-cards
目標モード | 目標と Token 予算を設定すると、AI がターンごとに作業を続けます。一時停止、再開、クリアが可能です
計画モード | まず調査して計画を書き、承認後に実行します
実行中のガイド | タスクの実行中に指示を追加したり、後続のリクエストをキューに入れたりできます
サブエージェント | 組み込みの探索・計画ロールに加え任意のロールテンプレートを利用でき、それぞれ許可したモデルだけを使います
質問 | AI が判断を必要とするとき、会話内で選択肢カードを使って質問します
```

### コード、ナレッジ、メモリ

```ui-cards
コードナビゲーション | CodeKit が実際の作業ツリーからシンボル、定義、参照を直接読み取ります
ナレッジベース | AI があなたのために管理するライブラリ。履歴は永久に保持され、プロジェクトごとにアクセスを許可できます
メモリ | ユーザーフォルダーに保存する Markdown メモリ、または各ターンの前に想起する MemoryMesh 長期メモリ
```

### 安全性とレビュー

```ui-checklist
ok | 権限モード | 閲覧のみ、ワークスペース編集、自動承認、フルアクセス
ok | 承認パイプライン | ルール、判定モデル、レビューモデル。判断がつかないものはすべてあなたに確認します
ok | Diff レビュー | 統合表示と分割表示、単語単位の差分、ステージングと取り消し
ok | Git コミット | AI がメッセージを作成し、現在のブランチまたは新しいブランチにコミットしてプッシュできます
ok | シークレット | 環境変数の値が AI や画面に表示されることはありません
```

### Vulcan Code を拡張する

```ui-cards
スキル | プロンプトスキル（`SKILL.md`）とプログラム可能な LuaSkills パッケージ
MCP | ローカルと HTTP の MCP サーバーに接続でき、AI にひとつの会話だけ接続させることもできます
MCP サービス | ほかの AI ツールが会話の一覧取得、メッセージ送信、質問への回答を行えます。ツールごとに専用の Token を発行します
プラグイン | プラグインはツールや独自のページを追加します。例：AI ブラウザー、使用量統計
モデル | OpenAI、Anthropic、Gemini などのプロトコルファミリー、組み込みプロバイダーとカスタムプロバイダーに対応し、用途ごとに別のモデルを選べます
```
