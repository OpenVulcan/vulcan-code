Vulcan Code 0.1.0 は初の公開プレビュー版です。コードを書くことにも日々の業務にも使えるグラフィカルな AI ワークベンチで、プロジェクト、セッション、ターミナル、ブラウザー、コードレビュー、Git コミットをひとつの場所にまとめています。

```ui-kv
リリース | プレビュー
クライアント | デスクトップアプリ、ブラウザーの WebUI、ターミナルクライアント（TUI）
表示言語 | 11 言語
パッケージ | Python、Node.js、ブラウザーコンポーネントを同梱し、コマンド 1 つでインストール
ライセンス | MIT
```

### ハイライト

````ui-tabs
### 圧縮ウィンドウ
各セッションの圧縮ウィンドウは、入力欄のコンテキスト容量ダイヤルからいつでも切り替えられます。長いタスクでも新しいセッションを作り直す必要はありません。

```ui-kv
サイズ | 5 段階。デフォルトは 200K、256K、272K、373K、500K トークンで、設定で変更可能
モデルに従う | 「デフォルト（モデルに従う）」を選ぶと、現在のモデルのウィンドウに合わせて圧縮
適用範囲 | 変わるのは自動圧縮のタイミングだけで、モデル自体のコンテキストウィンドウは変わりません
手動圧縮 | /compact で現在のセッションをいつでも圧縮
```

### ツールカードと折りたたみ
ツールの種類ごとに専用のカードがあり、呼び出しが多くても回答が埋もれません。

```ui-checklist
ok | 専用カード | ファイル、コマンド、ターミナル、サブエージェント、検索、メディア、質問、環境変数、設定変更など
ok | 所要時間とリンク | すべての呼び出しに所要時間を表示し、カード上のファイルはファイルパネルで直接開けます
ok | 必要に応じて折りたたみ | 実行中は展開し、完了すると折りたたみ。連続した呼び出しはひとつの要約にまとめます
ok | いつでも切り替え | デフォルトは設定で選び、セッションごとに入力欄の「ツールの折りたたみ」または /collapse で切り替え
```

### マルチモーダル
「マルチモーダル拡張」では機能ごとにモデルを 1 つ、または複数割り当てられます。「拡張機能」でセッションごとにオン・オフできます。

```ui-cards
ウェブ | ウェブ検索とページ本文の抽出
理解 | 画像、動画、音声の理解
生成 | 画像と動画の生成。画像は Codex サブスクリプションも利用可能
音声と音楽 | 音声合成と文字起こし、音楽生成とカバー
```

### 環境変数
組み込みの環境変数管理により、シークレットは手元のマシンに留まり、AI には変数名しか見えません。

```ui-checklist
ok | 3 つの階層 | グローバル、プロジェクト、セッションの 3 階層を画面上で編集でき、ページはサイドバーに表示できます
ok | 値は非表示 | 値が AI や画面に表示されることはなく、ツール結果に現れた値はマスクされます
ok | 必要なときに入力 | AI に足りない変数があるとフォームで入力を求め、値が会話を経由することはありません
ok | 自動で注入 | コマンドとターミナルには対応する階層の変数が渡され、MCP サーバーはグローバルの変数を使います
```

### サブエージェントのモデル
サブエージェントは、あなたが許可したモデルだけを使います。

```ui-kv
2 つのレベル | システム設定がデフォルトで、セッションごとに個別に設定できます
デフォルトで選択 | 呼び出し元のモデルはデフォルトで含まれ、選択を外すこともできます
範囲外 | そのまま拒否され、別のモデルに黙って置き換えられることはありません
セッションの設定 | 入力欄の下にある「セッションの設定」でいつでも変更でき、ワンクリックでシステムのデフォルトに戻すこともできます
```
````

### ワークベンチ

```ui-cards
プロジェクトとセッション | 複数のプロジェクトとセッションを好きな順に並べて同時に扱え、ファイルツリー、レビュー、メモリ、サブエージェントのパネルを備えます
プロジェクトのターミナル | 複数タブのターミナル。AI は長時間実行や対話型のコマンドセッションを保持できます
ファイルパネル | @ でファイルを参照、入力欄へドラッグ、ターミナルや出力からパスを開く、検索と行ジャンプ
リッチな回答 | Markdown、コード、Mermaid 図をストリーミング表示。インタラクティブな回答ではチェックリスト、比較、チャート、フローなどが加わり、決定カードから返信を挿入または送信できます
分岐と再試行 | 以前の質問を編集して再生成するか、完了した任意のターンから新しいセッションをフォーク
コマンドパレット | キーボードショートカット、会話内の検索、会話を Markdown としてコピー
専任アシスタント | 基本プロンプトが固定され、設定が凍結されたセッション。繰り返し発生する 1 つの仕事を担当
```

### 作業を進める

```ui-cards
目標モード | 目標とトークン予算を設定すると、AI がターンごとに作業を続けます。一時停止、再開、クリアが可能
計画モード | まず調査して計画を書き、承認後に実行
実行中の誘導 | タスクの実行中に指示を追加したり、後続のリクエストをキューに入れたりできます
サブエージェント | 組み込みの探索・計画ロールと、任意のロールテンプレート
質問 | AI が判断を必要とするとき、セッション内で選択肢カードを使って質問します
```

### コード、ナレッジ、メモリ

```ui-cards
コードナビゲーション | CodeKit が実際の作業ツリーを読み取り、シンボル、定義、参照をたどります
ナレッジベース | AI が管理するライブラリ。履歴は永久に保持され、プロジェクトごとにアクセスを許可できます
メモリ | ユーザーフォルダーの Markdown メモリ、または各ターンの前に想起され作業過程に表示される MemoryMesh の長期メモリ
```

### 安全性とレビュー

```ui-checklist
ok | 権限モード | 閲覧のみ、ワークスペース編集、自動承認、フルアクセス
ok | 承認パイプライン | ルール、判定モデル、レビューモデルで確認し、判断がつかないものはあなたに回します
ok | 判定モデル | ローカルモデル、クラウド、API のいずれでも実行可能
ok | 差分レビュー | 統合ビューと分割ビュー、単語レベルの差分、ステージと元に戻す操作
ok | Git | プル、AI によるコミットメッセージ作成、現在のブランチまたは新しいブランチへのコミット、そしてプッシュ
```

### Vulcan Code の拡張

```ui-cards
スキル | プロンプトスキル（SKILL.md）とプログラム可能な LuaSkills パッケージ。LuaSkills Hub からインストール可能
MCP | ローカルおよび HTTP の MCP サーバーに接続できるほか、1 つのセッションに限って AI に接続させることもできます
MCP サービス | 他の AI ツールがセッションの一覧取得、メッセージ送信、質問への回答を行えます。トークンはツールごとに発行
AI 設定 | AI が MCP サーバーやモデルプロバイダーを追加します。先にプレビューを示し、権限モードに応じて確認を求めます
プラグイン | プラグインはツールや独自のページを追加します。例：AI ブラウザー、使用量の統計
RTK | コマンド出力と Git コンテキストを圧縮してトークンを節約し、節約量を集計
モデル | OpenAI、Anthropic、Gemini などのプロトコルファミリー、組み込みとカスタムのプロバイダー、用途ごとに別々のモデル
```
