Vulcan Code 0.1.0 — первая публичная предварительная версия: графическая среда для программирования с ИИ, где проекты, разговоры, терминалы, браузер, ревью кода и коммиты Git собраны в одном месте.

```ui-kv
Выпуск | Предварительная версия
Клиенты | Настольное приложение, WebUI в браузере, терминальный клиент (TUI)
Языки интерфейса | 11
Лицензия | MIT
```

### Рабочая среда

```ui-cards
Проекты и разговоры | Много проектов и разговоров одновременно, с панелями дерева файлов, ревью, памяти и субагентов
Терминалы проекта | Терминалы с вкладками; ИИ может удерживать долгие или интерактивные командные сессии
Насыщенные ответы | Потоковый вывод Markdown, кода, диаграмм Mermaid и карточек инструментов; интерактивные ответы добавляют визуальные компоненты: находки, сравнения, диаграммы, схемы
Ветвление и повтор | Отредактируйте прежний вопрос, чтобы получить новый ответ, или ответвите новый разговор от любого завершённого хода
Выделенные ассистенты | Разговоры с фиксированным базовым промптом и замороженными настройками для одной повторяющейся задачи
```

### Работа над задачами

```ui-cards
Режим цели | Задайте цель и бюджет Token; ИИ продолжает работу ход за ходом, его можно приостановить, возобновить или сбросить
Режим планирования | Сначала исследование и план, выполнение — только после вашего одобрения
Подсказки на ходу | Добавляйте указания или ставьте в очередь новые запросы, пока задача выполняется
Субагенты | Встроенные роли исследования и планирования и необязательные шаблоны ролей, каждая ограничена разрешёнными вами моделями
Вопросы | Когда ИИ нужно решение, он спрашивает прямо в разговоре с карточками вариантов
```

### Код, знания и память

```ui-cards
Навигация по коду | CodeKit читает актуальное рабочее дерево: символы, определения и ссылки
База знаний | Библиотеки, которые ИИ ведёт для вас, с постоянной историей и доступом по проектам
Память | Память в Markdown в папке пользователя или долговременная память MemoryMesh с извлечением перед каждым ходом
```

### Безопасность и ревью

```ui-checklist
ok | Режимы разрешений | Только просмотр, изменение рабочей области, автоодобрение и полный доступ
ok | Конвейер одобрения | Правила, модель решений и модель-рецензент; всё неочевидное передаётся вам
ok | Ревью Diff | Единый и раздельный вид, изменения на уровне слов, индексирование и откат
ok | Коммиты Git | Сообщения пишет ИИ, коммит в текущую или новую ветку, затем push
ok | Секреты | Значения переменных окружения никогда не показываются ни ИИ, ни в интерфейсе
```

### Расширение Vulcan Code

```ui-cards
Навыки | Навыки-промпты (`SKILL.md`) и программируемые пакеты LuaSkills
MCP | Подключайте локальные и HTTP-серверы MCP или позвольте ИИ подключить сервер для одного разговора
Служба MCP | Другие ИИ-инструменты могут получать список разговоров, отправлять сообщения и отвечать на вопросы, у каждого свой Token
Плагины | Плагины добавляют инструменты и собственные страницы, например ИИ-браузер и статистику использования
Модели | OpenAI, Anthropic, Gemini и другие семейства протоколов, встроенные и пользовательские провайдеры, отдельные модели для разных задач
```
