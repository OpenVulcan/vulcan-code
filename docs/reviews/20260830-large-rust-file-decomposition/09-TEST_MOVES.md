## 核对口径

- 原文件包含 122 项有效测试，全部原样迁移；17 个共享夹具保留父模块，1 个局部辅助函数随所属测试移动。
- 旧前缀统一为 `v1::document::document_tests::`；下表逐项列出新职责模块和测试名称，旧名为旧前缀加测试名称，新名为旧前缀加模块名、`::` 和测试名称。
- 测试属性、函数主体、断言与资源身份不变；测试之间没有互相调用。共享夹具只有一份，子模块复用父模块测试命名空间。
- 假定 Provider／模型身份只是本领域夹具输入，不执行供应商目录查询；不能因为夹具使用历史示例 ID 就删除有意义的状态机测试。
