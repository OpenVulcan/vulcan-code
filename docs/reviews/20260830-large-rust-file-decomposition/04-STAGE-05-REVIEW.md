3. 第五阶段移除根部显示专属模型/Schema及LanceDB列/格式残留导入；没有添加allow或其他警告压制。
4. 修正绑定释放不只用于创建失败、共享缓存不意味着句柄生命周期只能激活一次、显示初始化并不创建代次FTS、显示元数据并非单事务原子发布等过时注释；补充转换与新模块入口参数/返回说明。全部业务表达式、SQL、断言均与冻结原始节点严格等价。
