# 拆分前测试校正台账

## 用户最新授权

用户明确要求先修复旧测试：无意义测试可以移除；仍有意义、但因源码或函数变化而过时的测试必须修正为符合当前契约的测试。治理范围为本次 15 个超大文件及其关联测试，不扩展为无关全仓库整改。

## 判定规则

1. 当前契约仍成立：保留测试，不能因失败就判为无效。
2. 当前类型、函数或实际清单已改变：更新构造／预期／入口，保留原本有意义的行为验证。
3. 行为已明确删除，且测试不再验证任何有效契约：记录源码证据、替代覆盖和移除理由后再删除。
4. 失败由资源、环境或真实生产缺陷造成：独立诊断，不以删除测试或降低断言强度规避。
