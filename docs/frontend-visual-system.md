# 前端视觉与响应式基线

本轮调整日期：2026-09-08。范围为 WebUI 的全局视觉、共享组件和响应式布局，保留现有功能入口、数据操作与后端契约。

## 样式归属

- `apps/vulcan-code-web/src/ui/foundations/theme.css`：明暗主题唯一基础色板、圆角、浮层阴影。
- `apps/vulcan-code-web/src/ui/foundations/tokens.css`：语义颜色和页面间距；业务页面优先引用语义变量。
- `apps/vulcan-code-web/src/styles/responsive.css`：跨页面容器约束、手机布局、触摸尺寸与减少动效规则。
- `apps/vulcan-code-web/src/components/ui/`：按钮、输入、选择、弹窗、表格和导航抽屉的共享实现。

亮色采用浅灰画布和白色内容表面，暗色采用蓝灰画布、内容表面和浮层分级。文本、边界、选中状态与错误状态分别使用对应语义颜色；混色使用 sRGB。正文输入区与下方工具条仍保留轻微层次和分隔线。

## 布局规则

1. 宽度不超过 720 像素时，主导航为模态抽屉，默认关闭。手机展开状态独立于桌面偏好；进入页面、选择会话和新建会话后关闭抽屉。支持关闭按钮、遮罩、Esc 与焦点恢复。
2. 页面使用动态视口高度，内容区域自行滚动。手机正文占满可用宽度；底部输入区和状态栏考虑安全区。
3. 记忆、技能、插件和智能体共用固定左导航与不限宽正文布局。导航采用独立浅色表面、统一行高与选中标记。可用面板宽度不超过 720 像素时，导航转为限高 156 像素的双列顶部菜单；长目录独立滚动，保留全部分类与筛选。
4. 表单按内容容器可用宽度调整列数。供应商表格在窄容器中转为带字段标签的记录布局，保留每个单元格的操作。
5. 知识库创建和搜索在窄屏各占一行，操作按钮并排，库列表与详情上下排列。记忆项目选择优先保留名称宽度，次要按钮空间不足时换行。
6. 手机普通按钮和表单控件至少 40 像素高；弹层有视口宽高上限，列表保留独立滚动。虚拟列表行高不由通用触摸规则改写。
7. 桌面与手机共享业务组件和事件回调，不通过隐藏能力来换取布局空间。移动导航仅改变呈现和关闭行为。
