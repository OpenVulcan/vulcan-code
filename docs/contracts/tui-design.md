# Vulcan Code TUI 结构说明

> 实现细节以源码为准；本文只描述 `apps/vulcan-code-tui` 的分层与交互约定。

## 运行

```bash
cargo run -p vulcan-code-tui --bin vulcan-tui -- --locale zh-TW
```

参数：

- `--backend service|mock`：默认 `service`，连接本机运行中的 Vulcan Code 服务；`mock` 为脚本化演示。
- `--service-root <dir>`：服务用户根目录（其下为 `code/webui-service.json`）；省略时依次搜索用户目录下的常用服务根。
- `--locale <tag>`：省略时跟随服务的界面语言，再按系统语言匹配。
- `--theme dark|light`。

重新编译前须先关闭正在运行的 `vulcan-tui.exe`（Windows 会锁定可执行文件）。

发行物把 `vulcan-tui` 与服务一同发布到 `bin/`，并在运行布局清单中声明为 `tuiExecutable`。Windows 托盘的“打开终端客户端”
在新控制台中按该条目启动，并以 `--service-root` 绑定到托盘所属 Core 的发现根目录，因此不会连到其他服务实例。

## 分层

| 目录 | 职责 |
| --- | --- |
| `apps/vulcan-code-tui/src/model/` | 与服务协议对齐的数据模型（会话、事件、工具调用、Git、页面标量） |
| `apps/vulcan-code-tui/src/backend/` | `Command` / `BackendEvent` 通道；`service/` 连接真实服务，`mock/` 为脚本化模拟服务 |
| `apps/vulcan-code-tui/src/backend/service/` | 发现文件 → `POST /rpc` + `/events` WebSocket；单工作线程持有工作台投影与事件窗口（见下文） |
| `apps/vulcan-code-tui/src/service_api/` | WebUI 服务函数的一对一请求构建器、槽位、字段编辑器与两步预检确认协议 |
| `apps/vulcan-code-tui/src/app/` | 状态机：焦点、区域、浮层、提问、历史索引、命中表，以及 `action::perform` 单一副作用入口 |
| `apps/vulcan-code-tui/src/app/input/` | 键盘与鼠标输入，按焦点与浮层分派 |
| `apps/vulcan-code-tui/src/ui/` | 纯渲染：工作台、侧栏、会话记录、思考框、输入框、右侧面板、系统页面、浮层 |
| `apps/vulcan-code-tui/src/i18n/` | 基于共享目录（`crates/vulcan-i18n`）的运行时翻译与键检查 |

## 界面

会话 HTML 回答可在输入区、`Alt+H` 或 `/html` 切换。`/html-results` 提供 Core 结果的浏览器打开、
链接复制与原始源码检查；会话正文将精确 Core 围栏渲染为带默认浏览器按钮的结果块，鼠标点击或
选中消息后按回车先确认、再签发并打开。多个结果通过选择面板逐个操作。打开后保留真实临时地址，
兼容缺少浏览器、远程终端或启动器返回成功但无可见窗口的环境。具体授权契约见
[`session-html-answers.md`](session-html-answers.md)。

- **顶栏**：品牌、分支、连接状态。活动栏放不下时加入“当前区域 ▾ F2”切换按钮，其优先级高于右侧状态。
  标签式活动栏与会话面板同时内联、且状态放得进面板宽度时，顶行只拆成活动栏上方的品牌单元格和面板上方的
  状态单元格（各自延续下方列的边框），侧栏与对话列直接从顶行开始；其他布局保留横跨窗口的整行顶栏。
- **活动栏**：左边缘的纵向区域切换栏，顺序与 WebUI 活动栏一致：工作台、分隔线、插件（知识库作为插件页面缩进
  在其下，由 `Area::parent` 唯一定义）、技能、代理、记忆，设置固定在底部。宽度足以并排放下完整工作台时显示
  图标与名称，否则只显示图标，更窄时隐藏并改用顶栏按钮；F2 始终可用。在其他区域时工作台条目显示运行或待处理
  标记；已在工作台时点击工作台条目折叠或展开会话侧栏（同 Ctrl+B）。
- **工作台**：
  - 左侧栏：新建会话、添加项目（文件夹选择器）、项目置顶与分组、右键或 `⋯` 打开菜单。分隔线上的 `⊟/⊞`（或 `z`）
    折叠/展开全部项目，`«`（或 Ctrl+B）收起为窄栏：按钮加每个项目的首字母与运行/待处理标记，点击首字母以抽屉
    打开列表并定位该项目。宽度放不下完整侧栏时自动显示窄栏；连窄栏都放不下时侧栏只在获得焦点时以抽屉出现。
  - 会话记录：思考、回复（Markdown，`ui/markdown.rs` 逐行渲染；带分隔行的管道表格按方框边框绘制，遵循
    `:--`/`:-:`/`--:` 对齐，过宽时按列收缩并在列内换行，连每列 3 格都放不下时退回为逐行文本；完整的
    `mermaid` 代码块由 `ui/mermaid.rs` 在同一框内绘制：流程图与状态图走分层布局（最长路径分层、长边折点、
    重心排序、层间每个来源一条走线通道，回指的边逆向绘制并带反向箭头），本方向过宽时改用另一方向；时序图
    绘制参与者、生命线、消息、注释与区块框；饼图转为条形。其他图表类型、无法解析的语句、两个方向都放不下
    或仍在流式输出时显示源码，不画错也不截断）、工具组可折叠；
    超过 12 行的用户消息折叠为 8 行预览，点击展开；Ctrl+T 切换思考框停靠/浮动。鼠标单击或右键只原地选中所在
    块，不滚动视图（块已在屏幕上，滚到其顶部会让文本离开指针）；键盘移动选择时才把所选块滚入可见范围。
  - 文本选择（`app/selection.rs`）：鼠标捕获使终端无法自行选字，因此在会话记录中按住左键拖动即选择文本，
    拖过上下边缘时逐行滚动；松开时以 OSC 52 将所选文本写入系统剪贴板并提示“已复制”，选择保持高亮直到下次
    单击。位置记录为排版行与显示列，滚动不影响；换会话或宽度变化时隐藏。复制内容由事件循环在处理完输入后
    写出（`console::write_sequence`）；不支持 OSC 52 的终端（如旧版 conhost）不会收到内容。
  - 会话栏（输入框上方固定一行）：上下文用量、本轮实时用量（运行中，`~` 表示流式估算）或上一轮、缓存命中率、
    会话合计（含子代理）、子代理、目标、记忆注入数、输出速度。各段有完整与紧凑两种形式和优先级，宽度不足时
    低优先级先收缩再隐藏，剩余空间再还给高优先级段；点击打开对应面板标签。对话列低于 14 行时不显示，上下文
    进度条改回状态栏。阈值颜色与 WebUI 一致（90% 警示、95% 危急，`Theme::usage_color` 唯一定义）。
  - 输入框：模式、附件、模型、推理强度、停止按钮；`/` 斜杠命令。Alt/Ctrl/Shift+Enter、Ctrl+J 或行尾 `\` 加
    Enter 换行；高度随内容增长，上限为对话列高度的 1/3（3–12 行）。4 行或 800 字以上的粘贴折叠为
    `[粘贴 #n · m 行]` 标签：退格/删除整体移除，点击或 Alt+V 预览、展开或移除，发送时展开为原文。不支持括号
    粘贴的终端中，逐键到达的粘贴会在事件循环中合并还原（`app::composer::coalesce`）。
  - 右侧面板（Alt+1..6 直达）：变更（仓库清单、diff、暂存、提交、推送、切换分支）、进度、终端、记忆（本会话的动态 TTL
    条目与静态画像）、统计（上下文用量、目标、主会话与子代理用量）、代理（子代理运行状态）。条目可打开
    详情表（Detail sheet）查看全文并执行操作。
- **系统区域**：左侧导航 + 声明式页面（`app/pages/` 按区域产出行，`ui/pages.rs` 统一渲染）。`pages::navigation(app)`
  为每条导航行提供名称、计数、选择状态及共享动作；静态页面清单不再作为分类或知识库下标。
  - 插件：LuaSkills 技能包（工具显式/隐式/禁用切换、更新、卸载、安装）与 LuaSkills 设置；代码语义索引的项目
    （更新模式、同步、重建、碎片压缩）与引擎设置；Vulcan 插件列表。运行就绪插件的每个详情挂载在“插件”分组下
    占一个导航行（插件列表条目也可直接打开），`kind: settings` 版面渲染为：标题区状态、链接与就地阅读的包内文档；
    标签选择；字段（开关、选择、文本、数字、带全选/清空的清单，按 `visible_when` 条件显示）；遮蔽单次输入的
    凭据及其状态、替换与删除；操作按钮；数据区块（参数选择、刷新、最近加载时间、指标卡片、迷你走势图或
    `tui.variant: table` 的逐行列表、带名次的表格）。配置以完整对象写回并保留同级字段；配置含终端从不接收的
    机密字段时，字段只读并提示到桌面应用或 WebUI 修改。模块类挂载只显示说明。
  - 记忆：概览；数据组（内容、画像、记忆项目、内部维护）；配置组（规则、内部推理、原生资源、高级设置）。
  - 知识库：左侧按真实库名和文档数量选择，另有管理知识库入口；正文通过视图选择器进入概览、文档、搜索、
    来源、项目授权、设置或索引维护。文档按准确相对目录筛选，每页 20 条，额外读取一条确认下一页；
    根目录与全部目录分开。阅读页保留正文缩进和空行，可选择原始或展示语料，搜索命中可打开对应文档。
    来源支持导入、同步和保留来源身份的目录重映射；维护支持修复、重建、展示预检构建和向量构建。
    活动任务在上次观察成功后间隔两秒读取进度，完成后刷新当前内容，失败时保留可重试错误。
  - 代理、技能：左侧读取各自服务目录的真实分类、图标、本地化名称及数量；智能体按排序值排列分类，技能
    保持服务顺序且只统计生效版本。右侧支持状态、跨语言关键词筛选，技能另有来源及用户覆盖筛选；
    启用、覆盖还原和删除遵守服务权限。分类删除后回到全部分类，正文编辑仍在编辑器中进行。
  - 设置包含外观与语言、上下文、Git 提交、供应商、凭据、模型、AI 能力、MCP、已归档会话、诊断与关于。
- **页面行类型**：分节标题线、带点引导线的只读信息、开关、选项、数字（‹ › 步进，Enter 直接输入并校验范围）、
  文本、按钮、可展开条目（操作按钮单行排列，排不下的收进 `⋯` 菜单）、统计卡片、进度条及保留空白的文档正文。
  条目按钮可以是带标签的开关（对应 WebUI 开关单元格）；禁用按钮及不适用的 `—` 单元格不获得焦点、不注册点击、
  不进入溢出菜单。
- **单行按钮条**：页面条目操作、右侧面板标签、Git 按钮与面板内按钮行都不换行；`ui::text::fit_strip` 是唯一的
  排布规则，放不下的项目收进 `⋯` 溢出按钮，点击以菜单列出；当前标签或键盘选中的按钮始终保持可见。
- **设置编辑**：单字段输入经过校验后立即构建真实保存请求；完整 DTO 保存保留全部同级字段，部分更新只发送协议允许的字段。写入完成并刷新权威槽位前，阻止另一份完整文档覆盖。多个必填字段使用顺序表单，取消即丢弃临时输入。
- **预检审查**：知识导入与展示构建、插件安装、VCE 路由及维护、VMM 删除与维护先显示可滚动的服务预检明细，再明确确认。就绪文件清单可缩减；导入与展示构建使用各自确认结构，不能添加未审查文件；VCE 逐项目选择兼容或重建，强制重建项不能改成兼容。
- **凭据**：输入遮蔽显示且仅放在临时表单中发送一次；回包进入槽位前清空密钥、任意命名的 MCP 请求头与环境值。修改 MCP 时需要重新输入这些值，界面有明确说明；环境变量名称引用与安装密钥名称保留。
- **浮层**：命令面板、选择器、菜单、确认、输入提示、文件夹选择器、diff、提交对话框、帮助、历史浏览（Ctrl+F）与详情查看器。
- **通知组件**：提示（toast）、由实时状态派生的通知与日后插件声明的通知共用 `app/notice.rs` 的声明形状和
  `ui/notice.rs` 的唯一渲染器。声明为带 `type` 标记的 JSON（当前只有 `notice`），字段为 `key`（同键替换）、
  `title`、`message`、`tone`、`title_tone`、`frame_tone`、`placement`（`top_right` 默认、`top_left`、`top_center`、
  `bottom_right`、`bottom_left`、`bottom_center`）、`frame`（`bar` 默认、`box` 标题嵌入边框、`plain`）、`progress`
  （以旋转指示代替图标）与 `duration_ms`；未知类型或字段被拒绝。色调只用主题名称 `normal`、`muted`、`success`、
  `warning`、`danger`、`accent`、`info`，不接受颜色值。内置通知在 `app/notice-presets.json` 中以同一形状声明，代码只
  提供文本；同一锚点的通知自锚点依次排开，实时通知最靠近锚点。会话处于 `MemoryRecall` 运行阶段（回答前 PreCheck
  召回，对应 WebUI 的 `runtime.memoryRecall`）时显示“正在召回记忆”通知，阶段结束即消失。

## 交互约定

- 所有区域支持鼠标：单击聚焦或激活、双击打开、右键菜单、滚轮滚动；浮层外点击关闭浮层。
- 提问（Ask）为会话内非模态面板，带上一题 / 下一题步进按钮。
- 历史浏览按类别过滤并搜索；详情查看器完整展开单个条目的全部事件（输入 JSON、变更、输出）。

## 暂未实现

- 输入框 `@` 文件提及。
- 浏览器 OAuth 授权流程；凭据页支持按服务声明的配置导入令牌或已取得的授权凭据。
- 插件 ESM 模块页面（`kind: module`）与内置浏览器等仅 WebUI 可用的插件视图。

## 服务后端

- **发现与连接**：读取服务自身的发现文件取得地址与令牌；以 `startup.snapshot` 探测，再打开
  `/events?token=&clientId=`（`clientId` 为本进程 UUID，重连期间不变）并拉取 `workbench.snapshot`。传输失败
  或事件流关闭时以 0.5 s 起、翻倍至 5 s 的退避重新发现并重连。令牌只存在于请求头与 WebSocket URL 中，
  不写入日志、提示、错误或 `Debug` 输出。
- **共享 DTO**：TUI 链接 `vulcan-service-api` 与 `vulcan-session-core`，事件帧、工作台快照、增量、会话事件窗口
  及各 RPC 响应都按共享类型严格解析，事件状态枚举直接复用共享类型；不符合类型的数据以“无法读取”提示报告来源
  与期望类型，不回显取值（serde 错误可能引用凭据）。只有 Git 载荷（DTO 位于服务内核、未共享）仍由
  `service/wire.rs` 按字段读取。系统区域槽位仍保存原始 DTO，工作台槽位由类型化快照序列化后取允许字段。
  每个会话命令按其声明的响应类型折叠：工作台快照直接应用；会话附加状态响应与子代理路由响应按 `revision`
  合并；置顶切换与模型选择不返回快照，与 WebUI 一致随后重读工作台。
- **单线程状态**：界面命令、事件帧、套接字关闭、后台调用结果都进入同一收件箱；工作台快照按 `revision` 折叠
  `workbenchDelta`（独立生命周期类增量不受代际过滤），会话事件按 v1 窗口规则（`service_epoch`、窗口代际、
  `memory_revision` 缺口即重新加载）合并，文本追加按 UTF-16 基准长度截断后拼接，并以完整事件 `EventUpsert`
  交给界面。
- **耗时调用**：通用 `ServiceCall`、提交、提交信息生成及提交/推送在后台线程执行，结果携带连接代际交回工作线程。槽位读取另有发送序号，较旧响应不能覆盖较新的读取；断线后的结果被丢弃。
- **新建会话**：先在本地建立草稿（`draft:` 前缀），首次提交时以 `draftSlotKey = new:<projectId|workspace>`
  并携带模型与推理强度创建真实会话，确认后以 `Selected` 切到真实 ID 并移除草稿。已有会话的模型与推理强度
  通过 `service_select_public_ai_model` / `service_select_workbench_reasoning_effort` 单独切换；推理强度只在
  当前模型接受的取值内循环。
- **附件**：由 TUI 读取本地文件字节，经 `service_stage_composer_attachment_bytes` 暂存后随提交发送；附件
  选择器直接列出本地磁盘，项目文件夹选择器使用服务的 `service_browse_project_directories`。
- **Git**：工作区为选中会话的项目。首次显示项目、显式刷新（`r`）及新连接时，与 WebUI
  `refreshProjectGitSummary` 一致读取 `workspace.git.catalog` 及每个受监听仓库的未暂存与已暂存快照；之后只按变化
  增量重读（见下文内存规则）。详情、分支与推送属于所选仓库。所选仓库
  依次取：仍受监听的当前选择、受监听的主仓库、第一个受监听仓库；都没有时显示“无可用仓库”且不保留旧详情。
  切换到另一项目时先发布 `GitCleared`，旧项目的清单不得在新项目加载期间继续显示。仓库多于一个、或没有受监听
  仓库时，变更标签页顶部列出全部仓库（所选标记、相对路径、变更与领先计数，未监听显示 `○`）；点击受监听仓库或
  按 `g` 循环切换，标题行或 `m` 打开监听开关菜单（`workspace.git.setMonitoring`，对应 WebUI Git 设置）。
  服务没有增量差异协议，增量由后端内存实现：每个项目按工作区路径保留目录、所选仓库及每个受监听仓库最近的两个
  视图。切换已加载的仓库、切换会话及回到已加载的项目都先从内存发布，不发请求；显示中项目的
  `workspaceGitChanged` 只重读事件指明的仓库（未指明时为全部受监听仓库，均不读目录），未显示项目的事件只
  标记仓库，回到该项目时只重读被标记的仓库。任何快照重读前先标记失效，两个视图均成功后才清除；失败后回到项目
  或重新选择仓库会重试。暂存、切换分支、提交与推送只重读所选仓库；监听开关只重读目录并
  加载新受监听的仓库；新连接使内存中的项目回到时重读目录。面板点击后立即标记所选仓库并
  隐藏旧仓库详情，跳过仍带较早选择的快照，直到后端发布该仓库，快速连续点击不会来回跳动。
  文件操作与详情使用服务返回的文件标识。diff 请求、响应及缓存同时绑定工作区、仓库键、文件路径和暂存模式；
  同一文件的暂存与未暂存版本分别读取，归属已改变的响应被丢弃。与 WebUI `sessionGitRepositoryAvailable` 一致，目录没有仓库且不在
  加载或 Git 操作中时，面板不显示变更标签（`App::panel_tabs`），所选标签保留并在回到有 Git 的项目时恢复；
  `Alt+1` 在隐藏期间不生效。文件 diff 读取失败或文件已不在变更清单时发布 `GitDiffFailed`，diff 视图以
  “载入失败”及服务原因取代加载状态，`r` 或重试按钮再次请求。
- **会话选择**：工作线程按顺序处理选择命令，工作台快照可能仍带有较早的选择；界面上最近且仍在列表中的选择
  保持不变，快照只补上缺失或已移除的选择，侧栏光标只随实际变化移动，避免快速切换时被拉回旧会话。
- **系统区域**：使用与 WebUI 完全相同的函数、RPC 方法和参数形状。原始 DTO 放入命名槽位，工作台只投影页面所需的允许字段；聊天与 Git 保留类型化事件，因为后端需要管理其会话、草稿和工作区。不存在独立的系统命令或设置草稿协议。
- **变更刷新**：`CallKind::Mutate` 成功后使用受影响槽位最近登记的加载器刷新。刷新失败清空旧值并保留重试加载器；当前页面可手动重新加载。项目、知识库及画像选择改变后清空依赖槽位，文档读取还检查目录、分页、文档身份及语料。新搜索立即清空旧命中。加载失败以 `SlotFailed` 保留脱敏原因，匹配重试时清除；旧归属的失败不能覆盖当前页面。
- **事件与重连**：重新连接后加载当前页面。VCE 概览变更按项目刷新，任务事件按项目、任务身份及序号过滤，终态刷新概览；界面关闭时显式终止工作线程及事件读取器。
- **模拟服务**：`backend/mock/service.rs` 持有仓库内合成 DTO。已实现写入会修改后续加载器读取的状态，项目与知识库相互隔离；预检冻结版本与目标，回收恢复只合并已移动记录。未知演示写入沿用成功回执，不能用作真实协议验收证据。完整对接矩阵见 [服务适配说明](tui-service-adaptation.md)。

## 验证

TUI 是工作区成员，沿用根 `.cargo/config.toml` 的四任务编译与测试限制及工作区 lint：

```bash
cargo fmt --check
cargo clippy -p vulcan-code-tui --all-targets -- -D warnings
cargo nextest run -p vulcan-code-tui -p vulcan-i18n
```

Windows 上运行中的 TUI 会锁住其可执行文件；此时加 `--target-dir target/verification` 在独立目录验证。

协议测试使用本地合成 HTTP/WebSocket 服务器，验证认证信封、密钥错误回显清理、乱序读取、连接代际与后台线程退出。
回归测试验证完整 DTO 的同级字段、预检指纹和版本、幂等任务、选择作用域、回收恢复与输入遮蔽。
无头渲染（`src/render_smoke_tests.rs`）覆盖全部系统页面及工作台浮层，在 160×45 和 64×20 尺寸下通过命中表驱动
鼠标操作；需要目视检查布局时设置 `VULCAN_TUI_SNAPSHOT_DIR=<目录>` 后运行该测试输出快照。
使用模拟后端的测试经 `mock::inline()` 在测试线程逐步驱动：脚本延迟立即到期，事件逐条应用，等待一律写成状态条件
（如运行阶段、槽位已加载），不按墙钟时长等待；演示用的 `mock::spawn()` 保留真实节奏。

这些检查不包含真实服务的写入、付费模型调用或真实终端的人工验收。
