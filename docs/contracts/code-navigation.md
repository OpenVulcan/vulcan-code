# 代码导航

## 权威与同步触发点

内置代码导航由 `config/luaskills_root_skills.yaml` 中的 CodeKit 根技能、LuaSkills 工具注册与
`vulcan-agent-runtime` 的包主帮助注入链路共同定义。修改默认技能、可见工具、帮助注入或代码导航入口时，
必须同步本文，并验证工具目录、专职会话过滤与请求中的包主帮助。用户持久化的工具选择不被启动流程改写。

## 实时工作树

CodeKit 是唯一内置代码导航方案，在实时工作树上完成目录统计、结构定位、文本搜索、正文提取与整函数替换。
具体工具路由由已安装包的主帮助定义，宿主不另存一份说明。结构输出只能定位；证明行为必须读取正文、调用点或测试。
文本匹配必须保留没有结构归属的命中；长行使用有匹配位置的预览，主机按统一工具结果预算分页。

主机不预建整库代码图谱、代码向量库或替代检索引擎。需要语义代码检索时，由用户显式接入外部 MCP 服务。
只能描述概念的需求通过 AI 管理知识库中的架构笔记关联到实际源码，笔记不能代替当前源码证据。

## 退役依据与数据边界

`codebase_memory` 曾预建整库代码图谱，启动慢、内存占用高，并与 CodeKit 重复。
随后 VCE（`vulcan-context-engine`）使用向量、全文检索与重排，建库和查询仍慢，增加嵌入与重排成本，
收益不足以覆盖实时工作树查询的维护与过期成本。两者均已退役，不保留隐藏入口或降级路径。

共享 SQLite、LanceDB、分词器、通用嵌入能力与 Git 文件监听继续由各自消费者使用。
用户原有 VCE 数据目录不自动删除；应用表退役仅通过独立 Debug 数据库维护入口执行，原记录留在验证过的备份中。
维护契约见 [本地 Debug 应用数据库维护](debug-database-maintenance.md)。
