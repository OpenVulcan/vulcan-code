# OpenVulcan 全局账户接入

## 权威来源与同步条件

账户、授权、积分与原生推理协议属于 `openvulcan-web` 用户中心；其权威实现位于该仓库的
`server/internal/deviceauth/`、`server/internal/httpapi/control/`、`server/internal/vectorapi/`、
`server/internal/decision/` 与 `contracts/openapi-vulcancode.yaml`。
本文件说明 Vulcan Code 的接入边界，不替代上游协议。上游令牌轮换、域名、模型目录、用量字段或原生
契约版本变化时，必须重新核对上述源码，同时更新适配器、系统清单、接口文档与行为测试。

向量任务命名的当前事实同时核对用户中心 `src/admin-model-presets.ts`、
`server/seeds/defaults_cn.yaml` 与 `server/seeds/defaults_global.yaml`；模型修订允许的字符串形状
以 `server/internal/modelcatalog/model.go` 为准。预设或种子调整任务名称时同步核对目录到请求的投影。

系统供应商事实由 `crates/vulcan-runtime-assets/resources/provider-manifests/manifests/openvulcan.json`
发布；字段形状由供应商 Schema 与 Rust 类型共同校验。模型清单来自用户中心实时发现，不在客户端
复制模型名称、维度、批次大小或价格表。

## 首次启动与全局状态

- 软件服务就绪后首先加载账户，再原子认领应用数据目录下的 `openvulcan-onboarding-v1.seen`。
  该标记与工程目录无关；多窗口并发只有一个窗口获得首次提示，跳过后重启或切换工程不重复提示。
- 侧栏账户菜单长期保留登录和账户管理入口。首次提示可跳过，登录失败也不阻塞使用其他供应商。
- 账户、授权事务与供应商连接属于应用全局。浏览器界面只接收公开用户名、区域和连接标识，不能取得
  调用令牌、证明密钥或持久凭据内容。
- `core_account` 是系统供应商的账户生命周期标记。未登录时供应商目录隐藏它；登录提交完成后显示。
  普通供应商新增、编辑、禁用、删除和通用授权入口不得绕过账户登录／退出流程。
- 登录不会替用户选择向量、权限判定等模型用途。模型目录发现后，用户继续通过既有模型设置显式选择。
- 退出先清理本地连接与关联配置、删除凭据，再撤销当前设备远端授权。远端离线错误不会恢复本地登录。
  正在执行且已到达远端的请求不因此成为可安全重放的请求。

## 区域与授权

| 区域 | 授权及账户接口 | 推理接口 |
| --- | --- | --- |
| 中文版 | `https://auth.openvulcan.cn` | `https://api.openvulcan.cn` |
| 国际版 | `https://auth.openvulcan.com` | `https://api.openvulcan.com` |

用户选择区域后，区域与永久 `authorization_id` 随凭据持久化。登录、刷新、模型目录、账户、用量及
推理请求均使用该区域的固定域名；禁止重定向携带凭据，禁止失败后切换另一地区。

浏览器授权使用授权码与 S256 证明密钥；宿主预先监听数字环回地址 `127.0.0.1` 的随机端口，回调路径
固定为 `/vulcancode/auth/callback`。批准网址、事务编号、回调状态与授权码严格绑定，重复参数、错误
路径、错误状态与过期事务被拒绝。关闭弹窗取消当前事务，迟到回调不能创建账户；已收到但未提交的
令牌会尝试撤销当前设备授权。

本地回调由 Vulcan Code 服务返回自包含单页，使用官网 `openvulcan-web/src/site/brand.tsx` 的标识几何
及 `apps/vulcan-code-web/src/ui-kit/styles/tokens.css` 的主题配色。官网品牌调整时应同步本地模板；文案归属于共享 `oauth` 语言分面，
优先使用应用已保存语言，未选择时通过共享注册表检测系统语言。页面不加载外部脚本、字体或样式。
授权码交换成功只表示浏览器授权阶段完成，不代表账户读取与连接保存成功；最终结果由应用内账户窗口
确认。交换失败和回调校验失败各有独立结果页，错误详情仅在应用内展示。页面禁止缓存与来源转发，并在
加载后移除地址栏中的一次性参数；关闭被浏览器拦截时显示手动关闭指引。

账户窗口根据实际失败阶段显示可读说明，不解析英文错误文本推断状态码或故障原因。启动、授权和连接
失败可按用户原先选择的区域重新登录；已提交后仅状态读取失败时重读账户，不重放授权。技术详情默认
折叠，可完整复制；长行换行并在详情区内滚动，避免撑宽弹窗。错误组件自身加载样式，不依赖设置页先被
打开。进行中的登录隐藏旧错误并阻止并发登录，等待浏览器时仍可跳过并取消当前事务。

账户窗口仍按需加载，回调专属文案不进入工作台；分阶段错误文案及恢复操作使首屏压缩体积增加，
本次为该功能增加 1000 字节首屏 JavaScript 压缩预算（675000 → 676000），原始体积、启动入口与
样式预算保持不变。预算检查继续沿构建清单计算真实静态依赖。

用户中心使用 `Authorization: Auth <access_token>`，不提供独立刷新令牌。客户端使用服务端返回的
绝对过期时间，在到期前一天通过现有凭据租约续期；轮换保持永久设备编号不变。当前上游令牌有效期
为十四天，旧令牌轮换后仅能在五分钟宽限内继续普通调用，不能再次刷新，且宽限不超过其原过期时间。
这些上游时限仅为当前协议说明；客户端令牌有效期始终读取服务端响应。

同一进程内的所有工程及运行时代际共享连接级刷新锁。刷新前先以比较交换持久化轮换占用标记，再发送
一次刷新请求，并以比较交换保存新令牌。刷新结果未知、进程在轮换中退出或保存失败时，不再次消费旧
令牌；清除不可继续使用的本地登录并提示重新授权。普通账户读取遇到网络故障则保留仍有效的凭据；
明确鉴权失败或凭据到期才使账户失效。账户界面每分钟串行检查一次，推理前也会解析最新凭据。

凭据封装版本保持 1：`openvulcan_auth` 是新增材料类别，携带区域、永久设备编号、服务端到期时间与
轮换占用状态，其他材料的格式不变。遵守仓库 V0.1 阶段规则，不受支持的封装版本明确拒绝，不添加迁移
或推测性默认值。启动时逐连接校验，失败连接保留配置和可见错误，但不
阻断工作台和其他有效连接；运行中的清单更新仍维持严格原子发布。

凭据关系表沿用 `ai_credential_secrets`，名称由存储层常量统一提供，不引入带版本后缀的表。该表允许
`openvulcan_auth` 及其 `rotation_pending` 状态，要求访问令牌、区域、永久设备编号和正数到期时间，
不接受独立刷新令牌或签发时间。建表、读取、创建、比较替换、删除和补偿使用同一张表。

用户可在设置中删除失败连接、输入新 Key 或重新授权。显式修复只使用新提供的材料，旧记录仅作为
存储层的不透明补偿快照，不解释或迁移旧材料；后续验证或发布失败时，恢复原始格式并保持替换修订号
单调递增。启动不会删除凭据、改写用户的连接开关或自动选择替代账户。

## 模型与用量边界

- 授权后的连接保存必须先通过区域原生目录发现：使用持久化的原生凭据向所选区域授权域名的
  `/api/v1/vulcancode/models` 发送请求，发现成功后才保存全局连接并发布目录。远端发现类型采用
  穷尽分支，新增类型必须显式声明是否访问远端；`open_vulcan` 属于远端发现，不能在通用校验入口
  被误判为缺少实现。发现失败时撤回临时凭据，不留下已保存连接或生效目录。
- 原生推理契约版本当前为 `2026-08-30`。目录仅暴露用户中心声明的向量和判定能力，不推断对话能力。
- 判定模型的输入资源只取 `decision_capabilities.max_images`：大于零时声明图片输入，为零或缺省
  时只读文本，不按模型名推断。图片输入只影响判定模型自身能力显示，不使其进入对话或多模态理解
  的模型选择（这些入口仍要求对话能力）。
- 向量支持宿主已有的文本输入、查询／文档任务、浮点稠密和稀疏输出。组合稠密加稀疏输出不映射为
  另一种宿主输出类型。输入宽度、默认维度、任务、批次限制均来自发现目录。
  `allowed_dimensions` 为不间断的连续整数时投影为等价的包含式最小／最大维度范围（例如 32–4096），
  存在缺口时保留精确集合；查询指令等输入前缀由用户中心原样转发，目录未声明时宿主不按模型名添加。
- `allowed_tasks` 是用户中心声明的任务字符串，不是宿主语义枚举。当前管理预设与种子目录分别
  使用 `retrieval_query`／`retrieval_document` 和 `search_query`／`search_document`；它们都映射为
  宿主查询／文档语义，但每个模型必须在发现证据中保留自己声明的准确字符串。该证据随协议变体
  冻结、选择和目录内容修订传递，实际请求只发送当前模型的声明值，不按区域、模型名或固定别名推断。
  同一模型若为同一宿主语义声明多个不同值则明确拒绝；未知任务不授予执行能力，没有任何受支持
  任务的向量模型不进入可执行目录。原样使用宿主语义标签的服务端声明仍保留其自身值。
- 原生 VMM 按用途选任务：路由同时声明查询与文档任务时，写入记忆用文档任务、检索用查询任务，
  否则两侧共用通用任务；只声明其中一侧的路由被拒绝，原因以目录键返回界面。任务配对计入向量代次
  指纹，配对改变即要求重建记忆向量。同一向量空间的物理指纹锁记录存储侧任务，查询与文档调用共用一把锁。
- 换供应商或中转会产生新代次。模型未变时，维护页可对维度一致的记忆“沿用现有向量”：每个旧代次可能
  来自不同模型，服务为每个旧代次各取一条带摘要的记忆用当前路由重新嵌入，只把余弦相似度达到阈值的
  代次改标为当前代次，未达标或无可抽样摘要的代次留待重建；没有任何代次达标时拒绝并要求重建；维度
  不同的记忆始终需要重建。
- 目录先校验协议版本，再逐模型解码。结构错误保留模型数组位置和具体字段原因；任务绑定冲突
  标识 `capabilities.allowed_tasks`，不再吞掉原因而只返回笼统目录错误。
- 响应校验契约版本、逐次请求编号、模型身份、完整索引、维度及有限数值。稀疏坐标允许零权重和空向量，
  索引必须唯一有序；词汇索引不受稠密向量维度限制。
- 判定映射当前宿主支持的选择题。服务端还支持的其他题型不在宿主接口中虚构。当前宿主要求供应商返回
  置信度与完整选项概率；上游合法省略这些可选证据时显式返回协议错误，不补造概率或放宽权限放行规则。
- 原生 `request_id` 是单次分派关联编号，不是幂等键。每次实际请求可能独立计费，因此原生推理失败不
  自动重放，响应丢失时保留结果未知状态。
- 账户信息、有效积分批次与小时用量分别读取 `account`、`quota-balances` 与 `usage`。基础额度只从
  有效批次计入，不能再与账户摘要相加。积分通过整数换算十进制字符串，用量计数始终保留服务端字符串，
  不经 JavaScript 浮点转换。
- 历史用量按服务端不透明游标分页，不能传用户或设备选择器。切换账户或关闭弹窗后，旧的在途响应不能
  更新新账户视图。

## 用户中心新增接口与上线顺序

用户中心补充以下原生客户端接口，均位于授权域名并只接受设备 `Auth` 凭据；浏览器 Cookie 不能授权：

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/v1/vulcancode/account` | 当前授权设备、公开用户身份与额度摘要 |
| GET | `/api/v1/vulcancode/quota-balances` | 当前用户有效积分批次 |
| GET | `/api/v1/vulcancode/usage` | 当前用户有界小时用量分页 |
| POST | `/api/v1/vulcancode/logout` | 撤销当前设备，其他设备不受影响 |

先部署带上述接口的用户中心，再分发客户端。国内与国际部署分别验证，国际入口不会回退到国内账户。
本次代码验收使用离线测试、模拟凭据和本地构建；真实浏览器批准、生产令牌轮换、生产积分扣费与多机
运行仍需在对应部署更新后进行验收。不要把模拟接口测试记作真实生产授权成功。

区域发现回归保留随包清单、真实域名、证书校验与原生授权头，通过仅注入测试客户端的域名解析指向
本地 HTTPS 服务，执行实际凭据数据库、连接保存事务与目录发布。两个区域均提供上述两种任务命名
的模型，并继续执行查询和文档请求，校验发送的任务值来自对应模型及原生响应解码。另覆盖未授权和
无效契约响应后的回滚；不访问生产账户，不修改系统域名解析，也不替代真实线上授权验收。
