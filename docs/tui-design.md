# Vulcan Code TUI 结构说明

> 适用于当前模拟演示阶段。实现细节以源码为准；本文只描述分层与交互约定。

## 运行

```bash
cargo run --bin vulcan-tui -- --locale zh-TW
```

参数：`--locale <tag>`（省略时按系统语言匹配）、`--theme dark|light`。

## 分层

| 目录 | 职责 |
| --- | --- |
| `src/model/` | 与服务协议对齐的数据模型（会话、事件、工具调用、Git、系统快照） |
| `src/backend/` | `Command` / `BackendEvent` 通道；`mock/` 为脚本化模拟服务（思考、输出、工具、提问、Git、系统插件） |
| `src/app/` | 状态机：焦点、区域、浮层、提问、历史索引、命中表，以及 `action::perform` 单一副作用入口 |
| `src/app/input/` | 键盘与鼠标输入，按焦点与浮层分派 |
| `src/ui/` | 纯渲染：工作台、侧栏、会话记录、思考框、输入框、右侧面板、系统页面、浮层 |
| `src/i18n*`、`src/bin/vulcan-tui-i18n.rs` | 运行时翻译与上游目录同步工具 |

## 界面

- **顶栏**：品牌、区域标签（工作台 / 技能 / 插件 / 代理 / 记忆 / 知识库 / 设置）、分支、连接状态。F2 切换区域。
- **工作台**：
  - 左侧栏：新建会话、添加项目（文件夹选择器）、置顶与项目分组、右键或 `⋯` 打开菜单。分隔线上的 `⊟/⊞`（或 `z`）
    折叠/展开全部项目，`«`（或 Ctrl+B）收起为窄栏：按钮加每个项目的首字母与运行/待处理标记，点击首字母以抽屉
    打开列表并定位该项目。宽度放不下完整侧栏时自动显示窄栏；连窄栏都放不下时侧栏只在获得焦点时以抽屉出现。
  - 会话记录：思考、回复（Markdown）、工具组可折叠；超过 12 行的用户消息折叠为 8 行预览，点击展开；
    Ctrl+T 切换思考框停靠/浮动。
  - 会话栏（输入框上方固定一行）：上下文用量、本轮实时用量（运行中，`~` 表示流式估算）或上一轮、缓存命中率、
    会话合计（含子代理）、子代理、目标、记忆注入数、输出速度。各段有完整与紧凑两种形式和优先级，宽度不足时
    低优先级先收缩再隐藏，剩余空间再还给高优先级段；点击打开对应面板标签。对话列低于 14 行时不显示，上下文
    进度条改回状态栏。阈值颜色与 WebUI 一致（90% 警示、95% 危急，`Theme::usage_color` 唯一定义）。
  - 输入框：模式、附件、模型、推理强度、停止按钮；`/` 斜杠命令。Alt/Ctrl/Shift+Enter、Ctrl+J 或行尾 `\` 加
    Enter 换行；高度随内容增长，上限为对话列高度的 1/3（3–12 行）。4 行或 800 字以上的粘贴折叠为
    `[粘贴 #n · m 行]` 标签：退格/删除整体移除，点击或 Alt+V 预览、展开或移除，发送时展开为原文。不支持括号
    粘贴的终端中，逐键到达的粘贴会在事件循环中合并还原（`app::composer::coalesce`）。
  - 右侧面板（Alt+1..6 直达）：变更（diff、暂存、提交、推送、切换分支）、进度、终端、记忆（本会话的动态 TTL
    条目与静态画像）、统计（上下文用量、目标、主会话与子代理用量）、代理（子代理运行状态）。条目可打开
    详情表（Detail sheet）查看全文并执行操作。
- **系统区域**：左侧导航 + 声明式页面（`app/pages/` 按区域产出行，`ui/pages.rs` 统一渲染）。导航分组，页面右侧显示
  计数或未保存草稿数（`PageId::badge`）。
  - 插件：LuaSkills 技能包（工具显式/隐式/禁用切换、更新、卸载、安装）与 LuaSkills 设置；代码语义索引的项目
    （更新模式、同步、重建、碎片压缩）与引擎设置；Vulcan 插件列表（UI 挂载点只列出、不渲染）。
  - 记忆：概览；数据组（内容、画像、记忆项目、内部维护）；配置组（规则、内部推理、原生资源、高级设置）。
  - 知识库：知识库列表、单库详情（设置、导入目录、索引健康度与修复/重建）、检索。
  - 代理、技能：按系统 / 用户 / 插件层分组，支持启用、覆盖还原与删除；正文编辑在编辑器中进行。
  - 设置包含外观与语言、上下文、通知、Git 提交、供应商、凭据、模型、AI 能力、MCP、已归档会话、诊断与关于。
- **页面行类型**：分节标题线、带点引导线的只读信息、开关、选项、数字（‹ › 步进，Enter 直接输入并校验范围）、
  文本、按钮、可展开条目（操作按钮排不下时换行）、统计卡片、进度条。
- **草稿**：设置类页面的修改先进入草稿，只保存/放弃本页前缀（`PageId::draft_prefixes`）；跨字段校验失败时
  以提示替代保存按钮。机密设置只经 `SetSetting` 单次发送，不进入草稿或本地状态，留空表示保留原值。
- **浮层**：命令面板、选择器、菜单、确认、输入提示、文件夹选择器、diff、提交对话框、帮助、历史浏览（Ctrl+F）与详情查看器。

## 交互约定

- 所有区域支持鼠标：单击聚焦或激活、双击打开、右键菜单、滚轮滚动；浮层外点击关闭浮层。
- 提问（Ask）为会话内非模态面板，带上一题 / 下一题步进按钮。
- 历史浏览按类别过滤并搜索；详情查看器完整展开单个条目的全部事件（输入 JSON、变更、输出）。
