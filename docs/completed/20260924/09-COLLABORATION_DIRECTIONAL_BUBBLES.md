# 协作消息按收发方向展示

## 目标与最终约定

- 收到的会话任务、通知和任务结果右对齐，采用用户提示词气泡外观，但仍是协作消息。
- 气泡上沿显示消息类型、来源会话名和状态。会话名点击跳转，不显示当前会话或“来源／目标”标签。
- 任务消息标题按方向组成自然语句：发送方为“向 [会话名] 会话发送消息”，接收方为“收到来自 [会话名] 的消息”；名称保持可点击。宿主尚未提供名称时保留通用标题，不暴露内部身份。
- 短正文默认完整显示，不提供整卡折叠。超过用户提示词共用的二十行预览限制后，才显示浅色下箭头，展开或收起超出部分。
- 时间在气泡外侧右下方，不提供用户提示词的复制、编辑按钮。
- 发出的消息与结果保留工具卡布局和整卡折叠，只显示目标会话；子代理完成结果继续使用工具卡。
- 新任务气泡在“正在工作／已工作”分隔线上方，回合内插队位于执行过程内部。

## 决策及理由

1. 依据强类型接收、发送事件选择对端，不按名称或正文推断方向；任务结果按实际回传方向显示对端。
2. 复用用户气泡样式、统一宽度变量和既有测量折叠。预览行数抽为唯一常量，避免用户提示词和协作气泡各自维护限制。
3. 正文独立测量，短内容不受原整卡折叠记忆影响；时间独立于正文，始终放在框外。
4. 会话导航与折叠按钮分离，名称点击不能意外折叠。没有可用名称时不生成空导航控件，也不暴露内部标识。
5. 按已认领任务的规范回合身份将任务起点放到工作分隔线之前，保持运行中插队原位置，不改动持久化事件和后端调度。
