### 第四轮真实发现：全停没有结算已接纳未投影问题

在排除自然完成疑点后，对照正式方案的另一条规则：目标在可靠接纳问题后明确停止，应保留原接纳历史，同时向提问方报告 `TargetStopped`，允许其查询和显式撤销。当前 `set_collaboration_run_control` 已把未应用任务消息随停止原子失败，却没有处理目标收件箱中仍为 `Accepted` 的临时提问；已接纳问题的旧唤醒可能在停止前就返回延后，停止后来源仍无失败进度。新增领域回归先在原代码上重现 `Accepted` 与预期 `Failed` 不符。修复选择仅在 `Stopped` 与 `MainAndSubagents` 的原子停止修订中失败未投影、未结算的目标投递；`MainOnly` 的子到主提问及自然完成不变。服务停止后用双方规范生命周期门读取精确来源和目标身份，按目标失败操作日志回传修订和事件序列；两次写入间的中断由现有来源出站箱恢复。真实服务用例核对等待工具的 `target_stopped` 回执、来源坐标、重放幂等与显式撤销；领域全量 464 项及服务协作 147 项通过。此项为真实缺陷，连续无问题计数归零。

### 继续审核发现：普通子代理停止未关闭协作准入

普通子代理的面板停止与原生 `interrupt_agent` 会停止 `TaskRuntime`，但其 V1 文档没有可靠写入 `Stopped`；目标已接纳而未投影的问题也因此不会触发上一项修复。面板停止还会提前移除精确分离监听器，使其终态发布入口认为自己不再拥有执行，跳过子回合与父结果发布。不能以 `child_execution_profile` 判断子身份：真实服务回归证明，子会话可能在该配置尚未写入时就停止。因此保留监听器直至其发布终态，并在已经核对父任务预留、子根输入及执行身份的 `publish_non_success` 中，把子回合关闭与 `Stopped` 控制合并为一个原子修订；分离监听器随后独立回传目标停止的问题失败，回传错误不改变子业务终态。真实服务用例覆盖未准备完成的子会话、停止后拒收、已接纳问题失败、来源回执及原终态重放。此项修复后连续无问题轮数再次归零。

### 继续审核发现：关闭活动子代理会吞掉原终态

`close_agent` 在全部任务锁内中止活动执行并把常驻记录标为 `Archived`；被中止的原 Future 随后调用终态保存时，原准入函数因 `Archived` 返回“过期”，不会向分离监听器发布 `DelegateFinished`，父 V1 子任务义务因此可能永远不结算。定向回归先复现原停止回执被拒。修复只对同时满足“关闭归档、同一执行身份、同一尚在活动表且已预留停止的执行”的终态放行父报告，保持运行时记录及公开代理槽位已归档；不放行替代执行，也不把归档状态恢复为运行中。停止、完成和失败均须保留宿主实际终态分类。`close_agent` 相关八项测试通过；扩大到整个 `task_runtime` 筛选时，Windows 测试进程以 `STATUS_STACK_OVERFLOW` 退出，不能据此宣称全量通过，也未将该异常归因于本修复。此项单独提交并再次清零；后续继续审核关闭后的 V1 目标准入及卸载时序。

### 继续审核发现：关闭子代理没有可靠封闭消息准入，并过早卸载原终态所有者

运行时归档不等于 V1 停止：原 `close_agent` 只改变常驻注册表，冷加载子文档仍可接收问题；模型关闭事件与面板关闭又会提前卸载规范句柄、移除分离监听器，使原终态无法写回。决定让模型与面板共用宿主关闭入口：先解析精确子树及存储根，在排序后的规范生命周期锁内复核来源调用和目标身份，再通过运行时关闭事务的前置回调可靠写入停止准入，随后中止并归档。禁止模型工具缺少可靠宿主时退回纯运行时关闭。每次停止尝试采用独立操作身份，避免失败后恢复再关闭时错误重放旧停止回执。只有原监听器、开放业务回合和父侧任务义务全部结算才卸载规范句柄；界面导航可先隐藏已关闭子代理。失败问题独立回传，失败时保留句柄供恢复处理。

本项定向验证：运行时关闭八项通过，关闭界面投影三项通过，真实存储用例验证已结束子代理关闭后保留原监听器、监听器清理后卸载、冷加载可靠停止及拒收问题；服务和运行时全目标编译通过。全局格式检查存在大量既有差异，未执行全局格式重写。继续检查停止意图落盘与原执行终态落盘之间进程退出的冷恢复边界；此项修复不代表该边界已经验证。

最终补充验证：关闭修复后的服务协作一百四十八项全部通过。

### 继续审核发现：可靠停止与原子终态之间退出导致父任务永久待结算

子会话的停止意图已经落盘但原监听器尚未发布终态时退出，旧启动恢复拒绝重新运行停止的子会话，也因缺少真实回合闭合事件而不回传结果，父预留持续未完成。决定在原生终态恢复中补充明确停止恢复：持有规范父子生命周期锁后复核启动所有者、原预留、子代次及精确根动作；只有持久控制为停止或全停、原业务回合仍开放，并且没有原监听器或活动运行时执行时，才通过既有非成功发布器闭合原子回合并记录父侧停止凭据。已有成功或失败终态优先使用原事实；后续回合不受影响。不得仅因工作者缺失就推断失败或停止，也不得伪造最终正文。子侧已闭合而父发布中断时，下一次恢复继续使用原有终态重建路径。

新增真实存储验证覆盖两类停止、活动监听器排除、冷重载、父任务义务解除和重复扫描幂等。首次测试误将活动父 API 的正常跳过预期为冷 Hook 错误，修正测试预期，生产语义不变。再次测试真实暴露预留任务只能失败、不能停止的领域限制：停止可能发生于激活之前，因此允许预留直接结算为停止，仍禁止预留直接成功，不制造激活时间。对尚未发布子文件的初始预留，同样在根、父、子生命周期门和无活动所有者证明内，依据明确停止结算父义务，不创建子文件、子回复或非成功正文凭据。单独归档仍仅延后创建。领域协作九十项通过；最终服务验证结果待本项提交前补充。

本项最终验证：领域协作九十项、服务协作一百四十九项全部通过。继续审核时还发现后继复用的父预留尚未发布到子历史便遇到整树停止的相邻恢复窗口，另项处理；不将本次定向验证计入完整审核轮次。

提交边界复核：生命周期设计文档此前已由文档整理提交取消跟踪，本地文件仍保留。上一修复中强制暂存该文件会恢复其整份跟踪，超出本次允许的文档边界；立即用仅索引移除纠正，保留本地文件及停止恢复补充内容。本审核计划继续作为已授权的提交内决策记录，不恢复其他被文档整理取消跟踪的文件。

### 继续审核发现：整树停止在传播完成前退出，或取消尚未发布的后继

进一步追踪复用子会话发现：父侧后继预留已持久保存，但子历史尚未发布对应根输入时，整树停止使后继发布被跳过；旧结果恢复又要求根输入存在，因此父义务无法结算。同类窗口也存在于根停止已经落盘、后代停止尚未逐个落盘时。决定把规范根句柄及发现代次纳入原生结果恢复的有序生命周期锁，明确根、直接父或子停止均可在无活动所有者时授权该原执行的停止修复；`MainOnly` 不授予整树停止。已有真实完成或失败结果优先重建。

对于没有发布根输入的后继，仅当父侧精确预留仍为预留、可靠捕获意图明确为后继、子代次与身份匹配、原根输入不存在、且没有活动运行时或监听器，才把原父预留结算为停止。旧子历史、旧 API 和原执行结果均不修改；不生成子回复或激活事实。恢复操作键由父代次及原预留事件序号构成，避免无界追加原操作字符串。新增真实磁盘用例验证后继取消、前序历史完全保持和重复恢复幂等；原冷恢复用例增加停止只写入父侧的分支。服务全目标编译通过，最终协作回归结果待补充。

后继停止修复最终验证：服务协作一百五十项通过，服务全目标编译通过。随后第一轮完整审核无新问题，第二轮对照通知与提问拒收时发现通知来源提交后、目标接纳前的确定性拒收仍只被当成暂时错误反复重试；此项另行修复，连续无问题计数重置。
