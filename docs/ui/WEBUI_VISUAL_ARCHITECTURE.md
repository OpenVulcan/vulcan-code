# WebUI 视觉体系与特殊界面边界

## 1. 分层结构

- `components/ui/`：普通基础控件。负责统一的颜色、边框、圆角、阴影、焦点、禁用状态和通用密度。
- `components/product/`：稳定产品概念的组合组件。只接收确定的视图模型，不请求服务、不订阅全局状态。
- `components/features/`：业务数据适配、状态编排和页面布局。不得重新实现普通控件皮肤。
- `components/dev/visual-lab-settings-area.tsx`：共享组件与产品组件的固定人工验收入口。
- 特殊界面：只在下述白名单内拥有独立内容排版、语义色、局部滚动和复杂交互结构。

## 2. 特殊界面白名单

| 特殊区域 | 允许独立维护 | 禁止跨越的边界 |
| --- | --- | --- |
| Composer | 输入器、附件条、模型与能力选择器、进度胶囊、上下文圆盘、工具栏层级与分隔线 | 不改变会话滚动、转录渲染和锚点恢复 |
| 会话转录 | 稳定业务行、单行订阅、测量折叠、流式正文、语义锚点与会话位置恢复 | 不被普通 Card、Surface 或全局排版规则强制包裹 |
| Markdown | 标题、列表、表格、引用、代码块、增量渲染和局部滚动 | 不接受普通页面的元素级全局覆盖 |
| Diff | 增删改语义色、行号、并排/统一视图、搜索与大文件分段渲染 | 不将 Diff 语义色改成普通状态色 |
| 终端 | ANSI颜色、屏幕缓冲、选择复制、会话实时状态和停止语义 | 不使用历史结果覆盖实时命令会话状态 |
| Mermaid、SVG与媒体 | 画布、缩放、播放、生成媒体窗口和内容比例 | 不继承普通文本排版与Card内滚动 |
| Tool Presentation | 工具证据、命令输出、错误诊断和详情折叠 | 普通按钮、Tooltip、Dialog仍应复用共享控件 |

## 3. Composer 当前结论

Composer 的普通 Dialog、Button、DropdownMenu、Tooltip、Textarea 已经使用共享组件。保留的原生按钮均属于附件条、进度胶囊、上下文圆盘、计划胶囊、模型行或命令结果等专用结构；隐藏文件输入和数值目标输入也具有明确职责。不得为了消灭原生标签而改变其已经调教的尺寸和布局。

输入内容区与底部工具区继续由 `.composer-toolbar` 的顶部一像素分隔线和浅工具栏背景区分。该规则只属于工具栏区域，不允许扩散到整个Composer面板。

## 4. 样式作用域规则

1. 普通业务页面只允许为共享组件补充宽度、网格位置、对齐、滚动容器和业务专用最小尺寸。
2. 普通业务页面不得覆盖共享控件的颜色、边框、圆角、阴影或焦点环。
3. 特殊界面允许在自己的作用域内定义内容结构，但普通操作控件仍应复用共享组件。
4. `markdown.css`、`special-blocks.css`、`tool-presentations.css`、Diff、终端和媒体样式不得使用无作用域的元素选择器影响普通页面。
5. 会话语义滚动、稳定行业务投影和 per-surface 状态恢复不属于视觉体系重构范围。

## 5. 会话转录职责边界

会话转录继续使用原生 DOM 流布局，不为 Markdown、代码块、图片或可展开工具结果建立估算型虚拟画布。时间线顺序与行业务快照分离：顺序层只保存稳定业务键，行 Store 只通知真实发生变化的 Turn，历史 Turn 不随活动计时器或相邻流式正文重复更新。

主会话和子代理转录均由统一滚动控制器拥有程序化位置写入权。控制器按精确 surface id 保存 `anchorKey`、`anchorTop`、`scrollTop` 与 `followTail`，通过真实 DOM 业务行恢复会话切换、历史前置和宽度重排后的阅读位置。展开状态与像素高度分离；运行期记忆不保存 Turn 高度，也不为每个 Turn 建立 `ResizeObserver`。

浏览器原生锚定在会话滚动容器内保持关闭，因为显式语义锚点已经负责几何补偿；两者同时启用会形成双重位置修正。普通视觉组件不得直接写入会话 `scrollTop`，也不得通过固定毫秒窗口、设备事件猜测或重复多帧回放干预滚动所有权。

## 6. shadcn 定位

当前 `shadcn` 不只是生成期工具：`styles.css` 仍显式导入 `shadcn/tailwind.css`，因此本轮不移除该依赖。组件的实际产品契约由项目内 `components/ui`、语义变量和Visual Lab维护；后续只有在移除运行时CSS引用并完成全页面验证后，才能把shadcn降为纯生成工具。

## 7. 验收入口

- 设置 → 系统 → 视觉实验室：共享组件矩阵与产品用量组件状态。
- 空会话与已有会话：Composer分隔线、工具栏背景、多行输入及弹出层。
- 长Markdown、代码块、Diff、终端、Mermaid和媒体：特殊内容作用域。
- Settings、VMM、Skills、Agents、Agent Skills、Knowledge：首次延迟加载与重复打开。
- 项目图标：默认文件夹、自定义徽标、Skill Icons、Material Icon Theme与Lucide。
